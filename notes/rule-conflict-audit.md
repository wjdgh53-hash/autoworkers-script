## 0. 원칙 — 정호님

> *"계속 기존 문제를 막기 위해 무언가를 추가하고 덧대면 서로 충돌되는 문제가 계속 생기고, 읽어야 할 데이터도 많아지고 복잡해지는 거 아니야?"*
> *"불필요한 규칙 다 제거하고, 서로 충돌하는 규칙 다 제거하고, 쓸데없는 말을 자아내는 규칙 다 제거하기."*

**새 규칙을 덧대지 않는다. 사고를 유발하는 기존 규칙을 찾아 도려낸다.**

### 이 감사가 찾아낸 핵심 원리

> **규칙에는 「막는 것」과 「시키는 것」이 있는데, 사고는 대부분 「시키는 것」에서 난다.**

| | 성격 | 결과 |
|---|---|---|
| **막는 규칙** (상한·금지) | 어기지만 않으면 된다 | 없는 소재에서 뭘 만들 이유가 없다 |
| **시키는 규칙** (하한·필수·최소 개수) | **채워야 통과한다** | 그 소재에 필요 없어도 **만들어 낸다** |

08-16의 결함이 전부 후자였다. 작가·검수자는 규칙을 어긴 게 아니라 **지켰다.**

**추가 원칙: 지표는 소재를 보지 않는다.** 1,000자당 개수를 세는 규칙은 숫자가 본질인 소재와
사람 이야기를 구분하지 못한다. 총량 규칙 대신 **소재와 무관하게 항상 결함인 것**만 남긴다.

### ① 삭제한 「시키는 규칙」

| 규칙 | 채우면 나오던 것 |
|---|---|
| 반문 하한 3.5 | 답 없는 질문 (08-16이 7.7) |

| 2인칭 하한 1.2 · 반문 하한 1.4 (방구석) | "여러분" 남발 — 신설 당일 철회 |
| **확장 비유 = 8블록 필수** | **본문 3분의 1을 비유로 채움** → 개념을 비유로 대체 |
| 훅 ⑤ "답의 씨앗을 **은유로**" | *"머스크의 돈이 앉아 있던 그 자리"* |
| 훅 ⑤ "**추적 선언**" | *"뒤에 가서 한 줄로 갚아 드리겠습니다"* |
| 클로징 "**열린 질문 2~3개, 답을 주지 않고**" | 매 영상 답 없는 질문 2~3개 |
| 오픈루프 "파트 전환 직전마다" | 파트 7개면 오픈루프 6개 = 답 미루기 6번 |
| 독창성 "최소 3가지" / 레퍼 표현 "최소 5개, 웬만하면 있다" | 없는 것을 찾아 올림 |
| L1 차용 "최후의 수단" / "최소 2개는 L3·L4" | 제목 공식 계승이 곧 L1인데 억제됨 |
| 설계 원칙 예문 "요구사항 **3개 이상** 나열" | 두 개뿐이어도 세 개를 만듦 |

**남긴 하한은 「숫자 밀도」 하나뿐이다.** 이건 문체 요구가 아니라 *"비유로 분량을 때웠나"* 의
진단 지표이고, 미달의 처방이 **"숫자를 채워라"가 아니라 "비유를 걷어내라"** 다.

### ② 삭제한 「소재를 안 보는 총량 상한」

**숫자 밀도 상한 10.0 / 방구석 34.0.**

- **과반이 걸리는 상한은 무시되고, 그 습관이 진짜 FAIL에도 옮겨붙는다** — 08-16 비유 경고가 그렇게 통과됐다
- 실제 청취 문제인 **몰아쓰기는 문장당 4개 게이트가 잡는다**(초과 54편 중 40편이 거기에도 걸림)

### ④ 오탐 제거 — 문장당 숫자 게이트

**169문장 → 45문장.** 제외한 것:
- **날짜** — *"2005년 12월에 법이 바뀌면서 2006년 1월부터"* 가 숫자 4개로 잡혔다. 날짜는 계산 대상이 아니라 시점 표지다
- **분수** — *"3분의 1에서 4분의 1"* 이 4개. 게다가 §3이 **퍼센트를 분수로 바꾸라고 지시**한다. 규칙을 지킬수록 걸리는 모순이었다
- **제품명** — 천궁2 · F-35 · 코로나19의 숫자는 이름의 일부다

남은 45문장은 *"군수지원 50퍼센트, 성능 20퍼센트, 가격 15퍼센트, 협력 15퍼센트"* 같은 진짜 나열이다.

### ⑤ 배선 — 만들어 놓고 연결하지 않은 규칙

2026-08-19에 방구석 전용 썸네일 규칙 2개 파일을 만들었는데 **PD 전달 목록에 등록하지 않았다.**

매핑이 없어 생성되지 않았다.

→ `illustration` 매핑 신설, **채널 전용 오버라이드 전달 의무화**, 방구석 배정 갱신,

> **교훈: 채널 config에 규칙 파일을 새로 만들면 `pd-script.md` 전달 목록에도 반드시 등록한다.**
