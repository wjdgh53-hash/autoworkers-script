## 0. 원칙 — 정호님

> *"계속 기존 문제를 막기 위해 무언가를 추가하고 덧대면 서로 충돌되는 문제가 계속 생기고, 읽어야 할 데이터도 많아지고 복잡해지는 거 아니야?"*
> *"불필요한 규칙 다 제거하고, 서로 충돌하는 규칙 다 제거하고, 쓸데없는 말을 자아내는 규칙 다 제거하기."*

**새 규칙을 덧대지 않는다. 사고를 유발하는 기존 규칙을 찾아 도려낸다.**

### 이 감사가 찾아낸 핵심 원리

> **규칙에는 「막는 것」과 「시키는 것」이 있는데, 사고는 대부분 「시키는 것」에서 난다.**

| | 성격 | 결과 |
|---|---|---|
| **막는 규칙** (상한·금지) | 어기지만 않으면 된다 | 없는 소재에서 뭘 만들 이유가 없다 |
| **시키는 규칙** (하한·필수·최소 개수) | **채워야 통과한다** | 그 소재에 필요 없어도 **만들어 낸다** |

08-16의 결함이 전부 후자였다. 작가·검수자는 규칙을 어긴 게 아니라 **지켰다.**

**추가 원칙: 지표는 소재를 보지 않는다.** 1,000자당 개수를 세는 규칙은 숫자가 본질인 소재와
사람 이야기를 구분하지 못한다. 총량 규칙 대신 **소재와 무관하게 항상 결함인 것**만 남긴다.

### ① 삭제한 「시키는 규칙」

| 규칙 | 채우면 나오던 것 |
|---|---|
| 반문 하한 3.5 | 답 없는 질문 (08-16이 7.7) |
| 권위 인용 하한 0.3 + "파트마다 최소 1개" | 억지 출처 |
| 전환어 하한 0.6 | "자," 남발 |
| 2인칭 하한 1.2 · 반문 하한 1.4 (방구석) | "여러분" 남발 — 신설 당일 철회 |
| **확장 비유 = 8블록 필수** | **본문 3분의 1을 비유로 채움** → 개념을 비유로 대체 |
| 훅 ⑤ "답의 씨앗을 **은유로**" | *"머스크의 돈이 앉아 있던 그 자리"* |

| 클로징 "**열린 질문 2~3개, 답을 주지 않고**" | 매 영상 답 없는 질문 2~3개 |
| 오픈루프 "파트 전환 직전마다" | 파트 7개면 오픈루프 6개 = 답 미루기 6번 |

## 3. 2차 감사 (2026-08-19 후반) — 남겼던 3건 전부 처리

### 3-1. 계측기 오탐 3종 추가 제거 — 그중 하나는 버그였다

남은 FAIL을 표본으로 확인하니 게이트가 아니라 **계측이 틀린** 경우가 더 있었다.

| 오탐 | 예 | 원인 |
|---|---|---|
| 🔴 **이중 계수 (버그)** | `5만 7천 명`이 숫자 **2개** | `_NUM_RE`가 "5만 7천"을 세는데 `_KO_NUM_RE`가 뒤쪽 "천 명"을 또 셌다 |
| 비율 | `6대 1에서 21대 1` | 분수와 같은 논리 — 하나의 값이다 |
| 단위 붙은 범위 | `115발에서 131발` | 범위 정규식이 단위를 못 넘어갔다 |

**이중 계수는 문장당 나열뿐 아니라 숫자 밀도 값 전체를 부풀리고 있었다**(탐정 중앙값 13.4 → 13.0).
우리 대본은 TTS 규칙 때문에 큰 수를 아라비아+한글로 섞어 쓰므로 영향이 광범위했다.

### 3-2. 1인칭 정규식에서 1인칭이 아닌 말 제거

`솔직히` · `화가 나` · `놀랐` · `믿기지` — 전부 화자를 가리키지 않는다.
> *"솔직히 흔한 일이 아니에요"*(부사) · *"화가 나서 문을 두드려도"*(3인칭 장면) · *"믿기지 않는 수치입니다"*(3인칭)

이 넷 때문에 16편이 걸렸는데 진짜 1인칭 기준으로는 12편이었다.
**상한 1.2는 유지한다** — 진짜 1인칭 중앙값이 0.63이라 잘 맞는 값이고, 1인칭 과다는
소재와 무관하게 발표자 말투를 만드는 항목이라 반문·숫자밀도와 성격이 다르다.

### 3-3. 썸네일 규칙 감사 — 자기모순·누락

| 발견 | 내용 |
|---|---|
| 🔴 **자기모순** | 방구석 오버라이드가 *"그대로 두는 것: 진영 서사 무명인 금지"* 라고 선언해 놓고, 같은 파일 §2-A가 **무명인을 세우라**고 했다 |
| **옛 값 잔존** | 방구석 §6이 `styles`를 `["photorealistic"]` 한 종으로 적고 있었다 (JSON은 이미 2계열) |
| **원본이 불완전** | 「분수·%·픽셀 병기 금지」가 **국기볼형에만** 있었다. 세이프존의 유일한 원본은 design인데 정작 원본에 없었다 |
| **계열 누락** | strategist Phase 5·출력 목록, channel-setup Q7에 일러스트형이 빠져 있었다 |
| **예외 미기재** | 인물 크기 공통 55~60%가 "유일한 원본"인데 일러스트형은 30~40%다 |

**무명인 금지의 진짜 정체**: 공통 규칙은 **국가·기업이 맞서는 진영 서사 전용**인데
그 조건이 안 적혀 있었다. 주어가 시청자 본인인 채널은 진영 서사가 아니므로 적용 대상이 아니다.
→ 공통 파일에 적용 조건을 명시하고, 방구석 표에 「적용하지 않음」으로 넣었다.

## 5. 앞으로 지킬 것

1. **하한·필수·최소 개수를 새로 만들지 않는다.** 막고 싶으면 상한이나 금지로 쓴다
2. **1,000자당 개수를 세는 규칙은 소재를 못 본다.** 총량 대신 "항상 결함인 것"을 잡는다
3. **게이트가 과반을 잡으면 게이트를 의심한다.** 무시되는 경보는 진짜 경보까지 무디게 만든다
4. **채널 config에 규칙 파일을 만들면 `prompts/pd-script.md` 전달 목록에 반드시 등록한다**
5. **수치를 고칠 때는 `check_tone.py`를 먼저 고친다.** 문서의 표는 옮겨 적은 것이다
6. **「왜 이 규칙이 생겼나」는 지우지 않는다.** 이번에 반문 하한을 걷어낼 수 있었던 것도
   *"근거가 203k 1편"* 이라고 적혀 있었기 때문이다. 줄인다면 삭제가 아니라 `notes/`로 옮긴다

- 소재가 비유를 안 부르면 **비유가 0개여도 된다**
- 고유명사는 **`이름 + 쉬운 한 줄 설명` 순서**로 살아 있다
- 던진 질문에 그 자리에서 답한다 (규칙으로 강제하지 않지만, 압력이 사라졌으니 자연히 그래야 한다)

### ③ 기계 — 자동으로 돈다

```bash
.venv/bin/python scripts/src/check_tone.py {대본경로}
.venv/bin/python scripts/check_rules.py          # 규칙이 되돌아갔는지
```

### ④ 결함이 나왔을 때 — 원인을 규칙에서 찾는다

**대본만 고치지 않는다.** 이 문서 §0 원칙대로, 그 결함을 유도한 규칙이 있는지 먼저 본다.
없으면 그때 대본을 고치고, 있으면 규칙을 지운다.

⛔ **결함을 막는 새 규칙을 넣지 않는다.** 그게 이 저장소가 망가진 방식이고,
2026-08-19에도 내가 원인을 지운 자리에 반대 규칙을 다시 놓았다가 회수했다.
