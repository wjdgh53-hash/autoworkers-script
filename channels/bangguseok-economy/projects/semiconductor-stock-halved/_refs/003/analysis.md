## 4. 본문 구조 분석

**전체 구조 요약**

준법서약(개별 매매 금지) → 은퇴, "자유인" 오독 → 옛 취재기업 1억 매수 → 하락, 2천만 원 물타기 → 아내와 1차 갈등(-35%) → 처분효과 2회 반복(이익종목 매도해 손실종목에 재투입) → 글로벌 폭락, 패닉셀(-65%, 2.5억 확정손실) → 열흘 뒤 급반등("하루만 더 버텼다면") → 복구성 단타 200회/월, 추가 -2천만 → 앱 삭제, 지수펀드 복귀

패턴: "오만 → 첫 실패 신호 → 부정/합리화 → 확대 재투입 → 파국 → 복구 시도 실패 → 각성" 순환 반복

**전달 기법**

- 스토리텔링: 시간순 1인칭 고백체, 아내와의 대화가 갈등 축으로 반복 등장
- 비유: "잘 자라던 꽃 한 송이를 내 손으로 뿌리째 뽑아다가 (…) 잡초 밭에 옮겨 심은 꼴" (처분효과 설명, 2회 반복)
- 데이터: 손실률(-35%→-50%→-52%→-65%), 금액(1억→1.2억→1.5억→2.5억 손절) 단계적 제시
- 사례: 친구 태석(뇌동매매 비교 대상), 아내(가정 붕괴 서브플롯)

**리텐션 장치 — 여기서 무너진다**

- ⛔ **오픈루프 남용**: "그 확신이 얼마나 위험하고 오만했던 것인지 저는 곧 뼈저리게 배우게 됩니다"류 예고 문장이 초반~중반 **최소 3회** 반복 등장해 스포일러성으로 긴장이 조기 해소됨
- ⛔ **패턴 인터럽트 약함**: 부부싸움 장면이 3회 이상 유사 패턴으로 반복돼 신선도가 떨어짐. 특히 15~25분대가 거의 감정 장면 위주로 **정보 밀도가 비어 있다**

## 6. 댓글 반응 분석

**시청자가 가장 강하게 반응한 포인트**

- 손절 심리("본전만 오면 미련 없이 다 판다")에 대한 공감형 댓글 1건
- ⛔ **신뢰성 의심**: "창피하게 이런기사 거의구라다 조용히살자", "구라" — 서사 개연성(준법서약 위반·내부정보 활용 디테일)이 오히려 **"지어낸 이야기" 인상**을 줘 신뢰를 깎음
- 순위 3·5·7·9번 댓글은 채널 운영자가 앞선 댓글에 붙인 자기 답글로 보이며(문체 동일, "피드백 감사드립니다" 반복), **진성 시청자 반응은 사실상 4~5건에 불과**

**시청자 포지션**

"훈수쟁이가 정작 본인 하면 못한다"는 **냉소적 관전자** 포지션. 시청자 본인 자산과 연결 짓는 댓글은 **한 건도 없다.**

**우리 영상에서 반드시 다뤄야 할 포인트**

- 서사가 과도하게 소설적이면 "구라" 반응으로 확산이 막힌다 — 개연성 있는 디테일 유지
- 손절 타이밍 심리("본전 오면 판다")는 공감대가 있는 소재이므로 활용 가능(표현은 재구성)

## 7. 핵심 약속 역추적

**제목+썸네일이 약속한 것**: "잘난 척하던 전문가가 몰락한 5가지 이유를 알게 될 것 같다"

**인트로에서 확인해준 것**: "30년 지식도 무용지물로 만들어 버린 이 잔혹한 다섯 가지 함정의 전말을 지금 공개합니다" — 방향은 일치하나 **여전히 "저"의 이야기**로만 좁혀져 시청자 자산과의 연결 고리가 없다

**본문이 실제로 전달한 것**: 전형적 투자 실패 패턴(몰빵→물타기→처분효과→패닉셀→복구성 단타)의 개인 서사와 심리 묘사

**약속 이행 평가**: 내용상 이행이나, **개연성 훼손으로 신뢰가 깨져 오버딜리버리는커녕 부분 신뢰 상실**로 이어졌다
