## 1. 기획 뼈대

- **핵심 약속**: 내 나이 칸이 여덟 층 어디에 서 있는지 확인하면서, 내가 못해서 거기 있는 게 아니라 표가 원래 그렇게 생겼다는 것을 알게 된다

- **썸네일 컨셉**: 층계참에 나이대별로 다르게 선 사람들(스케일 대비) / 상단 소형 인용 + 대형 정보 + 최대형 자기위치 질문 + 연령 라벨 5개
- **타겟 러닝타임**: **20분** (8,781자 / 1분 ≈ 440자)
- **톤**: 자기 전에 친구가 옆에서 풀어주는 이야기. 존댓말. 강의·훈계·조언 금지
- **관통 질문**: **"다 같이 나아졌다는데 왜 한 칸만 거꾸로 갔고, 나머지 칸은 왜 다 같은 자리에서 멈추는가?"**

## 2. Hook & Intro

### Hook (79자, ~11초)
최근 조사에서 순자산이 줄어든 나이대는 딱 한 칸이었습니다. 서른아홉 살 아래만 뒤로 갔습니다. 다 같이 나아졌다는데 왜 그 칸만 거꾸로 갔을까요.

### Intro (162자, ~22초)
이 표에는 더 이상한 구석이 있습니다. 나이가 올라갈수록 같은 나이 안에서 격차가 더 벌어집니다. 젊을 때는 옆집과 나란한데 나이를 먹으면 같은 나이 안에서도 층이 갈립니다. 오늘은 순자산을 여덟 층으로 갈라 놓고 우리 나이 칸이 어디에서 멈추는지 대 보겠습니다. 어느 층이냐보다 왜 거기서 멈추느냐가 오늘의 답입니다.

> ⛔ Hook·Intro가 이미 말한 것을 본문이 **처음 소개하듯** 다시 설명하지 않는다.
> Hook 소유: 「39세 이하만 마이너스」라는 **사실의 존재** (수치 −0.9%는 파트 6 소유) / Intro 소유: 「나이 먹을수록 같은 나이 안에서 벌어진다」는 **주장** (수치는 파트 2 소유) · 「여덟 층」이라는 틀

### 파트 2: 평균이 가리키는 자리에 사람이 없다 — 1층부터 3층까지 (~3.0분, ~1,320자) — 3:00~6:00

- **시청자 질문**: "평균 얼마라는 말은 늘 듣는데, 왜 내 주위엔 그만큼 가진 사람이 없지?"
- **블록**: 2 — **모순 발견 + 원리 명명**, 그리고 표의 아래 세 층 세우기
- **핵심 내용**
  1. **모순 발견.** 평균은 매년 오르는데 가운데 선 집은 그만큼 안 오른다. 그 간격을 나이별로 재 보면 **30대 9,475만 원 → 40대 2억 5만 원 → 50대 2억 3,476만 원**. **나이를 먹을수록 같은 나이 안에서 더 갈린다** (배수로도 1.61 → 1.70 → **1.74배**)
  2. **왜 평균이 위로 끌려가나.** 순자산 상위 10% 가구가 전체 가구 순자산의 **46.1%**를 갖고 있다. 1년 새 **1.6%p** 늘어 2012년 통계 작성 이래 최고다. 반대로 **아래쪽 절반을 전부 합쳐도 9.1%**다. **평균은 위쪽 절반의 무게로 만들어진 숫자다**
  3. 🔴 **원리 명명 — 한 문장으로 못박는다.** "층은 얼마를 벌었느냐가 아니라, **값이 오르는 것을 언제부터 쥐고 있었느냐**로 갈립니다." (뒤 파트가 전부 이 문장을 증명한다)
  4. **1층 세우기** — 순자산 1억 원 미만. 전체 가구의 **29.5%**

  6. **3층 세우기** — 3억에서 10억. **3억을 넘기면 상위 43% 안**으로 들어온다
  7. **안도 구간을 여기서 명시한다** — 2층은 못난 자리가 아니다. **표가 그렇게 생겼다.** ⛔ 단, 앵커의 「자책하실 필요 없습니다 / 그건 정상입니다」 골격을 쓰지 않는다. **사실 진술로 안도를 준다** ("가장 많은 사람이 서 있는 칸이 2층입니다")

### 파트 3: 4층부터는 한 칸 올라갈 때마다 자릿수가 바뀐다 (~3.5분, ~1,540자) — 6:00~9:30

  1. 🔴 **확장 비유 0개.** 블록 3을 **숫자 전개**로 간다. 이 채널이 직전에 비유 남발로 검수에 걸린 경로를 구조적으로 차단한다. 「층」은 제목이 준 프레임 언어이지 비유가 아니며, **건물·빌딩으로 명명하지 않는다**
  2. 🔴 **크리에이터 리액션 문형 3종을 새로 설계했다** (오해 정정형 / 동작 보고형 / 자기 반문 취소형). 직전 두 편 연속 치명 항목이던 `저는 + 이 대목 + ~더라고요` 골격을 **문형 단위로 폐기**했다
  3. **선제적 자기부정을 도입 2분에 배치** — 「가구냐 개인이냐」를 먼저 털어 이후 모든 숫자가 시비 없이 통과하게 만든다. 이게 이 채널의 표준으로 굳는 두 번째 편이다
  4. **균형을 두 번 넣는다** (파트 5의 「집을 빼면 뒤집힌다」, 파트 6의 「2012년 이래 줄어든 해는 한 번뿐」) — 세대 갈등으로 읽히는 것을 구조적으로 막는다

- **시청자 차별 경험**
  001·002를 이미 본 시청자가 **그 두 영상 댓글에서 자기가 던졌던 질문(「이거 가구 기준 아니냐」)의 답을 이 영상 3분 안에 받는다.** 그리고 두 영상이 주지 않은 것 — **나이별 상위 1% 문턱**과 **집을 뺐을 때의 역전** — 을 가져간다.

## 6. 리텐션 설계

- **감정 아크**: 신뢰(파트1) → 불안·안도(파트2) → 각성(파트3) → **안도 뒤의 각성**(파트4) → 재불안·균형(파트5) → 공감·균형(파트6) → **단정적 안도**(클로징)

- **재참여 포인트** (2~3분 간격 · 빈 구간 없음)

| 시점 | 위치 | 장치 |
|---|---|---|
| ~0:35 | Hook→파트1 | 관통 질문 설치 (한 칸만 거꾸로 갔다) |
| ~3:00 | 파트1→2 | 오픈루프 A: "대부분의 칸이 아래에서 두 번째에 몰려 있다" |
| ~4:30 | 파트2 중반 | **원리 명명** — 이 영상이 증명할 문장을 못박는다 |
| ~6:00 | 파트2→3 | "1층부터 3층까지는 이렇게 채워집니다. 문제는 4층부터입니다" |
| ~7:45 | 파트3 중반 | **크리에이터 리액션 전환 블록** + 층 간격 숫자 전개 (아래 세 층 9억 vs 한 칸 18억 5,000만) |
| ~9:30 | 파트3→4 | "이제 이 표 위에 나이를 얹습니다" — **핵심 약속 이행 시작** |
| ~11:30 | 파트4 중반 | 40대에서 평균과 가운데 집이 층이 갈리는 지점 |
| ~13:00 | 파트4→5 | "층이 올라간 칸들이 정작 쓸 돈은 더 적다" |
| ~14:45 | 파트5 중반 | **집을 빼면 순서가 뒤집힌다** (반전 1) |
| ~16:15 | 파트5→6 | "집을 못 산 칸은 어떻게 됐을까요" |
| ~17:30 | 파트6 중반 | **관통 질문 절반 회수** (왜 그 칸만 뒤로 갔나) |
| ~18:45 | 파트6→클로징 | "이 표는 나이 순서대로 올라가는 표가 아닙니다" |
| ~19:20 | 클로징 | **63.1세 반전** (반전 2) + 관통 질문 완전 회수 |

- **스테이크 상승**: 「내 층이 어디인가」(2) → 「위층은 다른 표다」(4) → 「내 나이 칸은 삼십 년에 한 칸 움직였다」(4) → 「층이 높아도 쓸 돈이 없다」(5) → 「사다리가 한 종류로 좁아졌다」(4) → 내려서 재운다(3)

- **참고할 레퍼런스 장치** (patterns.md에서 **기능만** 발췌 — ⛔ 원문 문장은 위 금지 골격 목록으로 넘겼다)
  - **초반 오픈루프 1개 설치 → 후반 회수**: 두 성공작이 공통으로 쓴 구조. 우리는 관통 질문(Hook)과 오픈루프 A(파트1)를 각각 파트6·클로징과 파트4에서 받는다. ⛔ **예고 문구는 새로 짓는다** (「뒤에서 정확히 알려 드리겠습니다」 골격 금지)
  - **숫자는 항상 대비 쌍으로**: 평균 vs 가운데 집, 위층 vs 아래층, 집 포함 vs 집 제외. **이 편은 전 파트가 대비 쌍으로 굴러간다**
  - **파트 전환마다 브릿지**: 기능은 계승하되 **정형구를 반복하지 않는다.** 파트마다 다른 문장으로 짓는다 (⛔ 「자, 여기서부터가 진짜 X입니다」·「자, 다음은 N대입니다」 금지)
  - **안도 구간을 말로 선언하기**: 기능은 계승. ⛔ 「자책하실 필요 없습니다 / 그건 정상입니다」 골격은 금지 → **사실 진술로 안도를 만든다**
  - **회의를 선제 해소하기**: 001·002 최상위 댓글이 전부 「정확성 검증」이었고 두 영상 다 본문에서 안 짚었다. **우리는 파트 1에서 통째로 답한다** — 이 세트에서 우리만 갖는 자리다
  - **순차 공개(층을 하나씩 여닫기)**: 파트 2·3·4가 이 리듬으로 굴러간다. 칸 하나가 끝날 때마다 다음 칸으로 넘기는 짧은 궁금증을 남긴다
