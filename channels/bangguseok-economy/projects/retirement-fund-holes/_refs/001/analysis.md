# 레퍼런스 분석 — "노후자금 구멍 5개, 당신은 이미 2개 뚫려 있습니다" (야무진 경제학, 103,452회)

> 역할: 🥇 **주 레퍼** — 채널 중앙값(12,108회)의 **8.5배**. 이번 대본이 계승할 1순위 골격.

## 1. 주제 요약

노후자금이 사라지는 건 시장 변동(파도)이 아니라 원금집착·몰빵·수익률착시·세금·따라하기라는 5개의 구조적 구멍(선체 결함) 때문이며, 시청자 대부분이 이미 최소 2개는 뚫려 있다는 것을 자가진단시키는 영상.

## 2. 썸네일 & 제목 분석

**★ 썸네일 텍스트 추출**

| # | 텍스트 (원문 그대로) | 글자수 | 크기/색상/위치 | 확신도 |
|---|---|---|---|---|
| 1 | `"노후 망하는 사람"` | 9자 | 최대 폰트, 흰색+검정 아웃라인, 하단 상단부(첫 줄) | 확실 |
| 2 | `전부 이러고 있습니다` | 10자 | 최대 폰트, 노란색+검정 아웃라인, 하단(두번째 줄) | 확실 |

- 제목("노후자금 구멍 5개, 당신은 이미 2개 뚫려 있습니다")과 썸네일 텍스트가 **다르다.** 썸네일은 "망하는 사람" 프레이밍, 제목은 "구멍 5개/2개 뚫림" 프레이밍 — 두 카피가 서로 다른 각도로 동일 공포를 이중 타격한다.

**썸네일 비주얼 분석**

| 항목 | 분석 |
|---|---|
| 구도 패턴 | 균열·붕괴형 (다수의 구멍에서 물이 뿜어져 나오는 침몰선) + 인물 경고 포즈 결합 |
| 핵심 오브젝트 | 여러 구멍에서 물줄기가 새어나오는 녹슨 화물선(침몰 중), 정장 입은 노란 계란형 캐릭터가 검지를 세우고 경고하는 포즈 |
| 색채 | 배경: 붉은/주황(화염+노을), 포인트: 노란색(텍스트 2줄+캐릭터), 브랜드컬러: 노란 얼굴 캐릭터(채널 마스코트로 추정) |
| 인물 | 애니메이션 캐릭터, 표정은 진지·경고(눈썹 치켜뜨고 안경 너머 응시, 검지 세움), 시선은 정면 |
| 텍스트 공간 | 화면 하단 전체 폭, 약 40% 차지, 2줄 계층형(흰색 인용구 위 / 노란색 결론 아래) |
| 시각 장치 | 선체 다수 구멍에서 물 뿜어나오는 펀칭 연출, 검은 연기 기둥, 화염, 침몰 각도 |
| 감정 | 경고/불안 |

- 텍스트 레이아웃 요약: 총 2개 텍스트 블록, 계층형 배치(인용구 → 결론 문구)

**제목 분석**
- 전문: "노후자금 구멍 5개, 당신은 이미 2개 뚫려 있습니다"
- 핵심 장치: 숫자(5개/2개) 대비, 2인칭 직격("당신은"), 현재완료형 손실 확정("이미 뚫려 있습니다" — 미래 경고가 아니라 과거에 이미 벌어진 일로 기정사실화)
- **제목 첫머리 분석**: 첫 3~4어절 "노후자금 구멍 5개"가 곧바로 시청자 지갑의 실물(노후자금)로 진입한다. 국가·기업·시장 등 배경 설명 없이 제목 첫 단어부터 "당신 돈" 얘기다.

**썸네일-제목 조합이 만드는 기대감**
"이 영상을 클릭하면 내 노후자금에 이미 뚫려 있는 구멍이 무엇인지, 나는 몇 개나 뚫렸는지 알 수 있을 것 같다"

## 3. 훅 & 인트로 분석

**훅**: "1억 원을 은행 전기예금에 넣으면 한 달에 손해 주는 이자가 얼마인지 아십니까? 21만7,000원입니다. 부부 두 분이 삼겹살 한번 드시고 손주 용돈 한 번 주면 그냥 사라지는 돈이에요."
- 숫자형+공감형 결합. 추상적 "이자 손실"을 즉시 생활 단위(외식 한 끼+용돈)로 환산해 시청자 본인 얘기로 체감시킨다.
- 효과적인 이유: 질문("아십니까?")으로 참여시킨 뒤 바로 구체 숫자로 답하는 구조라 이탈할 틈이 없다.

**인트로**: "노후자금을 배 한 척이라고 생각해 보십시오... 노후자금이라는 배를 침몰시키는 건 파도가 아니에요. 선체에 난 구멍입니다. (…) 대부분이 최소 두 개는 이미 뚫려 있는 구멍입니다."
- 제목의 약속(구멍5개/2개뚫림)을 즉시 재확인하며 비유로 시각화. "15분은 남는 장사"라는 시간투자 정당화, 구독 요청을 미리 처리해 뒤에서 흐름을 끊지 않음.
- 강한 인트로: "오늘의 결론은 이 한 문장" 식으로 결론을 예고만 하고 회수는 뒤로 미뤄 오픈루프를 심는다.

## 4. 본문 구조 분석

**전체 구조 요약**: 원금보장 집착(구멍1) → 몰빵(구멍2) → 수익률 착시(구멍3) → 세금(구멍4) → 남 따라하기(구멍5)
- 배치 패턴: 앞의 3개는 "시장이 만든 구멍"(통제 어려움) → 4번째는 "시장과 무관한 확정된 구멍"(즉시 통제 가능, 안도감 제공) → 5번째는 "앞의 4개를 전부 다시 뚫는 메타 구멍"(태도 문제로 좁혀지는 반전). 통제불가→통제가능→메타경고 순으로 긴장을 재설계한다.

**전달 기법**
- 스토리텔링: "배" 비유를 도입~클로징까지 일관되게 회수(갑판에서 물 퍼내기 vs 아래로 내려가 구멍 막기)
- 데이터: 구체 금리(3.08%), 세율(15.4%, 16.5%), 금액(1억→10년 후 9,438만원, 900만원 납입시 148만5천원 공제)
- 수학 반전: "-50%+50%=평균0%"인데 실제로는 -25%(1억→7,500만원), 몰빵 70%가 반토막나면 회복에 53.8% 필요

**리텐션 장치**
- 전환(초반): "여기 한 겹이 더 있습니다" — 구멍1→2, 더 나쁜 얘기가 남았다는 예고
- 전환(중반): "여기서 각도를 한번 틀어 보겠습니다" — 구멍2→3
- 오픈루프(중반): "지금까지 세 개는 시장이 만든 구멍이었는데요. 네 번째는 시장과 아무 상관없이... 가장 확실하게 막을 수 있는 구멍" — 구간 성격이 바뀐다는 예고로 중반 이탈 방지
- 서스펜스(구멍4 내부): "그런데 여기가 진짜 무서운 대목이에요" — 중도해지 시 세액공제 전액 반납 경고
- 반전 예고(후반, 최강 오픈루프): "그런데 마지막 다섯 번째가 나머지 네 개를 전부 다시 뚫어 버리는 구멍이에요" — 이미 배운 4개가 무효화될 수 있다는 위기감으로 끝까지 보게 만듦

## 5. 감정 트리거

- 불안: 도입부 손실액("21만7,000원", "562만 원이 조용히 증발")
- 자각의 찔림(자책 아닌): "이거 들으시면 어떤 분들은 벌써 기분이 상하실 거예요" — 직접 지목하되 곧바로 "100번 맞는 말씀"이라 존중하며 방어를 낮춤
- 안도/통제감: 구멍4(세금)에서 "수익률은 예측이지만 이건 계산입니다" — 확정적으로 막을 수 있다는 안도
- 흐름: 불안(도입)→경각심 심화(구멍1~3)→안도(구멍4)→재긴장(구멍5 반전)→행동 CTA로 해소(엔딩)

## 6. 댓글 반응 분석

**시청자가 가장 강하게 반응한 포인트**
- "퇴직금 주식투자했다가 날렸다, 예금이 제일이다"(34), "있는 돈 지키는 게 최고"(11) — 구멍1(원금보장 집착) 메시지에 공감하면서도 일부는 "그래도 예금이 낫다"는 반론성 반응, 완전히 설득되지 않은 지점
- "21만원이 어디냐"(4) — 훅의 손실액 숫자에 직접 반응

**시청자 포지션**: 이미 은퇴했거나 은퇴를 앞둔 실전 투자 경험자(퇴직금 손실 경험담), 안정성을 최우선으로 여기는 시니어

**우리 영상에서 반드시 다뤄야 할 포인트**
- "그래도 예금이 안전하지 않냐"는 반박을 미리 방어하는 문장 필요 (구멍1 설명 시 "원금 지키는 게 왜 문제냐" 선반박 구조를 그대로 계승할 가치 있음)
- 손실 경험담류(퇴직금 날린 사례) 같은 공감 요소를 도입부에 반영하면 초반 이탈 방지에 유리

## 7. 핵심 약속 역추적

**제목+썸네일이 약속한 것**: 내 노후자금에 이미 뚫려 있는 구멍이 몇 개인지, 무엇인지 알게 될 것 같다
**인트로에서 확인해준 것**: "대부분이 최소 두 개는 이미 뚫려 있는 구멍입니다" — 제목의 "이미 2개 뚫려있다"를 그대로 재확인, 배 비유로 구체화
**본문이 실제로 전달한 것**: 5개 구멍 각각의 구조와 구체 금액, 그중 세금은 즉시 실행 가능한 해결책(연금저축·IRP 한도 확인)까지 제공
**약속 이행 평가**: 이행. 오버딜리버리 — 단순 나열을 넘어 "다섯 번째가 나머지를 다시 뚫는다"는 반전 구조로 기대 이상의 통찰 제공
