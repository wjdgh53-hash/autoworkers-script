## 3. 🔴 격차 ① — 숫자 밀도가 벤치의 1/3이다

```
경제해적단 히트   10.5 ~ 21.6   (1천자당 숫자 표현 수)
야무진 히트       15.6
─────────────────────────────
우리              3.9 ~ 5.7     ← 1/3 ~ 1/4
```

**원 단위 금액 등장 횟수**로 보면 더 벌어진다 — 경제해적단 209k편은 **73회**, 우리 08-16은 **14회**다.

### 벤치가 숫자를 쓰는 법 — 「같은 사실을 세 번 숫자로 다시 말한다」

> [289k편] "수익도 똑같이 **1억 원**이 났어요. 그런데 세금하고 건강보험료까지 계산해 보니까 한 사람은 **970만 원**을 냈고 한 사람은 **3,700만 원**을 냈습니다. **세 배**가 넘습니다."

한 문단에 금액 3개 + 배수 1개다. **주장 → 금액 → 대비 금액 → 배수** 4단으로 같은 말을 반복한다.

> [야무진 104k편] "한 달에 손에 쥐는 이자가 얼마인지 아십니까? **21만 7,000원**입니다. 부부 두 분이 삼겹살 한번 드시고 손주 용돈 한 번 주면 그냥 사라지는 돈이에요."

**숫자 → 생활 환산**을 붙인다. 21만 7,000원을 「삼겹살 + 손주 용돈」으로 번역한다.

### ⚠️ 다만 숫자만 늘리면 안 된다 — 실패작이 그 증거다

경제해적단 [2,179회 실패작](https://www.youtube.com/watch?v=rHKJbvIGft8)은 숫자 밀도 **14.1**로 히트 수준인데 죽었다.
**숫자는 필요조건이지 충분조건이 아니다.** 소재(레버리지 ETF = 소수)와 오프닝(§4)이 먼저다.

### 처방

- **DRAFT 게이트에 「숫자 밀도 1천자당 10 이상」을 넣는다.** 현재 게이트는 「숫자 밀도 8.7」처럼 다른 척도를 쓰고 있어 이 지표와 대조가 안 된다
- 숫자를 넣을 때 **세트로 넣는다**: `주장 → 금액 → 대비 금액 → 배수 → 생활 환산`
- ⛔ 통계 나열이 아니다. **한 사실을 여러 각도의 숫자로 다시 말하는 것**이다

## 4. 🔴 격차 ② — 오프닝 첫 문장이 「선언」이다. 히트는 「당신 경험 확인 질문」이다

**경제해적단 안에서 히트와 실패가 여기서 갈렸다.**

| | 첫 문장 | 형식 |
|---|---|---|
| ⭕ [289k](https://www.youtube.com/watch?v=JREdVuRBv9U) | "S&P500 사 보려고 검색해 **보신 적 있으시죠?**" | **질문** |
| ⭕ [209k](https://www.youtube.com/watch?v=PEnNxbBd5eY) | "매달 30만 원씩 넣고 계신 분들 계좌 열어봤다가 그냥 조용히 닫은 **적 있으시죠?**" | **질문** |
| ⭕ [야무진 104k](https://www.youtube.com/watch?v=LjHlXKeRH5s) | "1억 원을 은행 정기예금에 넣으면 한 달에 손에 쥐는 이자가 얼마인지 **아십니까?** — 21만 7,000원입니다." | **질문 + 즉답 숫자** |
| ⛔ [3,763회](https://www.youtube.com/watch?v=I3-Up8QGbcU) | "**부자들은** 차트를 쳐다보지도 않습니다." | 선언 · **주어가 남** |
| ⛔ [2,179회](https://www.youtube.com/watch?v=rHKJbvIGft8) | "주가는 올랐습니다. 그런데 계좌는 팔았습니다." | 선언 |
| **우리 08-18** | "한 달도 거르지 않고 **부으셨을 겁니다.**" | **선언(추정)** |
| **우리 08-16** | "여러분 통장에 든 돈은 앞으로도 그대로 **있을 겁니다.**" | **선언** |

**우리 둘 다 「~일 겁니다」로 시작한다. 이건 내가 시청자 상태를 단정하는 문장이다.**
히트는 **시청자에게 물어서 스스로 떠올리게 한다.** 「~하신 적 있으시죠?」는 답하는 순간 이미 몰입한 것이다.

### 벤치 오프닝 5단 공식 (경제해적단 히트 2편 공통)

```
① 당신 경험 확인 질문      "~해 보신 적 있으시죠?"
② 그때 든 생각을 대신 말해줌  "아무거나 사도 되겠지, 이렇게 생각하셨다면"
③ 두 사람 대비 + 금액       "같은 걸 산 두 사람... 970만원 vs 3,700만원"
④ 변수 하나로 좁힘          "딱 한 가지가 달랐습니다"
⑤ 자기진단 약속 + 진입비용   "여러분 계좌가 어느 쪽인지 알려드립니다. 확인하는데 10초면 됩니다"
```

우리는 **⑤만 갖고 있다.** ①②③④가 비어 있다.

> 🔴 **③의 「두 사람 대비」는 [thumbnail-design.md](../thumbnail-design.md) §3-A의 좌우 대비 구도와 같은 구조다.**
> 경제해적단 최고작은 **썸네일(족쇄 vs 황금길)과 오프닝(970만 vs 3,700만)이 한 몸**이다. 우리는 썸네일과 대본이 따로 논다.

## 8-1. 🔴 숫자 밀도 — **히트와 실패를 가르지 못한다.** 3절의 결론을 약화한다

```
히트   23.3 ~ 32.8   (해설형 4편)
실패   20.8 ~ 30.0   ← 완전히 겹친다
우리    7.0 ~  8.7
```

**밀도를 올리면 성적이 오른다는 증거는 없다.** 우리 최고작 [08-16](https://www.youtube.com/watch?v=TxSTmhN8PaQ)(26.6배)이 7.0이고, 실패작 [08-18](https://www.youtube.com/watch?v=33l7widZdTs)이 **더 높은** 8.7이다.

**다만 확실한 사실이 하나 있다** — 우리는 **벤치 7편 중 어느 편보다도 낮다.** 그래서 하한만 12.0(벤치 최저 12.2 바로 아래)으로 두고 **WARN**으로 처리한다. 차단하지 않는다.

### 🚨 더 중요한 것 — 기존 게이트가 벤치 히트를 전부 차단하고 있었다

`check_tone.py`의 숫자 밀도 **상한 10.0은 치명적 FAIL**이었다. 위 표의 **벤치 7편이 전부 이 상한을 넘는다.**
그 상한의 근거는 모듈 주석에 적혀 있다 — *"우리는 시니어 타겟이고 203k 히트작이 4.6이다"*. **탐정경제학 계열의 근거**다.
→ 방구석 전용 밴드로 **상한 34.0 / 하한 12.0** 재정의(2026-08-19). 탐정경제학은 기존 4.0~10.0 유지.

## 8-2. ⭕ 2인칭 — 이게 가장 깨끗하게 갈린다

```
히트   1.0 ~ 2.4
실패   0.6 ~ 1.3
우리   0.3 ~ 0.9   ← 둘 다 실패 구간
```

**하한 1.2**를 방구석 전용 밴드에 넣었다. ⛔ 상한은 두지 않는다 — 근거가 없다.
