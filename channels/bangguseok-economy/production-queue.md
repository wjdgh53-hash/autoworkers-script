# 제작 대기열 — 방구석 경제

> 최초 작성 2026-08-16
> **소재를 뉴스에서 찾지 않는다.** 결이 같은 채널([config/_benchmarks/channels.md](config/_benchmarks/channels.md))의 **검증된 히트작 중 우리가 아직 안 만든 것**을 역추출한다. 그러면 검증된 레퍼가 처음부터 붙어 온다. 뉴스는 그 소재를 최신화하는 데만 쓴다.
>
> 🔗 모든 항목에 원본 레퍼 링크를 병기한다. 배율 숫자만으로는 판단을 검증할 수 없다.
>
> 🔴 **1~6번은 전부 축 A다. 중간에 축 B·C·D를 끼우지 않는다.** 알고리즘 재학습이 어긋난다([direction.md](direction.md) 9절).
> 🔴 **순서를 바꾸려면 사용자에게 먼저 확인한다.** 임의로 재정렬하지 않는다.

## ⚡ 이 파일을 꺼내 쓰는 법

| 사용자가 말하면 | 무슨 일이 벌어지나 | 걸리는 시간 |
|---|---|---|
| **「다음」이 들어간 제작 요청** — "다음 거 / 다음 대본 / 다음 편 / 다음 소재로 / 그다음 거 / 순서대로 다음 거 / 대기열 다음 거" | `channel-trend-pd` **Phase 0-A 빠른 경로** — 아래 `미제작` 1순위를 꺼내 **배율만 재확인**하고 곧장 `script-pd` 인계 | 5분 |
| "소재 추천해줘" / "오늘 뭐 올리지" | `channel-trend-pd` **전체 스캔** — Phase 1~4.5 전부 | 반나절 |
| "이어서 해줘" / "계속해줘" | `script-pd` — **하던 프로젝트 재개.** 대기열과 무관하다 | — |

> 🚨 **대기열은 채널마다 따로 있다.** 「다음」 요청이 왔는데 채널이 명시되지 않았으면
> **양쪽 대기열의 다음 순번을 나란히 보여주며 어느 채널인지 묻고 답을 기다린다.** 기본값으로 밀지 않는다.
> 현재 대기열: `channels/detective-economy/` · `channels/bangguseok-economy/`
>
> 🔴 **이 채널은 축 잠금이 걸려 있다.** 빠른 경로로 항목을 꺼낼 때도 아래 **공통 체크리스트와 축 A 유지 규칙을 먼저 읽고 따른다.** 순서를 건너뛰어 다른 축을 끼우면 알고리즘 재학습이 어긋난다.

절차 원본은 `.claude/skills/channel-trend-pd/SKILL.md` Phase 0-A다.

## 공통 체크리스트 (착수 전 매번 확인)

- [ ] 제목 **첫머리**가 시청자 지갑의 실물(돈·저축·집·계좌·노후자금·금액)인가 — "나라·정부·경제"로 시작하면 죽는다
- [ ] 주어가 시청자 본인인가 — 국가·기업은 배경으로만
- [ ] 길이 16~20분 (22분 초과 금지)
- [ ] 레퍼 고유 표현·비유를 복제하지 않았는가 — 골격만 계승, 문장은 새로 창작
  ⚠️ **이 금지는 「대본 본문」에만 적용된다.** 제목·썸네일 텍스트는 `prompts/creative-strategy.md`의 「🔓 제목·썸네일 텍스트의 어휘 제약」이 유일한 원본이며, 2026-08-16부터 **100% 그대로 베끼기만 금지**다(단일 명사·감정어·수식어·장르 관용어는 마음껏 쓴다). 모든 채널 공통.
