**공통 패턴:**
- 3개 영상 모두 **"지금 이 순간"의 전쟁 상황**에서 시작. 과거 역사부터 시작한 영상은 없음.
- 훅 직후 반드시 **"왜?"라는 질문 또는 인지 불일치**가 배치됨.
- 001과 003은 "현재 상황 → 의문"으로, 002는 "얻게 될 보상 약속"으로 진입하지만, 둘 다 결국 **"이 영상을 끝까지 봐야 할 이유"를 5초 안에 심는다**는 점에서 동일.

**인트로(훅 직후)의 공통 장치:**
- 001: "더 이상한 건 따로 있어요. 이 두 나라 사실 친구였습니다."
- 002: "남북한 관계조차 이들과 비교하면 상대적으로 온건해 보일 정도입니다."
- 003: "더 충격적인 건요. 이 두 나라가 한때 형제보다 가까운 사이였다는 겁니다."

3개 중 2개(001, 003)가 **"한때 친구/형제였다"는 반전 예고**를 인트로에서 던짐. 이것이 첫 번째 오픈루프 역할.

### 설계 원칙

- [ ] 훅은 **현재 진행 중인 전쟁/뉴스 장면**으로 시작한다. 역사부터 시작하지 않는다.
- [ ] 훅 5초 안에 **"왜?"** 또는 **"이상하지 않으세요?"** 형태의 인지 불일치를 심는다.
- [ ] 인트로(훅 직후)에서 **"이 두 나라는 한때 친구였다"는 반전 예고**를 던져 첫 번째 오픈루프를 건다.
- [ ] 인트로 마무리에 **"그게 어쩌다 이렇게 됐을까요?"** 식의 본문 진입 명분을 만든다.

| "민주당이 일본을 적으로 규정하는 이유도 이와 동일합니다" (003) | 20 | 지적 쾌감 + 현실 대입 | "적대적 공생" 개념 해설 |

**3개 영상 공통 감정 흐름:**

```
궁금증(훅) → 놀라움/충격(한때 친구였다) → 흥미(동맹의 깊이)
→ 소름/황당함(혁명 + 비밀 무기 거래) → 냉소적 쾌감(국제정치의 민낯)
→ 분노 또는 공포(현재 상황) → 지적 쾌감(구조적 인사이트 정리)
```

이 흐름에서 **시청자 반응이 가장 폭발한 지점은 "냉소적 쾌감"과 "현실 대입 분노"**. 단순한 역사 전달이 아니라 "나는 이제 진실을 안다"는 우월감과 "이건 우리나라 이야기이기도 하다"는 연결 감정이 핵심.

**감정을 만드는 3대 장치:**
1. **역설적 사실 폭로**: "적에게 무기를 팔았다" — 3개 영상 모두 이 포인트를 별도 강조
2. **한 줄 정리**: "영원한 적도 친구도 없다. 이해관계만 있을 뿐"(001) / "적대적 공생"(003) — 복잡한 역사를 한 문장으로 압축해 시청자가 인용·공유 가능하게 만듦
3. **현실 대입 유도**: 직접 한국 정치를 언급하지 않아도 시청자가 스스로 연결. "지도자 한 명이 나라를 망친다"는 서사가 한국적 감정과 자동 연결됨.

### 설계 원칙

- [ ] 감정 흐름을 **궁금 → 충격 → 소름 → 냉소적 쾌감 → 분노/공포 → 지적 쾌감** 순서로 설계한다.
- [ ] **"겉으로는 X, 뒤로는 Y" 구조의 폭로 문장**을 반드시 포함한다. 시청자가 직접 인용하고 싶어하는 포맷.
- [ ] 마무리에 **한 줄로 압축되는 인사이트**(예: "영원한 적도 친구도 없다")를 배치한다. 댓글·공유 트리거.
- [ ] 지도자 한 명의 결정이 수천만 명의 삶을 바꾸는 서사를 통해 **"서민 관점"의 분노/공감**을 자연스럽게 유도한다.
- [ ] 한국 정치를 직접 언급하지 않되, 시청자가 **스스로 현실에 대입**할 수 있는 보편적 프레임("지도자의 선택", "이해관계의 배신")으로 서술한다.

| 영상 | 썸네일 역할 | 제목 역할 |
|------|------------|-----------|
| 001 | "누가 박살냈나"(범인 지목) | "진짜 이유를 알려준다"(보상 약속) |
| 002 | "이렇게 먼데?"(시각적 의문) | "왜 원수가 됐나?"(질문 명시) |
| 003 | "전쟁의 진짜 이유는 '이것'"(빈칸) | "우리가 아는 건 틀렸다"(기존 지식 부정) |

**분담 공식:** 썸네일이 **감정적 궁금증**(시각+텍스트)을 걸고, 제목이 **지적 보상 약속**(언어)을 건다. 둘이 같은 말을 반복하지 않고 보완 관계.

### 설계 원칙

- [ ] **썸네일 메인 텍스트는 12~14자** 이내로 제한한다.
- [ ] 썸네일에 **"진짜 이유" 또는 빈칸 효과('이것')** 형태의 궁금증 장치를 넣는다.
- [ ] 썸네일 비주얼은 **핵심 인물(호메이니) + 충돌/긴장 색채(빨강, 화염)**를 활용한다.
- [ ] 텍스트 전용 공간과 비주얼 공간을 **명확히 분리**한다 (좌우 분할 또는 상하 분할).
- [ ] 제목 앞쪽에 **"이란 이스라엘"** 검색 키워드를 배치한다.
- [ ] 제목에 **숫자, 역설, 또는 기존 상식 부정** 장치 중 하나를 사용한다.
- [ ] 썸네일은 **감정적 궁금증**(범인 지목, 시각적 의문), 제목은 **지적 보상 약속**("진짜 이유", "틀렸습니다")으로 역할을 분담한다. 같은 말을 반복하지 않는다.
