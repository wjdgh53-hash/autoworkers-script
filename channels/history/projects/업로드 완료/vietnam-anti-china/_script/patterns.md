**공통 훅 패턴** (4/4 영상):
1. **한국 시청자의 반중 감정을 진입점으로 활용** — 002·003·004는 한국의 반중 정서를 먼저 호명하고, 005는 "같은 이념인데 왜?"라는 역설로 진입. 모두 시청자가 이미 가진 감정/상식을 건드리는 것으로 시작.
2. **"더 심한 나라가 있다"는 서열 비교로 궁금증 전환** — 002: "둘째가라면 서러워할 반중국가가 또 있습니다", 003: "한국만만 창계 중국을 싫어하는 나라가 있습니다", 004: "한국만큼이나 반중 정서가 심한 아시아 국가가 또 존재하죠". 3/4 영상에서 동일한 전환 구조.
3. **수치로 감정을 객관화** — 002: "81%", 003: "88%, 92%", 004: "56개국 중 1위". 3/4 영상에서 여론조사 수치를 즉시 배치.

**인트로 공통 역할** (3/4 영상):
- "수천 년"/"아주 먼 옛날"이라는 시간 스케일을 예고하여, 장대한 서사가 펼쳐질 것이라는 기대치 설정 → 이탈 억제. (002: "역사 자체가 중국으로부터 살아남기입니다 이게 수천 년간입니다", 004: "고대로 거슬러 올라가야 합니다", 005: "아주 먼 옛날부터 거슬러 올라가야 합니다")

**시청자 관심 방향 요약**: 시청자는 자신이 이미 가진 반중 감정을 역사적으로 정당화해줄 서사를 원하며, 동시에 "나보다 더 심한 나라"의 이야기를 통해 자신의 감정을 대리 해소하고 싶어 한다.

### 설계 원칙

**훅 소재 풀** (포텐셜 상위 5개, 시청자 관심 방향 부합 순):

1. **"28년 혈맹이 하루아침에 전쟁"** — 공산 동맹의 배신. "같은 편인데 왜 싸워?"라는 역설이 시청자의 "말도 안 돼" 반응을 가장 강하게 유발.
2. **"60만 대군을 보냈는데 한 달 만에 철수"** — 약소국의 승리. 통쾌함 + 궁금증("어떻게?") 동시 자극.
3. **"세계 1위 반중(88%)인데 수입의 3분의 1이 중국산"** — 감정과 경제의 모순. 채널 컨셉("숨겨진 진짜 이유")과 직결.
4. **"반미 전쟁 함께 치른 혈맹의 젊은 세대가 친미 반중"** — 세대 역전의 아이러니.
5. **"도와줬던 나라의 영토를 혼란 틈타 무력 점령"** — 배신의 구체적 장면.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 — 공통 서사 흐름** (4/4 영상):

모든 레퍼런스가 동일한 대구조를 공유한다:

```
고대 지배(~1000년) → 독립·저항 반복 → 근현대 공산 밀월 → 배신(중월전쟁) → 현재 남중국해 갈등 → 경제적 딜레마
```

세부 차이는 있으나, 핵심 서사 뼈대는 **"지배 → 저항 → 동맹 → 배신 → 현재 위기"**로 수렴한다.

- 002: 역사 누적 → 반전(동맹→배신) → 현재 위기 → 생존 전략
- 003: 역설 제시 → 역사 소급 → 경제 아이러니
- 004: 역설 제시 → 역사 소급 → 현재 갈등 → 구조적 결론
- 005: 시간순 + 배신 반복 사이클

**공통 패턴**: 시간순 전개를 기본으로 하되, **후반부에 "그래서 지금은?"이라는 현재성 전환**을 반드시 배치. 단순 역사 나열이 아니라 "왜 지금도 싸우는가"라는 질문에 수렴하는 인과형 구조.

**개별 전략**: 002만 지정학적 생존 전략(손자병법, 미국 활용)까지 확장. 나머지는 현재 갈등에서 마무리.

**전달 기법 — 공통 패턴**:

*비유*:
- **역사적 고사/비유를 현대 독자의 언어로 번역** (공통 패턴, 3/4 영상): 002: "남만은 남쪽에 있는 오랑캐라는 뜻입니다 우리를 동이라고 부른 것과 같은 거죠", 004: "조공 질서를 연상시킨다는 지적", "소련의 위성국 같은 느낌". 추상적 외교 개념을 시청자가 체감할 수 있는 비교로 전환.

*숫자*:
- **대비 쌍으로 스케일 체감** (공통 패턴, 4/4 영상): 002: "60만 병력 vs 예비 병력도 당해내지 못하고", 003: "39만 대 20만", 005: "28년간 지원 → 모조리 중단". 숫자를 단독으로 던지지 않고, 반드시 대비 대상과 쌍으로 제시.
- **여론조사 수치를 신뢰 장치로 활용** (공통 패턴, 3/4): "81%", "88%", "92%", "56개국 중 1위" — 감정적 주장을 객관적 데이터로 먼저 뒷받침.

*사례*:
- **특정 인물+연도로 사건화** (공통 패턴, 4/4): 002의 쯩 자매·레로이, 003의 호치민·닉슨 방중, 004의 레러이·호치민, 005의 덩샤오핑. 연도와 인물명을 콕 집어 역사를 서사화.

**리텐션 장치 — 공통 배치 패턴**:

| 위치 | 장치 | 빈도 | 대표 인용 |
|------|------|------|----------|
| 초반 | 오픈루프 (본문 진입 직전 질문) | 4/4 | 002: "어떻게 된 일일까요", 003: "지금부터 그 이유를 살펴보겠습니다", 005: "어째서 앙숙 관계가 된 것일까" |
| 중반 | 패턴 인터럽트 ("여기까지 보면 좋아 보이는데...") | 3/4 | 003: "여기까지만 보면 베트남이 중국을 싫어할 이유는 없어 보입니다", 004: "같은 체제인데 문제는 다 해결된 것 같은데" |
| 중반→후반 | 반전 브릿지 (안도감 직후 뒤집기) | 3/4 | 005: "모든 갈등을 마무리 짓고 밝은 미래를 향해 나아가는 것 같았으니까 **그러나**" |

**공통 패턴**: 중반에 "공산 동맹 시기"를 다룰 때 **의도적으로 "관계 좋아 보이는" 구간을 만들고 즉시 뒤집는다**. 시청자가 "어? 그러면 왜 싫어하지?"라고 의문을 갖게 만든 뒤 배신 파트로 전환하는 구조가 3/4 영상에서 반복.

### 설계 원칙

**본론 뼈대**:
1. 고대 천년 지배 → 저항 영웅 에피소드 (분노 축적 + 통쾌함)
2. 공산 동맹기 → "여기까진 좋아 보인다"는 안도감 의도적 배치
3. 배신 (중월전쟁) → 안도감 즉시 뒤집기 (감정 낙차 극대화)
4. 현재 남중국해 + 경제 딜레마 → "지금 우리에게 어떤 의미인가"

**전달 기법 규칙**:
- 비유는 외교·군사 개념이 나올 때마다 한국 시청자가 체감할 수 있는 비교로 즉시 번역할 것
- 숫자는 반드시 대비 쌍으로 제시 (병력 수 vs 결과, 원조 금액 vs 배신 시점, 반중 비율 vs 경제 의존도)
- 사례는 "인물명 + 연도 + 구체적 행동"의 3요소를 갖출 것

**리텐션 장치 배치 규칙**:
- 본문 진입 직전: 오픈루프 질문으로 "답을 알아야 한다"는 당위 설치
- 공산 동맹 파트 직후: "여기까지 보면 사이좋아 보이죠?" 패턴 인터럽트 → 즉시 배신 파트로 반전
- 파트 전환 직전마다: 다음 파트의 핵심 충격 포인트를 한 줄로 예고 (오픈루프)

### 관찰

| 감정 | 대표 댓글 | 좋아요 | 영상 |

| 반중 공감/분노 | "답은 간단 사람이라면 중국을 좋아할 수가 없거든" | 848 | 003 |

**감정 순위**: 1위 반중 분노/공감 (압도적), 2위 자국 상황 투영, 3위 경각심(경제 의존 아이러니)

가장 좋아요가 많은 두 댓글(1,600개, 848개) 모두 **반중 분노의 보편화**("중국이라서 그렇다")에 집중. 시청자는 베트남 이야기를 자신의 반중 감정을 정당화하는 도구로 소비하고 있다.

**감정을 만든 장치 역추적**:

*분노 (가장 뜨거운 감정)*:
- 003: "믿었던 형님 중국이 갑자기 미국과 친해졌던 것입니다" — 배신 장면의 의인화
- 005: "1950년부터 1978년까지 28년간 이어진 인도적 지원을 모조리 중단" — 구체적 기간+전면 중단의 대비
- 004: "베트남의 혼란을 틈타 무력으로 불법적으로 점령" — "혼란을 틈타"라는 비겁함 강조
- 공통: **중국의 배신 행위를 구체적 장면으로 묘사**할 때 분노가 가장 강하게 발생

*통쾌함 (2위 감정)*:
- 002: "60만 병력으로 침공했습니다. 하지만 베트남의 예비 병력도 당해내지 못하고 겨우 한 달 만에 별 소득 없이 물러났습니다" — 다윗 vs 골리앗의 역전
- 003: "중국은 전쟁에 무려 39만 대병력을 투입했고... 명확한 승자는 없이" — 압도적 병력으로도 이기지 못한 굴욕

*경각심 (마무리 감정)*:
- 002: "가장 폭이 짧은 곳은 불과 50키로 ... 여기를 점령당하면 남북으로 분단" — 구체적 지리 수치로 위협 실감
- 003: "수입품 중 33.9% 중국산 ... 어느 날 뭔 짓을 할지 모르니까" — 일상과 연결된 공포

**감정 흐름 — 공통 패턴** (4/4 영상):

```
공감(훅) → 분노 축적(역사적 지배·배신) → 통쾌함(저항·승리) → 경각심(현재 위기·딜레마)
```

002·003·004·005 모두 이 흐름을 따른다. 차이점은 통쾌함과 경각심의 비중인데, 조회수 1위인 003이 분노→통쾌함 구간을 가장 길게 배치했다.

### 설계 원칙

**감정 설계 가이드**:

```
공감(초반 10%) → 분노 축적(20%) → 통쾌함(30%) → 배신 분노 폭발(20%) → 경각심(20%)
```

- **분노를 먼저 충분히 쌓아야 통쾌함이 폭발한다**: 천년 지배의 구체적 착취 장면(인물+연도+행위)을 최소 3건 이상 나열한 뒤 저항 영웅 에피소드로 전환
- **통쾌함은 "숫자 대비"로 극대화**: "60만 vs 예비병력", "39만 대군 vs 3주 철수" 같은 병력 수치 대비를 반드시 포함
- **배신 파트에서 분노를 한 번 더 폭발시킨다**: 공산 동맹기의 원조 금액·기간을 구체적으로 쌓은 뒤 "하루아침에 전면 중단"으로 낙차를 만들 것
- **경각심은 한국과의 연결로 마무리**: 댓글이 자발적으로 한국 상황을 투영하고 있으므로(002 1위·003 7위 댓글), 우리 영상에서는 마무리에 한국-베트남 유사성을 명시적으로 짚어 감정 회수

### 설계 원칙

**썸네일 텍스트 설계 원칙**:

- 계층형 배치 (상단 소형 보조 → 하단 대형 핵심)
- 반드시 "왜?" 또는 질문형 요소 1개 포함
- 반중 키워드 1개 이상 포함 ("반중", "혐오", "앙숙" 등)
- 역설/대비 구조를 텍스트에 녹일 것 ("같은 공산국가인데", "혈맹이 앙숙으로" 등)

**제목 설계 원칙**:
- "왜"를 포함한 질문형 구조 필수
- 역설적 전제를 제목 안에 삽입 ("같은 OO인데", "혈맹이었던" 등)
- 30자 내외 (003: 25자, 002: 24자, 005: 18자, 004: 30자)

**역할 분담 공식**:
- 썸네일: **감정 + 시각적 갈등** (클릭 욕구 자극)
- 제목: **정보 + 역설 전제 + 질문** (클릭 정당화)
- 썸네일과 제목이 같은 정보를 반복하지 않도록 할 것

**썸네일 비주얼 원칙**:
- A vs B 좌우 분할 구도 (대립 메시지를 글자 없이 전달)
- 빨강+노랑 색채 (중국·베트남 국기색 활용, 모바일에서도 시선 집중)
- 핵심 오브젝트: 양국 상징물(국기, 지도자, 군인) 중 최소 2개 대치 배치
- 텍스트 공간: 전체 면적의 30~35%
