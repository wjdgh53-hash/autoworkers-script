# 공통 성공 패턴 & 설계 원칙

레퍼런스 4개 교차 비교 결과. 영상 번호: 002(지식 브런치, 144만), 003(별별역사, 460만), 004(당신이 몰랐던 이야기, 41만), 005(지식한잔, 67만).

## 1. 반복되는 훅 공식

### 관찰 A — 레퍼런스 훅 분석

**훅 원문 비교**:

| 영상 | 훅 원문 (첫 3~5초) | 핵심 장치 |
|------|-------------------|----------|
| 002 | "요즘 한국에서의 중국 혐오는 대단합니다. 지난해 미국의 이교전문지 디플로맷이 56개국을 대상으로 중국에 관한 인식 조사를 했습니다. 그 결과 한국은 세계에서 반중의식이 가장 높은 나라였습니다. 무려 81%가 중국에 부정적입니다." | 숫자형 + 한국 시청자 공감 |
| 003 | "중국 요즘 중국의 패권주의적 행보가 심해짐에 따라 세계 특히 중국 주변국들의 반중 감정은 매우 강화되고 있습니다. 중국의 그러한 행동의 결과 2023년 한국인이 제일 부정적으로 생각하는 나라는 중국이 되었을 정도이죠. 그런데 한국 만만 창계 중국을 싫어하는 나라가 있습니다." | 한국 시청자 공감 → 의외성 전환 |
| 004 | "여러분은 중국에 호감을 갖고 계신가요? 대부분 아니다라고 대답하실 것 같네요." | 직접 질문 + 공감 유도 |
| 005 | "동아시아는... 상호 긴밀한 관계를 잃었던 중국과 베트남... 둘다 이념을 내세우며 권위주의 통치 체제를 고수하고 과거 서구 열강의 침략을 경험한 바 있으며..." | 공통점 나열 → 역설 전환 |

**공통 훅 패턴** (4/4 영상):
1. **한국 시청자의 반중 감정을 먼저 소환** (002, 003, 004): "너도 중국 싫지?"로 시작해 공감 상태를 만든 뒤 베트남으로 피벗. 005도 공통점(같은 공산주의) 나열 후 "왜 앙숙인가?"로 전환하여 같은 구조를 취함.
2. **"그런데 한국보다 더한 나라가 있다"는 전환** (002, 003, 004): 시청자의 '나'의 이야기에서 '남(베트남)'의 이야기로 시선을 이동시키는 피벗 장치. 자기 이야기에서 시작했기 때문에 전환 후에도 관심이 유지된다.
3. **구체적 수치로 감정을 데이터화** (002, 003, 004): "81%", "88%", "56개국", "세계 1위" 등 숫자가 반드시 등장하여 감정적 주장에 객관적 권위를 부여한다.

**인트로 공통 역할** (4/4 영상):
- "왜?"라는 개방형 질문을 열어두고 닫지 않음 (오픈루프 설치)
- "수천 년", "아주 먼 옛날부터"라는 시간적 스케일로 이야기의 규모감 예고
- 역설 제시: "같은 공산국가인데", "원조까지 해줬는데" → 상식과 현실의 괴리를 명확히 대비

**시청자 관심 방향 요약**: 레퍼런스 훅들은 공통적으로 "나(한국인)도 중국 싫은데, 나보다 더 싫어하는 나라가 있다니? 그 이유가 뭐지?"라는 **자기 투영적 호기심**과 **역설에 대한 해소 욕구**를 건드린다.

### 설계 원칙

**훅 소재 풀 (포텐셜 상위 5개)**:

1. **"28년 동지가 하루아침에 침략자"**: 200억 달러 원조 + 32만 지원병을 보낸 중국이 베트남을 침공한 사실. 시청자 관심 방향(역설 해소 욕구)과 정확히 부합.
2. **"같은 편끼리 전쟁"**: 같은 공산주의 국가가 국경을 맞대고 전면전. 상식 파괴력 최상.
3. **"가장 많이 수출하는 나라를 가장 싫어한다"**: 수출의 절반 vs 세계 최고 반중. 경제-감정 분리의 역설.
4. **"강대국 3개를 이긴 나라의 허리 50km 약점"**: 승리의 서사 후 지정학적 취약점 반전.
5. **"원수(미국)와 손잡아 동지(중국)를 견제"**: 적과 동지가 뒤바뀌는 지정학적 아이러니.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 — 정보 배치 순서 비교**:

| 영상 | 서사 흐름 |
|------|----------|
| 002 | 고대 기원 → 독립과 반복 침략 → 국토 형성 → 공산 밀월 → 배신 → 아킬레스건 → 딜레마 → 생존 전략 |
| 003 | 고대 기원 → 조공 역설 → 공산 밀월 → 균열 → 중월전쟁 → 경제 파국 → 남중국해 → 현재 아이러니 |
| 004 | 현재 상태 → 역설 강화 → 고대 기원 → 근현대 → 결정적 균열 → 직접 충돌 → 화해와 재경색 → 딜레마 |
| 005 | 고대 기원 → 프랑스 식민 → 독립전쟁 → 혈맹 → 중소 분쟁 → 중월전쟁 → 국경 분쟁 → 남중국해 |

**공통 서사 흐름** (4/4 영상):
> **고대 종속(1천 년 지배) → 독립 쟁취 → 반복 침략과 저항 → 공산 동지 밀월기 → 배신/균열 → 중월전쟁(1979) → 현재 남중국해 분쟁 + 경제적 딜레마**

004만 "현재 상태 → 역설 → 고대로 회귀"의 역순 시작을 사용했으나, 전체적으로는 동일한 시간순 흐름으로 합류한다.

**전달 기법**:

*비유* (공통 패턴):
- 추상적 지정학 개념을 구체적 이미지로 전환하는 방식이 4개 영상 모두에서 반복된다.
- 002: "남중국해의 중국이 건설 중인 해군기지는 베트남의 아킬레스건을 노리는 비수와 같습니다"
- 003: "쿨타임이 차면 베트남에 쳐들어갔죠" — 게임 용어로 반복 침공 패턴을 직관화
- 003: "인도차이나 반도 안에서 그야말로 여포" — 절대 강자를 한 단어로 압축
- 005: "크루 100처럼 서로 협력을 이어왔던" — 친밀한 관계를 친숙한 이미지로 단축

*숫자/데이터* (공통 패턴):
- 4개 영상 모두 핵심 주장마다 구체적 수치를 반드시 배치한다.
- **대비 쌍** 구조가 반복: "수출의 절반이 중국" vs "반중 88%"(003), "200억 달러 원조" vs "39만 대군 침공"(003), "허리 폭 50km" vs "1100km 안남 산맥"(002)
- 날짜 명시로 실재감 부여: "1979년 2월"(003, 005), "기원전 111년"(004), "1978년 12월 25일"(003)

*사례/에피소드* (공통 패턴):
- 4개 영상 모두 인물 중심 에피소드를 서사의 앵커로 사용: 쯩짝·쯩리 자매(002, 004), 레러이 유격전(002, 004), 호찌민 독립 선언(004, 005)
- 개별 전략(002만 사용): 삼국지 칠종칠금 고사로 중화사상 설명 — 한국 시청자에게 친숙한 소재로 추상 개념을 구체화

### 설계 원칙

**본론 뼈대**:
1. 시간순 전개를 기본 골격으로 한다. 고대 종속 → 저항·독립 → 공산 밀월 → 배신·전쟁 → 현재 딜레마 순서.
2. 중간에 **"밀월기"를 반드시 배치**한다. 단순히 "늘 싸웠다"가 아니라 "친해졌다가 더 크게 배신당했다"의 감정 낙차가 리텐션의 핵심이다.
3. 후반부는 역사 서술에서 **현재 지정학적 위기**로 전환하여 "나와 관련 있는 이야기"로 착지한다.

**전달 기법 사용 규칙**:
1. **비유는 추상적 개념이 등장할 때마다 1개씩 배치**한다. 지정학, 외교 전략, 군사 개념 등 시청자가 직관적으로 이해하기 어려운 부분에 반드시 게임·일상·한국사 비유를 넣는다.
2. **숫자는 반드시 대비 쌍으로 제시**한다. "200억 달러 원조" 단독이 아니라 "200억 달러 원조한 나라가 60만 대군으로 침공"처럼 충돌하는 수치를 나란히 놓아야 역설이 살아난다.
3. **사례/에피소드는 인물의 이름과 구체적 행동으로 제시**한다. "반란이 일어났다"가 아니라 "쯩짝·쯩리 자매가 코끼리를 타고 진군했다"처럼 장면이 그려지는 수준으로.

**리텐션 장치 배치 규칙**:
1. **초반**: 본문 진입 전 반드시 "왜?"를 담은 오픈루프를 설치한다. 이 질문은 영상 후반부에서야 해소된다.
2. **밀월기→배신 전환점**: 패턴 인터럽트를 배치한다. "여기까지 들으면 사이 좋은 것 같죠? 근데요..."처럼 시청자의 예상을 대신 말한 뒤 뒤집는다.
3. **파트 전환마다**: 다음 파트의 위기/갈등을 한 문장으로 예고하는 전환 멘트를 삽입한다.
4. **화해 이후**: "이제 끝인 줄 알았는데..."식의 오픈루프를 재설치하여 후반부 이탈을 방지한다.

**공통 감정 흐름**: 공감/호기심(초반) → 분노·배신감(중반, 착취+배신의 누적) → 경각심·긴장(후반, 현재 위기 + 한국 대입)

### 설계 원칙

1. **분노 축적이 최우선 엔진이다.** 초반 30%에서 중국의 구체적 착취 행위(노비 매매, 문화 말살, 영토 강탈)를 최소 3개 이상 구체적 장면으로 묘사하여 분노를 충분히 쌓는다.
2. **밀월기로 감정을 리셋한 뒤 배신으로 더 큰 분노를 만든다.** 중반에 "200억 달러 원조, 32만 지원병"이라는 우정의 증거를 충분히 보여준 뒤, "그 나라가 60만 대군으로 침공"이라는 배신 장면으로 전환한다. 감정의 낙차가 클수록 반응이 강하다.
3. **후반 30%에서 반드시 한국 시청자의 현실과 연결한다.** "거래는 하지만 마음은 안 준다"는 댓글이 증명하듯, 시청자는 베트남 이야기를 자기 이야기로 치환할 때 가장 강하게 반응한다. 남중국해 → 서해/이어도, 경제 의존 → 한중 무역 구조로 자연스럽게 연결한다.
4. **감정 흐름 설계**: 공감(초반 15%) → 분노(초중반 30%) → 배신감(중반 20%) → 경탄/통쾌(중후반 15%) → 경각심(후반 20%)

### 설계 원칙

**썸네일 텍스트 설계 원칙**:
1. 텍스트 요소 3개, 총 글자수 30~40자 범위. 요소당 8~15자.
2. 핵심 요소에 **감정 키워드** 1개 이상 포함 ("진짜", "혐오", "배신", "몰락" 등).
3. 질문형("왜?") 또는 감정 대화체("못살게 구는 것들..!")를 최소 1개 요소에 배치.
4. 계층형 배치(태그라인 → 핵심 문구 → 보조 문구).

**제목 설계 원칙**:
1. 역설 전제 + 질문 구조를 기본으로 한다: "[상식적 기대]인데도 왜 [반대 결과]?"
2. 핵심 키워드를 제목 앞부분 15자 이내에 배치한다 (모바일 잘림 대비).
3. 감정 수식어("그리도", "진짜")로 규모감을 부여한다.

**역할 분담 공식**:
- 썸네일: 감정과 분위기를 즉각 전달 (이미지로 갈등 시각화 + 텍스트로 감정 증폭)
- 제목: 정보와 맥락을 제공 (역설 전제 + "왜?" 질문으로 클릭 동기)
- 썸네일과 제목이 같은 말을 반복하지 않고, 각각 감정/정보를 분담한다.

**썸네일 비주얼 원칙**:
1. **A vs B 대립 구도** 또는 **국가 상징물(국기·지도·지도자) 활용**을 기본 구도로 한다.
2. **빨간색 배경 + 노란색 포인트 텍스트** 색채 조합 사용 (주제의 국가 색상이자 갈등·긴급 신호).
3. 핵심 오브젝트는 1~2개로 제한하여 모바일 160x90px에서도 즉시 인식 가능하게 한다.
