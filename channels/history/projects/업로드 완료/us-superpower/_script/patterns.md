**공통 패턴 (3개 이상 영상에서 반복)**

1. **"미국 = 압도적 1등"을 첫 문장에서 기정사실로 선언** — 001, 002, 003 모두 훅의 첫 문장에서 미국이 세계 최강이라는 사실을 당연한 전제로 깔고 시작한다. 이 전제가 깔려야 "왜?"라는 질문이 자연스럽게 따라온다.
2. **훅 직후 "왜/어떻게"라는 원인 궁금증으로 전환** — 001("과연 그 이유가 무엇일까요"), 002("신이 주신 위치 때문일까요"), 003("어떻게 미국만이 유일하게 초강대국이 되었을까요") 모두 훅에서 결과(초강대국)를 보여준 뒤 원인 궁금증을 건다.
3. **숫자/데이터로 체감 스케일을 조기 제시** — 001("국방비 한국 1년 예산의 2배", "항공모함 11척"), 002("광물 자원이 없는게 없잖아요"), 003("미국은 세계 원톱") 모두 추상적 "강대국"을 시청자가 체감할 수 있는 구체적 수치/사실로 변환한다.

**개별 전략 (1개 영상 고유)**

- 004: 해설 없이 1492년 현장으로 곧바로 점프하는 Show Don't Tell — 연대기형 압축 영상이기에 가능한 전략
- 003: 대장금 비유로 패턴 인터럽트 — "뭐야?"라는 의아함을 유발해 방어심을 낮추는 독특한 방식
- 005: 실제 역사 현장(플리머스)을 카메라로 보여주며 진입 — EBS 다큐 특유의 현장감 전략

**인트로의 공통 역할 (3개 이상 영상)**

1. **"초라한 시작 vs 현재의 위용" 대비 설치** — 001("사실 미국도 처음에는 흔한 제국주의 식민지 중 하나"), 003("영국에서 밀려 미국으로 이주한 사람들이 만든 나라"), 005("이 거대한 국가가 이 작은 곳에서 시작됐다는 거"). 현재의 압도적 위상과 초라한 출발점을 충돌시켜 갭을 만든다.
2. **오픈루프(핵심 질문)를 본문 진입 직전에 설치** — 001("과연 그 이유가 무엇일까요"), 003("도대체 미국은 지리적으로 어떤 축복을 받은 걸까요"), 004("유럽인들에게 아메리카는 새로운 땅과 물자를 얻을 수 있는 절호의 기회였습니다") 모두 인트로 끝에서 본문 전체를 관통하는 질문/전제를 설치한다.

**시청자 관심 방향 요약**: 시청자는 "미국이 강하다"는 사실 자체에는 관심이 없다 — 이미 알고 있다. 궁금한 것은 **"왜 하필 미국만?"**이라는 구조적 원인이다. 특히 "원래 별것 아니었는데 어쩌다 1등이 됐는가"라는 역전의 스토리에 가장 강하게 반응한다.

### 설계 원칙

**훅 소재 풀 (역설 포텐셜 상위 5개 — 이후 creative-strategy.md Phase 3의 입력)**

1. **패배자가 만든 나라가 세계 1등** — "영국에서 쫓겨난 사람들이 영국을 넘어섰다"는 역전. 시청자의 "왜 하필 미국만?" 궁금증과 정확히 부합
2. **한 평당 0.7원에 산 땅이 미국을 초강대국으로 만듦** — 나폴레옹의 실수가 미국의 운명을 바꿈. 숫자의 황당함이 즉각적 반응 유발
3. **망하기 직전의 대공황을 전쟁이 살림** — "전쟁 = 파괴"라는 상식과 정면 충돌. "미국에겐 전쟁이 경제 정책이었다"는 프레임
4. **디트로이트 공장 하나 vs 나치 독일 전체** — 생산력 차이의 황당한 스케일. 숫자 하나로 "미국이 왜 이겼는지" 즉각 체감
5. **마녀 재판이 자유의 씨앗** — 비극이 오히려 미국의 핵심 가치(자유)를 만듦. 역설의 깊이가 있어 훅 이후 본론으로 연결하기 좋음

**훅/인트로 설계 규칙**

1. 첫 문장에서 미국의 현재 위상을 **한국인이 체감할 수 있는 수치**로 각인시킨다 (001: "한국 1년 예산의 2배")
2. 훅 직후 **"초라한 시작"**을 대비시켜 갭을 만든다 — "처음엔 별것 아니었다"를 반드시 포함
3. 인트로 끝에서 본문을 관통하는 **오픈루프 질문**을 설치한다 — "과연 그 이유가 무엇일까요" 형태
4. 역설 소재 풀에서 1개를 선택해 **역설형 훅**으로 변환한다 — "쫓겨난 자들이 세계를 지배하게 됐습니다" 형태

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조**

각 영상의 정보 배치 순서 비교:

| 영상 | 구조 |
|------|------|
| 001 | 지리 → 이민자 → 독립 → 영토 확장 → 남북전쟁 → 1차대전 → 대공황 → 2차대전 |
| 002 | 강대국 조건 4가지 정의 → 이집트 사례 → 달러-석유 → 페르시아 관용 → 영미 역전 → 쇠퇴 징조 |
| 003 | 결론 선공개 → 루이지애나 매입 → 비옥도 → 수로망 → 4가지 이점 → 1차대전 |
| 004 | 콜럼버스 → 독립전쟁 → 영토 확장 → 남북전쟁 → 산업화 → 대공황 → 냉전 |
| 005 | 플리머스 → 버몬트 → 세일럼 → 보스턴 → 필라델피아 → 워싱턴 → 뉴욕 |

**공통 서사 흐름 (4개 이상 영상에서 반복)**

1. **"초라한 출발점" → "조건/행운" → "위기" → "위기가 도약의 발판"** — 001, 003, 004, 005 모두 미국이 처음에 약소했음을 보여준 뒤, 지리/자원이라는 행운을 설명하고, 남북전쟁/대공황 등 위기를 거쳐 오히려 더 강해지는 구조를 따른다.
2. **시간순 전개가 기본 뼈대** — 001, 004, 005는 명시적 시간순. 003도 루이지애나 매입(1803)→1차대전(1914)의 시간순. 002만 주제별 분석 구조(예외).
3. **"위기 → 기회 전환" 반전 구조가 파트 간 접착제** — 001("대공황 → 2차대전이 구원"), 003("단순 비옥한 땅 → 수로망이라는 추가 가치"), 004("번영 → 대공황 → 뉴딜 → 전쟁 승리"), 005("마녀 재판 → 종교 자유 확립"). 각 파트가 "여기서 끝인 줄 알았는데..."로 다음 파트와 연결된다.

**개별 전략**: 002는 "강대국의 4가지 조건"이라는 분석 프레임을 먼저 제시하고 역사 사례로 검증하는 연역적 구조 — 전문가 패널 포맷 고유의 선택.

**전달 기법**

*비유 (공통 패턴 — 3개 이상)*:
- **게임/일상 용어로 역사를 번역** — 002("치트키 쓰고 게임했다"), 001("사기 맵"), 003("바보도 경영할 수 있는 회사" — 워렌 버핏 인용). 추상적 역사 개념을 시청자의 일상 언어로 변환하는 방식이 반복된다.
- **대비 쌍으로 스케일 체감** — 001("한국 1년 예산의 2배"), 003("한국 전라도 5등급 vs 미국 1등급"), 001("디트로이트 공장 하나 vs 나치 전차 총생산량"). 비교 대상을 한국이나 상대국과 나란히 놓아 체감을 극대화한다.

*숫자 (공통 패턴 — 5개 영상 모두)*:
- **모든 영상이 핵심 수치를 짧고 강렬하게 투입** — 001("항모 11척"), 002("국방비 1,100조 원"), 003("한 평당 0.7원", "수로 2만 4천 km"), 004("캘리포니아 인구 1년 만에 6배"), 005("102명의 청교도", "1,200만 이민자"). 긴 설명 없이 숫자 자체가 주장을 대신한다.
- **수치를 반드시 "대비 쌍"으로 제시** — 003("2만 4천 km, 중국의 7배"), 001("한국 1년 예산의 2배"), 002("미국 GDP 대비 3.5% vs 중국 2%"). 단독 숫자는 없고 항상 비교 대상이 함께 온다.

*사례 (공통 패턴 — 4개 이상)*:
- **인물 중심 에피소드로 역사를 인격화** — 001(나폴레옹, 링컨), 002(루즈벨트 vs 처칠, 키루스 대왕), 003(나폴레옹, 워렌 버핏), 004(콜럼버스, 블랙 호크, 링컨), 005(JFK, 나다니엘 호손). 제도나 구조 설명 전에 반드시 인물의 구체적 행동/대화가 먼저 나온다.

**리텐션 장치**

*오픈루프 배치 패턴 (5개 영상 모두)*:
- **인트로 끝**: 본문 전체를 관통하는 질문 설치 — 001("과연 그 이유가 무엇일까요"), 003("도대체 어떤 축복을 받은 걸까요")
- **파트 전환 직전**: 정보를 예고만 하고 공개를 지연 — 002("굉장히 중요한 포인트가 하나 있는데요"), 004("미국은 여전히 풀지 못한 문제가 있었는데")

*패턴 인터럽트 (4개 이상)*:
- **질문-답변 구조로 시청자 참여 유발** — 001("어디서 물품을 구해 올까요 맞습니다 미국이었죠"), 002("맞춰 보십시오"), 003("그런데 단순히 비옥한 땅이라면..."), 004("소련이 비밀리에 쿠바에 미사일 기지를 건설하면서"). 설명이 단조로워질 때 질문이나 긴장 포인트를 삽입한다.

*전환 멘트 (5개 영상 모두)*:
- **반전 예고형** — 001("하지만 그런 미국을 구원해 주는 또 다른 사건이 벌어지게 됩니다"), 003("그런데 단순히 비옥한 땅이라면 결정적인 이유가 되진 못했을 것입니다"), 004("문제는..."). "여기서 끝인 줄 알았지?"라는 기대 위반으로 다음 파트 진입.

### 설계 원칙

**본론 뼈대**

1. **시간순 전개 + 위기→도약 반전 구조**를 기본으로 채택한다. 각 파트는 "여기서 끝인 줄 알았는데 오히려 더 강해졌다"로 다음 파트와 연결한다.
2. 정보 배치 순서: **초라한 출발(식민지/이민자) → 지리적 행운(땅/자원) → 영토 확장(루이지애나 등) → 내부 위기(남북전쟁/대공황) → 전쟁이 도약의 발판(1·2차 대전) → 냉전 승리/현재**
3. 각 파트 시작 시 **인물의 구체적 행동/장면**으로 진입한 뒤 구조적 설명으로 넘어간다 (예: "나폴레옹이 전쟁 자금이 필요했다" → "그래서 루이지애나를 헐값에 팔았다" → "그 결과 미국 영토가 2배")

**전달 기법 규칙**

1. **비유는 추상적 개념이 등장할 때마다 배치**한다 — 게임/일상 용어로 번역 (예: "사기 맵", "치트키", "바보도 경영할 수 있는 회사")
2. **숫자는 반드시 "대비 쌍"으로 제시**한다 — 단독 숫자 금지. 한국이나 상대국과 나란히 놓아 체감 극대화 (예: "X는 한국의 Y배", "A 하나가 B 전체와 맞먹는")
3. **사례/에피소드는 인물의 구체적 행동으로 시작**한다 — "나폴레옹이 ~했다", "처칠이 ~했지만" 등 주어+동사 구조

**리텐션 장치 배치 규칙**

1. **파트 전환 직전**에 오픈루프를 설치한다 — "하지만 진짜 문제는 이제부터였습니다" 형태로 다음 파트 궁금증을 심는다
2. **3분 이상 정보 전달이 이어지면** 패턴 인터럽트를 삽입한다 — 질문("그럼 어떻게 됐을까요?") 또는 반전 사실("근데 여기서 소름돋는 건") 투입
3. **전환 멘트는 반전 예고형**을 사용한다 — "여기서 끝인 줄 알았는데" 구조

- **결론의 방향을 제목에서 미리 암시** — 002("치트키" = 유리한 조건), 003("축복을 타고 났을까" = 지리), 005("우연히 만들어지지 않았다" = 필연). 단순 질문이 아니라 답의 방향까지 힌트를 줌

개별 전략:
- 004: "한 편으로 알아보는"은 **가성비/효율 약속** — 조회수 1위. 시청자의 시간 절약 욕구를 정면으로 겨냥

**썸네일-제목 역할 분담**

| 영상 | 썸네일 역할 | 제목 역할 |
|------|-----------|----------|
| 004 | 감정(흥분·액션) + 시각적 스케일 | 정보(미국역사 요약 = 실용적 약속) |
| 001 | 감정(경외감) + 스케일(항공모함) | 정보(어떻게 초강대국이 됐는가) |
| 002 | 신뢰(전문가)+호기심(치트키) | 감정(ㅋㅋ = 가벼움) + 정보(치트키 = 프레임) |
| 003 | 정보(지도=지리)+감정(바보도) | 정보(어떤 축복? + 강대국 이유) |
| 005 | 감정(웅장함)+브랜드(EBS) | 정보(필연적 배경 총정리) |

공통 역할 분담 (4개 이상): **썸네일 = 감정/시각적 임팩트, 제목 = 정보/약속**. 썸네일이 스크롤을 멈추게 하고, 제목이 "클릭하면 뭘 얻는지"를 설명하는 분업 구조.

### 설계 원칙

**썸네일 텍스트 설계 원칙**

1. 핵심 텍스트 요소는 **2~3개**, 총 글자수는 **20~30자 이내**로 제한한다 (고퍼포먼스 004는 22자)
2. 대형 타이틀(5~15자)을 최대 폰트로 배치하고, 부제(12~18자)를 소형으로 계층화한다
3. **"될 수밖에 없는/된 이유" 구조를 포함**한다 — 필연성 표현이 5개 중 4개 영상에서 반복
4. 가능하면 **역설적 한마디**를 추가한다 — "바보들이 살아도", "치트키 쓰고 시작했죠" 형태

**제목 설계 원칙**

1. **"어떻게/왜" 질문형 + 답의 방향 힌트**를 결합한다 — "미국은 어떻게 ~했을까?" + 부제에서 핵심 프레임 제시
2. 제목에서 **답의 방향을 살짝 노출**한다 — 완전한 스포일러가 아닌 프레임 힌트 (예: "치트키", "축복", "우연이 아니다")
3. 주요 키워드("초강대국", "미국", "이유")를 반드시 포함하여 검색 노출을 확보한다

**역할 분담 공식**

- **썸네일**: 감정 + 시각적 스케일 (성조기, 항공모함, 무장 인물, 지도 등 미국의 힘을 즉각 체감시키는 이미지)
- **제목**: 정보 + 실용적 약속 ("이 영상을 보면 ~를 알 수 있다")
- 겹치는 정보 금지: 썸네일이 "미국 = 크고 강하다"를 보여주면, 제목은 "왜 강한지"를 설명한다

**썸네일 비주얼 원칙**

1. **스케일 대비 구도**를 기본으로 채택한다 — 미국의 힘을 상징하는 오브젝트(항모, 성조기, 지도 등)를 크게 배치
2. **배경은 어두운 톤 + 미국 국기색(빨강·파랑·흰색) 포인트**로 통일한다
3. 모바일 160x90px에서도 **주목 요소 1개**가 명확히 인식되어야 한다
4. 텍스트 공간은 전체의 **35~45%**를 확보한다
