## 1. 반복되는 훅 공식

### 관찰 A — 레퍼런스 훅 분석

**원문 비교**:

| 영상 | 훅 원문 | 패턴 |
|------|--------|------|
| 001 | "여러분이 태어나는 순간 나라가 정해져 있잖아요. (...) 그런데 세상에는 태어나면서부터 나라가 없는 사람들이 있습니다." | 시청자 전제 확인 → 전제 깨뜨리기 |
| 002 | "한 나라의 최고 지도자가 폭격에 죽었습니다. 수도가 불바다가 됐고 북방장관도 정보기관 수장도 전부 같이 죽었어요." | 충격적 결과 선제 투하 |
| 003 | "지금 중동이 불타고 있습니다. (...) 두바이의 상징 브루즈 알아랍에 요격된 드론의 잔해가 떨어지면서 불길이 치솟았어요." | 충격적 장면 묘사 선제 투하 |

**공통 훅 패턴** (3/3 영상):
- **추상적 배경 설명 없이 즉시 시작**: "오늘은 쿠르드족에 대해 알아볼게요" 같은 도입이 전무하다. 3개 영상 모두 첫 문장에서 바로 구체적 장면 또는 감각적 정보를 던진다.
- **인지적 충격 유발**: 001은 "당연한 전제 파괴", 002·003은 "극단적 결과 선제 공개"로 방법은 다르지만, 공통적으로 시청자의 기존 인식을 흔들어 "뭐야?" 반응을 만든다.

**공통 인트로 역할** (3/3 영상):
- **숫자로 스케일 체감**: "3천만~4천만 명"(001, 002), "수천 명의 무장 전사"(003)
- **한국 비유로 감정 연결**: "대한민국 전체 인구만큼"(001), "우리나라가 중국, 일본, 러시아, 몽골에 나뉘어 있었다면"(003)
- **핵심 질문으로 오픈루프 설치**: "어떤 기분일까요?"(001), "돈 때문에? 복수 때문에? 꿈 때문에?"(002), "이들 대체 누굴까요?"(003)
- **"지금"이라는 현재 진행형 긴급성 부여**: "지금 이들이 또다시 강대국의 전쟁터에 뛰어들었습니다"(001), "왜 하필 지금"(002), "지금 중동이 불타고 있습니다"(003)

**시청자 관심 방향 요약**: 레퍼런스 훅들은 공통적으로 "나라 없는 4천만 명이 왜 또다시 강대국의 전쟁에 뛰어드는가"라는 역설적 궁금증과, "100년간 배신당한 민족이 지금 어떤 선택을 하고 있는가"라는 현재 진행형 긴장감을 건드린다.

### 설계 원칙

**훅 소재 풀 (포텐셜 상위 5개)**:

1. **"4천만 명인데 나라가 없다"** — 숫자 모순. 시청자 관심 방향("왜 나라가 없는가")과 직결. 대한민국 인구와 대비하면 즉각적 체감 가능.
2. **"배신당하고도 또 손을 잡는다"** — 행동 모순. "왜?"라는 질문을 자동 생성하며 영상 끝까지의 시청 동기를 만든다.
3. **"독립투표 92.73% 찬성 → 거부"** — 결과 모순. 압도적 숫자가 무의미해지는 충격. 민주주의에 대한 상식을 정면으로 깬다.
4. **"자기를 버린 사람이 다시 전화를 걸었는데, 그 전화를 받는다"** — 행동 모순. 트럼프라는 구체적 인물이 있어 현실감이 높다.
5. **"나라도 군대도 없는 민병대가 정규군도 못 이긴 ISIS를 격퇴"** — 결과 모순. 비장한 경외감을 유발하며 영웅 서사의 시작점.

이 5개 소재가 이후 creative-strategy.md Phase 3에서 역설형 훅 생성의 입력으로 사용된다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 — 공통 서사 흐름** (3/3 영상):

- **일상적 행위로 치환**: "계약서에 도장까지 찍어 놓고 3년 만에 그 계약서를 아예 없던 일로 만들어 버린 셈"(001), "화재 현장에 소방관을 불렀는데 불이 좀 잡히니까 소방관을 내보낸 격"(001).

*숫자* (공통 패턴 — 3/3 영상):

- **한국 기준 환산**: "대한민국 전체 인구만큼"(001), "한반도의 7배"(003).

*사례* (공통 패턴 — 3/3 영상):

### 설계 원칙

**본론 구조 뼈대**:
1. 충격적 현재 상황으로 시작 (현재 긴급성)
2. 쿠르드족 정체성을 한국 비유로 즉시 체감시키기
3. 배신 에피소드를 시간순으로 최소 4회 이상 축적 (패턴 인식 = 분노 축적)
4. 배신 서사 중간에 영웅 서사(IS 격퇴, YPJ 등)를 반전으로 삽입
5. 영웅 서사 직후 또 다른 배신을 배치해 감정 낙차 극대화
6. 2026년 현재로 복귀, "이번에는 다를까?"로 마무리

**전달 기법 규칙**:
- 비유는 추상적 개념(무국적, 국제정치 역학)이 나올 때마다 한국 상황 또는 일상 행위로 치환한다
- 숫자는 반드시 대비 쌍으로 제시한다 (X인데 Y → 충격). 단독 숫자 나열 금지
- 사례는 구체적 인물명 + 장면 묘사(Show Don't Tell)로 전달한다. "학살이 있었습니다"(X) → "아이들이 골목에서 뛰어놀고 있었습니다. 그때 하늘에서 이상한 냄새가 내려오기 시작했어요"(O)

**리텐션 장치 배치 규칙**:
- 인트로 직후: 핵심 질문 오픈루프 1개 설치 (영상 끝까지 답을 미룸)
- 배신 에피소드 전환마다: "이게 끝이 아닙니다" 형태의 오픈루프로 다음 배신 궁금증 설치
- 배신→영웅 전환점: 패턴 인터럽트("여기서 반전이 있어요")로 시청자의 피로감을 리셋
- 후반부: 열린 질문으로 여운을 남기며 댓글 참여 유도

**감정 흐름 비교** (3/3 영상 공통):

```
호기심/충격(훅) → 공감(한국 비유) → 분노(배신 축적) → 경외(영웅 서사) → 다시 분노(또 다른 배신) → 비장한 여운(열린 결말)
```

핵심 공통점: **분노를 충분히 쌓은 뒤 영웅 서사로 경외감 전환 → 다시 배신으로 분노 재점화 → 열린 결말로 여운**. 감정이 단선적으로 흐르지 않고, 분노↔경외의 진자 운동을 반복한다.

### 설계 원칙

**감정 설계 전략**:
- **1순위 감정은 "동정/연민 → 독립 응원"**: 이 감정을 만들기 위해 초반에 한국 비유로 감정 연결을 확보하고, 배신 에피소드를 4회 이상 축적하여 분노를 충분히 쌓는다
- **분노 축적 장치**: 배신 에피소드마다 "약속 → 이행 → 배신"의 3단계를 완결시킨다. 약속 단계에서 희망을 키울수록 배신의 충격이 커진다
- **경외감 전환점을 중반 이후에 배치**: IS 격퇴, YPJ 등 영웅 서사는 배신 분노가 정점에 달한 후에 삽입하여 감정 낙차를 극대화한다
- **2026년 현재 상황으로 복귀 시 "또 배신당할 수 있다"는 불안을 심어** 댓글에서 "이번에는 꼭"이라는 응원 반응을 유도한다

**감정 흐름 설계 가이드**:
- 호기심/충격 (초반 5%) → 공감/연민 (초반 15%, 한국 비유) → 분노 축적 (초반~중반 40%, 배신 에피소드 반복) → 경외/통쾌 (중반~후반 20%, 영웅 서사) → 분노 재점화 (후반 10%, 또 다른 배신) → 비장한 여운 (마무리 10%, 열린 질문)
