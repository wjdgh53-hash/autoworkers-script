**공통 구조 패턴 3개**:
1. **결론/인증 사실을 맨 앞에 놓고, 본론은 전부 "왜"에 쓴다.** 두 편 다 결과를 감추지 않는다. 리텐션의 연료는 스포일러 방지가 아니라 **인과 설명의 부채**다.
2. **"기존에는 X였는데 이건 Y다" 재정의 문형을 골격으로 반복한다.** 001은 해양플랜트를 악당→보물로 뒤집고(동일 대상 재정의), 002는 같은 문형을 최소 6회 찍어낸다("발전소가 부동산이 아니라 움직이는 에너지 플랫폼", "배를 파는 산업에서 에너지 인프라를 파는 산업으로"). → **재정의 문장 1개가 파트 1개의 결론 역할**을 한다.
3. **부정적 요소를 잘게 흩지 않고 한 블록에 몰아넣은 뒤 곧바로 반등시킨다.** 001은 몰락을 1장에 집중(그 뒤로는 하락 없음), 002는 리스크를 후반 한 블록에 집중한 직후 최고 감정점을 배치. → **감정이 "의심 → 확신" 순으로 끝난다.**

**개별 전략**:
- 001 고유: **신규 소재 추가 없는 반전.** 동일 대상(해양플랜트)의 의미만 뒤집어 반전을 만들어 28분간 인지 부담이 늘지 않았다. → 15분에서는 이 절약이 더 결정적이므로 **채택**.
- 001 고유: **핵심 숫자 2회 반복.** 64% / 11기 중 7기를 인트로("믿기지 않는 결과")와 결실 파트("고생의 대가")에서 두 번 쓴다. 같은 숫자가 두 번째에 다른 감정값을 갖는다.
- 002 고유: **선제적 반론 처리** — "사람들은 당연히 묻습니다. 원전을 배 위에 올려도 괜찮습니까?"
- 002 고유: **의도적 김빼기** — "물론 이런 전망은 말 그대로 잠재 시장입니다", "다만 아직 상업적으로 널리 검증된 기술은 아닙니다". 절제가 권위를 만든다.

### 관찰 — 전달 기법

**비유**: 두 편의 노선이 갈린다. 001은 **비유 폭격**(FLNG = 유전+정유공장+창고+주유소 합체 / 해양플랜트 = 바다 위에 떠 있는 공장 / 영하 162도 = 우리 집 가스레인지 가스를 꽁꽁 얼린 것), 002는 **비유 거의 없음**(재정의 문형으로 대체). 조회수 7배 우위 + 채널 프로필의 "쉽게 말하면" 시그니처 → **001 노선 채택**.

**숫자**: 두 편의 유일한 완전 공통 기법 = **원수치를 즉시 체감 단위로 환산**한다.
- 001: 488m×74m → "축구장 4개를 나란히 이어붙인 크기" / 64% → "셋 중 둘은 대한민국 거제도에서 태어났다" / FLNG 4조 → "웬만한 배 열 척 이상을 파는 것과 맞먹는다"
- 002: 945TWh → "일본 전체 전력 소비량보다 약간 많은 수준" → "우리가 인공지능에게 질문 하나를 던지고 (…) 그 모든 행동 뒤에서 일본 한 나라 규모의 전력 수요가 새로 생기고 있다" (**원수치 → 국가 스케일 → 내 손가락, 3단 축소**)

**대비 쌍**: 두 편 다 숫자를 홀로 두지 않고 **A vs B로 짝지어** 제시한다. 001 = LNG선 2.5억 달러 vs FLNG 30억 달러, 마진 5~10% vs 20%+ / 002 = 415TWh vs 945TWh, 육상 원전 vs 부유식.

**고유명사로 신뢰 담보**: 001 = 프렐류드·셸·코랄·모잠비크·블랙록·거제도. 002 = 23분에 출처 9개(연합뉴스·ABS·IEA·IAEA·영국 NNL·한국원자력연구원 등), "~라고 보도했습니다"로 화자를 옮긴다. 두 편 다 **추상 논의가 3문장 이상 이어지지 않고 실명으로 착지**한다.

**체감 디테일**: 001은 재무 손실을 풍경으로 번역한다 — "잘 나가던 식당들이 문을 닫고 월룸촌이 텅텅 비었다", "주인을 찾지 못한 채 조선소 앞바다에 덩그런이 떠 있게 된 겁니다". 002는 이 장치가 없어 중반이 정보 나열로 흐른다(002 분석의 자체 약점 진단).

| 길이 | 48자 (앞 20자에 후크 집중 → 잘려도 작동) | 38자 |

**공통 패턴 3개**: ① 큰따옴표 인용구를 문장 맨 앞에 둔다(화자 미명시 → "누가 한 말?" 궁금증) ② 삼성중공업을 고유명사 앵커로 박는다 ③ 결과·정체를 감춘 명사구/구문으로 종결한다.

**001이 이긴 이유 2개** (pd-guide 히트작 공식과 정확히 일치):
- **구체적 숫자(5조)를 박았다.** 002는 숫자가 없다.
- **추상 과장어를 쓰지 않았다.** 002의 "충격적"은 pd-guide 금지 항목("세계 최초/충격/근황 류 추상 과장어 금지")이며, 002 자체 분석도 "썸네일은 충격을 팔았는데 본문은 스스로 온도를 낮춘다 = 클릭 감정 대비 정산 불완전"으로 미이행 판정했다.

**썸네일-제목 역할 분담**:
- 001: 썸네일 = **감정·결과의 극단 대비만**(8년 적자 → 세계 1위) + 국가 자부심(태극기) / 제목 = **갈등·수단·미공개 원인 전부**. 정보 중복 0%.
- 002: 썸네일 = **제목을 그대로 2단으로 쪼개 박음**(상단 카피 = 제목 앞부분, 하단 카피 = 제목 뒷부분). 같은 문장을 두 번 때리므로 **정보량이 늘지 않는다.**
> → **001의 분업(중복 0%)이 002의 중복(100%)보다 7배 성과.** 이것이 이 항목의 가장 실행 가능한 교훈이다.

### 설계 원칙

**제목 설계 원칙 — 001 공식 계승 (확정)**

pd-guide 히트작 골격 적용 조건 판정: 이 주제는 **"한국 급소형"** — 한국(거제도)이 세계 LNG 공급망의 급소가 되는 서사. ✅ 적용 가능. 단 강대국이 손 벌리는 서사가 아니라 **한국이 시장을 장악한 서사**이므로, 강대국 주어 대신 **결핍 인용 + 구체 숫자 + 역전 행동 + "~한 이유"** 4요소를 001 공식대로 쓴다.

```
"[결핍·조롱 인용구]" [구체 숫자] [삼성중공업] [역전 행동] 이유
```

- [ ] **큰따옴표 인용구로 시작**한다. 결핍·조롱·다급함 계열("~하지 마라", "~가 없다", "접어라" 결). ⚠️ `"모두가 접으라 했다"`는 레퍼 원문 — **표현만 교체**하고 공식은 유지.
- [ ] **구체 숫자를 반드시 박는다** (5조 / 8년 / 64% / 11기 중 7기 중 택 1~2).
- [ ] **`~한 이유` / `~한 배경`으로 종결**한다. 결과는 알려주고 원인은 감춘다(스포일러 + 오픈루프 동시 성립).
- [ ] **전문용어를 번역한다.** `FLNG` 단독 노출 금지 → `바다 위 LNG 공장` 계열로 풀되 검색어 `LNG`는 살린다. (⚠️ "바다 위 LNG 공장"은 레퍼 원문 — 다른 번역 표현으로 교체)
- [ ] **추상 과장어 금지**: 충격적 / 소름 / 세계 최초 / 근황 / 무서운.
- [ ] **앞 20자에 후크를 몰아넣는다** (인용구 + 숫자). 총 40~48자 허용.
- [ ] 극단 대비를 한 문장에 공존시킨다(최악의 숫자 ↔ 최고의 결과).

**썸네일 텍스트 설계 원칙 — 001 형식 채택**

## 부록 — 표현 복제 금지 목록 (독창성 방어)

레퍼 고유 표현은 **1개라도 복제되면 치명적**이다. 아래는 전면 교체 대상.

**001 금지**
- 계절 은유 세트: "기나긴 겨울", "봄을 기다리며 씨앗을 지켰다", "저마다의 겨울" → **다른 은유 축으로 전면 교체**
- "축구장 네 개를 이어붙인 크기" → 다른 스케일 기준
- "5만 원권을 쌓으면 빌딩 높이" → 다른 환산 방식
- "밑빠진 독에 물 붓기", "CEO의 무덤", "세상에서 제일 어려운 요리를 세 접시", "환골탈태", "황금알"
- "그런데 말입니다" (레퍼 시그니처 전환구, 3회+ 사용) → 채널 시그니처 "근데요, 여기서 진짜 핵심은"(최대 2회)
- "저주받은 이름 안에 보물이 숨을 쉬고 있었다", "수업료" 단어 그대로 사용 주의
- 제목 원문 "모두가 접으라 했다" / "바다 위 LNG 공장" / 썸네일 원문 "8년 적자에서 세계1위" / "삼성중공업의 대반전" → **공식만 계승, 표현 교체**

**002 금지**
- "떠다니는 산업 단지", "에너지의 문법이 바뀌고 있습니다", "종이 위 상상을 넘어", "발전소가 부동산이 아니라"
- "이 말은 무섭습니다" 계열 공포 강조 (채널 규칙 위반)
- "오늘 제목은 이것입니다" 제목 낭독 (금지어 "오늘" 계열)
- 제목 원문 "충격적 정체" (추상 과장어, pd-guide 금지)
