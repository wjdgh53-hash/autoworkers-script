## 1. 훅 분석 & 역설 소재 수집

### 관찰 A — 레퍼런스 훅 분석

**원문 비교**:

|------|---------|------|
| 001 | "시청자 여러분, 폭격 개시 딱 90분 전이었습니다." | 숫자형 + 현장 투입 |

| 005 | "이란 전쟁은 끝일까요?" | 핵심 질문 단문 |

**공통 패턴** (3개 이상 반복):

1. **"안도 → 반전" 구조** (001, 002, 003, 004, 005 전원): 모든 영상이 "휴전"이라는 긍정 뉴스를 전제로 깔고, 즉시 "끝이 아니다"로 뒤집는다. 002는 "그런데 이 전쟁에 끝난게 아닙니다", 005는 "이란 전쟁은 끝일까요?"라는 질문 자체가 "아닐 수 있다"를 내포한다.

2. **구체적 숫자로 긴박감 부여** (001, 002, 003): "90분 전"(001), "2주"(002), "2주간"(003). 추상적 위기가 아닌 카운트다운 가능한 숫자를 제시해 시청자를 현장에 투입한다.

3. **시청자의 안도감을 정면 부정** (001, 002, 004): 001은 "정말 다행이라고 생각하십니까?", 002는 "끝난게 아닙니다", 004는 "유쾌한 발언이 있는 건 아니에요". 안심하고 있던 시청자의 인지 상태를 의도적으로 깨뜨린다.

**인트로 공통 역할** (3개 이상 반복):

1. **오픈루프 설치** (001, 002, 004): "왜 하필 2주?"(001), "다음 전쟁을 위한 준비 시간"(002), "2주가 누구에게 약이 될지 모른다"(004). 본문까지 봐야 풀리는 핵심 미스터리를 심는다.
2. **구체적 시청 혜택 약속** (001, 004): "4가지 시나리오 + 행동 지침"(001), "치명적 4가지 변수"(004). 끝까지 보면 얻을 수 있는 구체적 보상을 제시한다.

**시청자 관심 방향 요약**: 시청자는 "휴전이 진짜 평화인지 아닌지"에 대한 불안을 안고 클릭하며, "아닌 이유"를 구체적 근거로 확인하고 싶어한다. 동시에 "그래서 내 생활에 어떤 영향이 오는가"까지 알고 싶어한다.

### 설계 원칙

**훅 소재 풀 (포텐셜 상위 5개)**:

1. **"이기고 있는 미국이 왜 멈췄나"** — 행동 모순. 시청자의 "미국이 이기고 있잖아, 왜?"를 정면으로 건드린다.
2. **"2주 = 항공모함 전투배치 소요 시간"** — 인과 역전. 평화의 시간이 전쟁 준비 시간이라는 반전.
3. **"세계 1위 산유국 미국이 유가에 항복"** — 숫자 모순. 1,300만 생산 vs 2,000만 소비라는 반직관적 숫자.
4. **"패전국 이란이 승전국 미국에 통행료 징수"** — 결과 모순. 지고 있는 쪽이 돈을 받는 역설.
5. **"중동 전쟁이 한국 쓰레기봉투를 품귀로 만든다"** — 결과 모순. 먼 나라 전쟁 → 내 일상 파괴의 연결고리.

- 1~2번은 시청자 관심 방향("휴전이 진짜인가")과 직접 부합하므로 최우선 활용.
- 3~5번은 "내 생활에 어떤 영향"이라는 두 번째 관심 방향에 부합.

**공통 패턴 — "줌인" 구조** (5개 전원):
먼 곳(국제 군사)에서 시작해 점점 가까운 곳(내 지갑)으로 끌어오는 동심원 수축 구조. 001이 가장 명확: "미국 군사작전 → 이란 통행료 → 한국 해상보험 12배 → 나프타 → 쓰레기봉투". 002도 "항모 재배치 → 동아시아 원유 → 유가 → 물가". 004도 "벤스 협상 → 이스라엘 → 호르무즈 → 유가 → 한국 선박".

**공통 패턴 — "안도 해체" 서사** (001, 002, 003, 004):
시청자의 안도감을 초반에 설정한 뒤 체계적으로 파괴. 001: "안도 → 의심 → 충격 → 공포 → 위기감". 002: "긴장 → 의심 → 공포 → 위기감". 003: "불안 → 안도 → 재불안". 004: "기대 → 불안 → 안도 → 좌절 → 답답함".

**공통 패턴 — "겉 vs 속" 프레임** (001, 002, 003, 005):
겉으로는 휴전/평화인데 속은 전쟁 준비/이면 거래. 001: "평화가 아닌 칼 가는 시간". 002: "카운트다운 구조". 003: "2주간 휴전이라고 하시면 안 돼요. 정전을 위한 2주간의 휴전". 005: "진짜 거래".

### 설계 원칙

**본론 뼈대**:
- [ ] "줌인" 구조 적용: 국제 군사 → 양측 요구 불일치 → 호르무즈/경제 → 한국 체감 → 미래 시나리오 순서로 배치
- [ ] "안도 해체" 서사: 초반에 휴전이라는 안도감을 의도적으로 세운 뒤, 파트마다 한 겹씩 벗겨내며 불안을 축적
- [ ] "겉 vs 속" 프레임 유지: 각 파트의 도입부에서 "겉으로는 X"를 세우고 "속은 Y"로 뒤집는 구조 반복

**전달 기법 규칙**:
- [ ] 비유는 국제정세/군사/경제 추상 개념이 등장할 때마다 배치. 일상 행위(택배비, 수도관, 동네 싸움 등)로 치환
- [ ] 숫자는 반드시 "원본 수치 → 체감 환산" 2단계로 제시. 단독 숫자 투척 금지
- [ ] 사례는 각 파트에 최소 1개 실제 에피소드(인물명/날짜/구체적 행위) 포함

**리텐션 장치 배치 규칙**:
- [ ] 인트로 직후: 영상 전체를 관통하는 핵심 오픈루프 1개 설치 ("왜 하필 X인가?" 형태)
- [ ] 파트 전환 직전: 전환 멘트로 새 미스터리를 던지며 다음 파트 궁금증 심기 ("근데 여기서 더 무서운 건…" 형태)
- [ ] 중반(전체의 40~60% 지점): 패턴 인터럽트 1회 ("지금까지는 워밍업" / "이제부터가 진짜" 형태)
- [ ] 후반(70% 이후): 미해결 오픈루프로 마지막 파트까지 긴장 유지

- 002: "휴전 종료 즉시 군사 행동 재개" — 카운트다운 구조로 시한부 불안

*2순위 감정(신뢰 갈증)을 만든 장치*:
- 003: 알파고가 "모르겠어요", "봐야 돼요"를 반복 — 모르는 것을 모른다고 인정하는 것이 2,000 좋아요(전체 1위)
- 004: "잘 몰라요", "이건 봐야 한다" — 박현도 교수의 불확실성 인정

*3순위 감정(체감형 위기)을 만든 장치*:

- 005: "샌프란시스코 친구가 1L 2,600원, 트럭 기름 한 번 채우는데 1,000달러(150만 원)" — 실제 인물의 체감 사례

**감정 흐름 — 공통 패턴** (4개 이상):

안도(휴전 소식) → 의심("끝이 아니다") → 충격(군사적 근거/반전) → 위기감(경제 파급/내 생활) → 불안 지속(미해결 변수)

5개 영상 모두 감정이 한 번도 완전히 해소되지 않고 축적되는 구조. 001이 가장 극적: "안도 → 의심 → 충격 → 공포 → 위기감 → 불안 심화 → 경각심". 안도감의 낙차가 클수록 이후 불안의 강도가 높아진다.

### 설계 원칙

**감정 설계 우선순위**:
- [ ] 1순위 감정 = **불안/비관**. 이 주제에서 시청자가 가장 강하게 반응하는 감정이므로, 영상 전체에 걸쳐 "이 상황이 좋게 끝나기 어렵다"는 불안을 축적한다
- [ ] 2순위 감정 = **신뢰 갈증 해소**. "모른다고 솔직히 말하는" 태도가 2,000 좋아요(전체 최고)를 받았다. 불확실한 부분은 억지 전망 대신 변수를 열거하고 "봐야 안다"고 인정한다
- [ ] 3순위 감정 = **체감형 위기**. 거시 경제를 개인 체감(유가→물가→내 지갑)으로 끌어내리는 파트를 반드시 배치한다

**감정 흐름 설계 가이드**:
- [ ] 초반(0~20%): 안도감을 의도적으로 세운다 → 즉시 깨뜨린다 (낙차가 클수록 효과적)
- [ ] 전반(20~40%): 군사적 근거/숨겨진 이면을 제시하며 의심→충격으로 전환
- [ ] 중반(40~60%): 호르무즈/경제 파급으로 위기감 축적. "내 삶에 미치는 영향" 파트
- [ ] 후반(60~80%): 미해결 변수/협상 교착으로 불안을 절정까지 끌어올림
- [ ] 마무리(80~100%): 시나리오 제시 + 솔직한 불확실성 인정으로 신뢰+경각심 동시 달성

**감정 증폭 장치 규칙**:
- [ ] 불안 증폭: "안도 파괴" 문장을 영상 전반에 최소 3회 배치 ("~라고 안심하고 계시죠? 그런데…" 형태)
- [ ] 체감 위기: 숫자 제시 후 반드시 "이게 내 생활에서는…"으로 연결 (001의 "석유→나프타→쓰레기봉투" 체인 참고)
- [ ] 신뢰 확보: 확정할 수 없는 전망에 대해 "이건 아직 모릅니다. 변수가 X, Y, Z가 있거든요"로 솔직히 열거
