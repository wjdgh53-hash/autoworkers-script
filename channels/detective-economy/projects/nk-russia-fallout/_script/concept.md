# 영상 컨셉

## 앵글
김정은이 러시아에 13조 원을 퍼부었지만 돌아온 건 1조뿐인 "역대급 호구 외교"의 전말. 독재자가 독재자에게 당하는 통쾌한 몰락 서사를 숫자로 입증하고, 이 파탄이 한반도에 미치는 영향까지 추적한다.

## 핵심 약속
이 영상을 끝까지 보면, 김정은이 13조를 쏟아붓고도 1조밖에 못 건진 구체적 내막에 소름 돋으면서, 이 북러 파탄이 내 월급과 안보에 어떤 영향을 주는지를 알게 된다.

## 타겟 시청자
"북한이 러시아에 군대를 보냈다는 건 알겠는데, 결국 어떻게 됐는지 궁금한" 직장인. 국제 뉴스 헤드라인은 봤지만 내막은 모르는 상태에서, 독재자가 당하는 꼴을 보고 싶은 통쾌함과 "이게 한반도에 뭔 영향이지?"라는 걱정이 동시에 작동하는 사람.

## 서사 유형
시간순 서사 — 김정은의 올인(파병/무기 지원)에서 푸틴의 배신(한국 접근)까지 시간순으로 따라가며 "그 다음은?" 궁금증을 자연 유지. 001(84.5만)이 동일한 몰락 서사 구조로 최고 조회수를 기록했으므로 검증된 방향.

## 감정 전략
- 목표 감정: 통쾌함 (댓글 최고 좋아요 352, 239 모두 통쾌함/냉소 반응)
- 감정 아크: 통쾌함·충격(초반, 13:1 불균형으로 "이 정도로 당했다고?") → 연민·분노(중반, 병사 월급 착취·자폭 강요로 "군인들은 죄 없는데") → 경각심·전망(후반, 한반도 영향과 조선업 기회)
- 리텐션 접근: 몰락이 겹겹이 쌓이는 구조("설상가상")로 중반 이탈 방지. 파트 전환마다 "근데 여기서 진짜 무서운 건" 전환 멘트로 다음 위기축 궁금증을 심는다.

## 제목 후보
1. "13조를 퍼줬는데 1조도 못 받았다" 김정은이 푸틴한테 완전히 당한 소름돋는 전말
2. "형님 약속이 다르잖아요" 푸틴에 역대급으로 호구 당한 김정은의 처참한 최후
3. 푸틴한테 13조 갖다 바친 김정은, 북러관계 완전히 끝장난 진짜 이유

## 확정 제목
"13조를 퍼줬는데 1조도 못 받았다" 김정은이 푸틴한테 완전히 당한 소름돋는 전말

## 썸네일 텍스트 후보

1. `13조 퍼줬는데 1조?` + `역대급 호구 김정은` + `북러관계 완전 끝장` (11자 + 9자 + 10자 = 30자, L3 멀티 리믹스: 001/002의 "파탄/끝장" 키워드 + 003의 감정 극대화 구조 조합)
2. `"푸틴 형님 너무합니다"` + `완전히 버림받은 김정은` + `13조 vs 1조의 진실` (11자 + 11자 + 9자 = 31자, L4 감정 차용: 002의 배신감 톤을 차용하되 따옴표 하소연 형태로 새로 작성)
3. `결국 호구 된 김정은` + `북러관계 싹 다 파탄났다` + `"형 약속이 다르잖아"` (9자 + 11자 + 9자 = 29자, L2 키워드 차용: 001/002 공통 "파탄났다" 키워드 + 002 "형 얘기가 다르잖아" 구조 변형)

## 확정 썸네일 텍스트
세트 1: `13조 퍼줬는데 1조?` + `역대급 호구 김정은` + `북러관계 완전 끝장`
- 근거: 숫자 충격(13:1)을 썸네일에서 즉시 제시하여 제목과 시너지 극대화. "역대급 호구"라는 독자적 표현으로 레퍼런스와 차별화하면서도 통쾌함 감정을 직접 자극.

## 썸네일 이미지 컨셉

### 컨셉 A: 균열 김정은 + 냉소 푸틴 대립
- 구도 패턴: A vs B (3/3 레퍼런스 공통 검증 구도)
- 핵심 오브젝트: 균열+흑백 처리된 김정은(위축 표정) vs 냉소적으로 웃는 푸틴
- 색채/대비: 어두운 배경(검정/짙은 남색) + 붉은 불꽃·균열 빛 포인트 + 노란색·빨간색 텍스트 영역
- 감정 톤: 통쾌함 (001 최고 조회수 썸네일과 동일 감정 방향, 김정은에 균열 효과로 "이미 끝난 사람" 비주얼)

### 컨셉 B: 13:1 스케일 대비 (숫자 시각화)
- 구도 패턴: 스케일 대비
- 핵심 오브젝트: 거대한 금괴/돈뭉치 더미(13조) 앞에 쪼그라든 작은 동전(1조)을 들고 있는 김정은. 뒤에서 돌아서는 푸틴의 뒷모습
- 색채/대비: 어두운 배경 + 금색(돈/부) 포인트 + 빨간색 하락 화살표
- 감정 톤: 충격 (숫자 불균형을 시각적으로 즉시 체감시키는 구도. 레퍼런스와 차별화된 독자적 비주얼)

## 텐션 트라이앵글 시너지
- 제목: 합리적 클릭 이유 제공 ("13조 vs 1조"라는 구체적 숫자로 정보적 약속)
- 썸네일 텍스트: 감정적 호기심 ("역대급 호구", "완전 끝장"으로 통쾌함·충격 즉시 유발)
- 썸네일 이미지: 시각적 보완 (균열 김정은 or 스케일 대비로 "당한 사람"의 상태를 비주얼로 전달)
- 시너지 평가: 제목의 숫자(13조 vs 1조) + 텍스트의 감정("호구") + 이미지의 비주얼(균열/위축)이 합쳐져 "독재자가 이 정도로 호구 당했다고? 어떻게?"라는 클릭 충동을 만든다. 3요소 모두 "김정은이 완전히 당했다"는 단일 메시지를 다른 각도에서 강화.

## 선택 근거
3개 패키지 중 이 패키지를 선택한 이유: 001(84.5만 조회)이 동일한 몰락 서사 + 13:1 숫자 불균형 + 통쾌함 감정 조합으로 최고 퍼포먼스를 기록. 댓글 최고 좋아요(352, 239)가 모두 통쾌함/냉소 반응이므로 이 감정을 전면에 배치하는 것이 검증된 방향. 역설 소재 포텐셜 1위(13:1 불균형, 별 5개)를 훅에 직접 활용하여 초반 이탈을 최소화한다.

## 패키지 B (정보 갭 대안)

### 제목
김정은이 푸틴한테 쏟아부은 돈, 돌아온 건 상상도 못 할 금액이었다

- 정보 갭 적용: 타겟(김정은-푸틴 관계에 관심 있는 시청자) 명확, 감정/상황("쏟아부은 돈"으로 대규모 투자 암시) 공개, 핵심 내용("상상도 못 할 금액"으로 구체적 액수 비움) → "얼마를 돌려받은 거지?" 궁금증 유발

### 썸네일 텍스트
`김정은이 쏟아부은 돈` + `돌아온 건 충격` + `북러관계 파탄`
(10자 + 6자 + 7자 = 23자)

- 제목이 "금액"을 비웠으므로 썸네일 텍스트에서도 구체적 숫자를 노출하지 않고 "충격"으로 감정만 전달. 패키지 A의 이미지 컨셉을 공유하되, 숫자 비공개로 정보 갭을 유지.

### 이미지 컨셉
패키지 A와 동일 (컨셉 A: 균열 김정은 + 냉소 푸틴 / 컨셉 B: 스케일 대비)
