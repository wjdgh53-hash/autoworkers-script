## 3. 문체 검수

### A. 통과 항목

- **쉼표·따옴표**: 따옴표 사용 1회(23행 회사 공식 표현 인용)뿐. 쉼표 남발 없음
- **용어 순화**: 경제·행정 용어 1,000자당 **0.0**. 공시·수주·순손실·시행령·전략물자 계열 0건. 기관 정식명칭 나열은 한국인터넷진흥원 1회뿐이고 그마저 "앞부분은 몰라도 됩니다. 끝에 붙은 GPU 서버 도입, 그것만 보시면 돼요"로 즉시 덜어냈다
- **숫자 4원칙**: 반올림 ⭕(51.79억→"오십억이 넘었고요", 69%→"열에 일곱 가까이") / 퍼센트→몇 중에 몇 ⭕(58.3%→"열 곳 중 여섯 곳") / 외화·원화 병기 ⭕ 0건 / 던진 뒤 살림 착지 ⭕(700W·600W→"계량기가 그만큼 덜 돈다", 20GW→"발전소를 새로 스무 개")
- **개념 설명 2~3번 다르게**: NPU(정의→계산기→정육점 냉장고), 학습/추론(정의→운전면허 학원→출근길), 쿠다(정의→작업대→공구함), 데이터센터 전기(정의→암산+선풍기→전봇대). 4개 개념 모두 3겹 ⭕
- **1인칭**: 13회 분산(21·25·35·41·47·55·67·79·87·107·113·119·125행). 전부 감정어("얼떨떨했습니다", "손이 좀 멈췄습니다", "뭉클했습니다", "화가 나더라고요", "멍했습니다"). **분석 말투 0건**
- **검증 과정 노출**: "우리는 이 숫자를 안 씁니다" 류 **0건**
- **클로징 착지**: 통찰 1줄 뒤 새벽 세 시 관제센터 장면 + 시청자 방의 전기. 통찰로 끝나지 않음 ⭕
- **독재자 존칭**: 해당 없음
- **공포·클릭베이트 과장어**: "진짜 무서운 건"·"소름"·"충격"·"경악" **전량 0건.** 전환 문구는 시그니처 "근데요, 여기서 진짜 핵심은" 2회(85·111행)로 상한 준수. "쉽게 말하면" 0회

### B. 하한 미달 2건 판단 — 실제 문제로 본다 (개선 권장)

**말 걸기 0.4 / 쉽게 풀어주기 0.1.** 시니어 타깃에서 이 두 항목은 "친근함 장식"이 아니라 **어려운 대목 앞에서 시청자를 붙잡아 두는 손잡이**다. 이 대본은 21분 중 NPU·학습/추론·쿠다·전력망 네 개의 낯선 개념을 지나간다. 개념 자체는 3겹으로 잘 풀었는데(§3-A), **"지금부터 어려운 얘기 나오는데 겁먹지 마시라"는 예고 신호가 개념 앞에 안 붙어 있다.** 시니어는 낯선 단어가 나오는 그 1초에 이탈한다. 즉 미달 자체보다 **미달 지점이 하필 개념 도입부**라는 게 문제다.

다만 일상 비유 2.9·1인칭 2.0·혼잣말 1.3으로 다른 친근함 장치는 기준의 2~3배다. 톤 자체는 무너지지 않았으므로 **차단 사유는 아니고, 아래 5곳에 문장 하나씩만 얹으면 해소된다** (총 +약 150자, 러닝타임 영향 없음 — §4-9의 중복 삭제분과 상쇄).

## 4. 톤 검수 — 통과

- 채널 프로필 말투("~거든요", "~인 거예요", 핵심에서 단정) 준수. "이 문장 술자리에서 말로 하겠는가" 기준 이탈 문장 없음

- outline 프로젝트 톤(미스터리 추적 / 1순위 감정 = 국가 역할론) 준수. 감정 아크도 설계대로: 의아함(파트1) → 자부심(파트2·3) → 분함(파트4, 87행이 정점) → 사명감(파트5) → 담담한 여운(클로징)

'돈이 어디로 먼저 갔는지' / '뭘 제일 겁내는지' 두 어절 조합을 **어느 쪽도 남기지 않는다.** 위치는 그대로(장면 바로 앞, 한 줄로 짧게).

### ② 63행 — '성적표' 문장 교체

```
현재: 회사는 전기 대비 성능이 세 배라고도 했어요. 다만 이건 회사가 자기 장비 놓고 자기 손으로 재서 내놓은 숫자입니다. 바깥 기관이 채점해서 건네준 성적표는 아니에요. 그건 짚고 가야죠.
교체: 회사는 전기 대비 성능이 세 배라고도 했어요. 다만 이건 회사가 자기 작업실에서 자기 자로 재서 내놓은 숫자입니다. 남이 와서 확인해 준 게 아니에요. 그건 짚고 가야죠.
```
'성적표', '바깥 기관' 두 단어는 대본 전체에서 뺀다(83행은 ⑥에서 통째 삭제).

### ③ 119행 — 현금 1조 → 자산 1조

```
현재: 그런데 같은 장부의 옆 칸을 열어 보면 금고에는 현금이 일조 가까이 들어 있습니다. 장부에는 내 몫이 없는데 금고에는 돈이 있는 집인 거예요.
교체: 그런데 같은 장부의 옆 칸을 열어 보면, 이 집이 굴리는 재산을 다 합친 게 일조를 넘어갑니다. 장부에 적힌 내 몫은 없는데 굴리는 살림은 일조가 넘는 집인 거예요.
```
"현금"이라는 단어를 쓰지 않는다. 실제 현금성 자산은 856억이라 "금고에 현금 1조"는 사실이 아니다.

### ④ 109행 — 스리마일섬 인과 수정

```
현재: 예전에 사고가 나서 세워 뒀던 스리마일섬 발전소, 거기를 다시 켜기로 했어요.
교체: 예전에 큰 사고가 났던 그 스리마일섬입니다. 돈이 안 된다고 몇 해 전에 불을 꺼 뒀는데, 거길 다시 켜기로 했어요.
```
뒤 문장 "사고 났던 발전소까지 되살릴 만큼 급한 판이라는 뜻이죠"는 그대로 둔다(사고가 났던 곳인 건 사실).

### ⑤ 129행 — 관제센터 시점 수정

```
현재: 지난달부터 그러고 있어요.
교체: 바로 이번 달부터 그 자리에 들어가기 시작했습니다.
```
8월 3일 발표, 이달 공급 시작이다. 완료형("그러고 있어요")을 착수형으로 바꾼다. 장면의 힘은 그대로다.

**⑥ 83행 전기 수치 재언급 삭제 (지적 2·9·13·15를 한 번에 해소)**


## 10. 참고 — 이번 대본이 특히 잘한 것 (수정 시 건드리지 말 것)

1. **숫자 밀도 4.1 / 경제행정 용어 0.0** — 기준의 절반 이하. 재작성 중 비유를 지우고 수치로 때우는 사고(`tone-guide` §4-1)가 나지 않도록, **위 수정은 전부 문장 교체이지 수치 추가가 아니다.**
2. **2중 고리 동시 회수(99~101행)** — 메인·서브가 '전기' 하나로 같은 자리에서 풀린다. 이 대본의 척추다.
3. **불리한 사실 5개가 전부 자랑 직후에 붙어 있다** — 002가 실패한 지점(리스크 뭉치기)을 정확히 피했다.
4. **파트 3 국가 역할론 1차 점화에서 전기·고지서를 끝까지 안 꺼냈다** — 파트 5의 화력을 지킨 절제.
5. **엔딩이 장면(새벽 세 시 관제센터) + 시청자 위치시키기**로 착지 — 001에 없던 항목까지 채웠다.
