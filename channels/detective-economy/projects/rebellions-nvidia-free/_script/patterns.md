**001의 훅이 특이한 지점 — 깨는 대상이 자기 제목이다.**
시청자가 클릭한 이유(엔비디아 없는 자립 서사)를 5초 만에 "근데 삼성 없이는 못 굽는다"로 깨버린다. 효과 둘:
① 시니어가 국뽕 채널에 대해 갖고 있는 방어("또 뻥이겠지")를 **채널이 먼저 인정해서 무력화**한다.
② 깨진 자리에 곧바로 수수께끼를 채워 넣어 이탈 대신 체류로 전환한다.

**인트로가 하는 일 3가지 (001)**

> "지난해 320억을 벌고 1205억을 태웠어요. **번 돈에 네 배를 까먹었는데 몸값은 3조 4천억입니다.** 150조 국민성장펀드에서 가장 먼저 돈을 넣은 곳이 삼성도 SK하이닉스도 아닌 여기 리벨리온이거든요. **왜 하필 이 적자 회사가 1번이었을까요?** 돈의 흐름을 따라가 보면 **답은 성능이 아닌 데서 나오더라고요.**"

1. **숫자 모순 제시** — 프로필의 "한 문단 숫자 2개" 기준으로는 과밀이지만, **숫자끼리 충돌시키는 게 목적**이라 밀도가 무기가 된다
2. **권위 대비로 이상함 증폭** — "삼성도 SK하이닉스도 아닌 여기". 아는 이름 둘을 탈락시켜 모르는 이름 하나를 궁금하게
3. **메인 고리 심기** — 답을 주지 않고 **답의 종류만 예고**("성능이 아닌 데서"). 오답 후보를 지워서 궁금증을 더 좁고 강하게

그리고 결정타:
> "젠슨 황이 놀랐다는 그 말은 **기사 제목에 붙어 있던 표현이에요.** 그건 잠깐 옆에 두고 확인되는 것부터 보겠습니다."

**자기 제목의 클릭베이트를 자기 손으로 해체한다.** 조회 대비 좋아요 1.76%라는 높은 호감도의 상당 부분이 여기서 나왔다. 댓글 66개 중 "낚시다"는 반응이 **단 한 건도 없다.**

**시청자 관심 방향 요약**
> 시니어 시청자는 "이 칩이 얼마나 좋은가"가 아니라 **"우리나라가 이번엔 제대로 하고 있나, 그리고 이 얘기 믿어도 되나"**를 궁금해한다. 훅은 자부심을 자극하되 **동시에 의심을 대신 말해줘야** 붙잡힌다.

### 설계 원칙 — 훅/인트로 체크리스트

1. **훅 3문장 공식을 그대로 계승한다**: `제목 복창 → 즉시 자기 배신(그런데) → 수수께끼 전환`. 배신의 재료는 위 역설 후보 중 ★★★★☆ 이상에서 고른다.
2. **인트로 안에 숫자 모순 1쌍을 반드시 충돌시킨다.** 여기서만 "한 문단 숫자 2개" 규칙을 넘겨도 된다 — 충돌이 목적이므로. 이후 본문에서는 규칙 준수.
3. **메인 열린 고리 1개는 "질문 + 답의 부정형"으로 던진다.** 답을 주지 말고 **오답 후보를 지운다**. (002는 답을 줘서 27분 연료를 5초에 태웠다.)
4. **1분 안에 자진 해체 고백 1회.** 제목·썸네일이 과장한 부분을 우리 입으로 먼저 내려놓는다. 이것이 002·003이 맞은 "국뽕사기/뻥친다" 반발을 사전 차단하는 유일한 장치다.
5. **권위 대비를 쓴다** — 아는 이름(삼성·SK·엔비디아)을 먼저 탈락시키고 모르는 이름을 남긴다.
6. **금지**: 목차 선언("세 가지를 다뤄보겠습니다"), 인트로 CTA, 결말 조기 공개, 도입부 딴 이야기.

| 4단 | 9~13분 | **정면 대결, 대등 확인.** 이기지 않았는데도 '대등'이 자부심을 굳힌다 | 자부심 정점 |
| 5단 | 13~17분 | **의도적 찬물.** 학습 불가 / CUDA 락인 / 매출 1토막 / 점유율 상승 / 방한 명단에 없음 | 급락 → **분함** |

핵심은 결론(전기)을 **영상의 약 65% 지점까지 미뤄뒀다**는 것. 26분 체류를 지탱한 건 정보량이 아니라 **인트로에서 심은 질문 하나**다. 5단에서 이탈이 안 나는 이유는 3~4단에서 시청자가 이미 "우리 편"이 됐기 때문 — **자부심이 꺾이면 사라지는 게 아니라 억울함으로 상이 바뀐다.**

### 관찰 — 전달 기법

**비유**: 세 편 중 001·002 두 편이 공통으로 **표현을 매번 바꿔가며 20회 이상** 썼고, 003은 **일상 비유가 단 하나도 없다**(→ 부진). 001의 비유는 전부 **주방·책상·학교·통장·물통** 등 살림 반경 안에서만 만들어졌다.

**숫자 — 001의 최대 기술이자 002·003과 갈린 지점**
001은 숫자를 던지지 않고 **항상 짝을 지어 대립**시킨다: 320억 vs 1205억 / 1 vs 0.9 / 144 vs 141 / 66% vs 74% / 26.7억 vs 7.31억 / 160억 vs 2069억 / 몸값 3조4천 vs 완전자본잠식. **단독 숫자가 거의 없다.** 그래서 밀도가 높은데도 나열형으로 안 읽힌다.
반면 002는 "7개월 / 2.25배 / 3.75배 / 100장 / 27장 / 73장"을 연달아 쏟고, 003은 "전력 효율 10배, 경쟁사 NPU보다 100배, 4나노, HBM3E, 140억"을 한 문단에 몰았다.

**살림 착지 — 전기요금이라는 단일 통로**
- 001: "그 전기값이 결국 **우리 집 고지서**로 넘어오기 때문이에요" / "그 부담은 **가정하고 공장의 고지서로 조용히 스며듭니다**"
- 002: 같은 전력 소재를 쓰고도 **기업 운영비에서 멈췄다.**
- 003: "전력 효율 10배"를 그대로 방치.
→ 반도체 주제에서 시니어를 붙잡는 **가장 짧은 다리는 전기요금 하나**다. 통로를 여러 개 만들지 않는다.

**스토리텔링**: 001·002 모두 창업자 서사 + 사명의 뜻 풀이를 썼다(공통 뼈대). 001은 이걸 **스펙 비교 앞에** 배치해서 이후 스펙 구간이 응원전으로 읽히게 만들었다. 002는 6번 블록(중반)에 배치.

### 설계 원칙 — 감정 체크리스트

1. **1순위 감정은 자부심이 아니라 '국가 역할론(사명감)'이다.** 001은 이걸 후반 5분에 몰아넣었는데 댓글이 전부 거기서 나왔다. → **우리는 2회 터뜨린다**: 8~9분(1차, 짧게 "이건 회사 하나 문제가 아니다") + 13~17분(2차, 전기·주권·고지서로 본격 폭발).

3. **"국뽕사기" 방어를 감정 장치로 쓴다.** 출처 구분 문장은 정보가 아니라 **신뢰라는 감정 자원**이다. 1분 안에 1회 + 성취 제시 직후 1회, 총 2회 이상.

5. **"망해도 남는 게 있다"는 안전망 문장을 우리가 먼저 준다.** 001에선 시청자가 스스로 만들어냈다(좋아요 24). 대본이 먼저 짚어주면 감정 착지가 훨씬 편해진다. 7단에 배치.
6. **대만·중국 축을 한 번 켠다.** 003 최다공감이 이미 원하고 있다. "엔비디아가 TSMC에 묶여 있다 → 대만이 흔들리면 → 우리 파운드리가 대안" 흐름은 국뽕과 반중을 동시에 태운다. 단 **피해자(한국) 시점 + 팩트 검증** 원칙 준수, 6단에 짧게.
7. **시니어가 직접 겪은 국산 제품 기억으로 한 번 더 번역한다.** 아래아한글 댓글(24)이 증거. 1980년대 메모리 선례 하나로만 끝내지 않는다.
8. **엔딩은 정보 정리 금지 → 장면 + 감정.** 003이 "신호탄이 될 것"으로 끝나 실패했다. 001도 시선으로는 끝냈으나 프로필의 **'시청자를 이야기 안에 위치시키기'가 빠져 있다 → 우리가 채운다.**

**001 제목이 작동한 4겹**
1. **절대 부정 수량어** — "엔비디아 없이"를 굳이 "**한 개도 안 쓰는**"으로 늘렸다. `0`을 수치가 아니라 **말투로** 박은 것
2. **어순: 유명 고유명사 먼저, 무명 나중** — `엔비디아` → `리벨리온`. 모르는 이름을 아는 이름의 무게에 얹어 **격상**시킨다. 뒤집으면 클릭이 안 나온다
3. **파이프(|) 뒤 권위자 인증** — 핵심은 조사 `도`. "젠슨 황**도**"는 그 바닥 최고 권위자**조차**라는 뜻이라, 검증 없이도 성취의 급을 한 단계 올린다
4. **다윗-골리앗 2단 압축** — 앞 절 = 골리앗의 부품을 하나도 안 썼다(**자립**), 뒤 절 = 골리앗 본인이 인정했다(**외부 승인**)

**003 제목의 심장 = 동사 선택**
"이겼다"도 "따라잡았다"도 아닌 **"허찔렀다"**. 약자가 강자의 빈틈을 찔렀다는 뜻이라 과장은 덜한데 통쾌함은 더 크다. **"이겼다"는 반박당하지만 "허를 찔렀다"는 반박이 애매하다** — 검증 부담은 낮고 감정 수익은 높은 동사.

**002가 실패한 이유**: 훅을 더 많이 넣어 **하나도 각인시키지 못했다.** "~할 수 있을까?"는 **답을 안 준다는 예고**로 읽힌다. 시니어에게는 "이미 일어난 일"이 "될까 말까"보다 항상 강하다.

### 썸네일-제목 역할 분담

**001 — 썸네일이 제목을 복사하지 않고 한 급씩 승격시켰다**

| | 제목 | 썸네일 |
|---|---|---|
| 사실의 급 | "한 개도 안 쓰는"(과정·상태) | "**AI 성공**"(결과 확정) |
| 인물 처리 | "놀랐다"(3인칭 서술) | "**나 필요 없다고??**"(1인칭 굴욕 대사) |
| 국적 | 표기 없음 | `MADE IN KOREA` 금색 각인 + 태극기 |

`나 필요 없다고??`가 감정의 결정타다. 제목의 "놀랐다"는 관찰자 서술이라 감정이 약한데, 썸네일은 그걸 **젠슨 황 본인의 입에서 나온 당황한 반문**으로 바꿨다. 정보가 아니라 **"우리가 저 사람을 당황시켰다"는 장면**이 팔린다.

**003 — 단어를 일부러 다르게 썼다**: 썸네일 `국산 AI칩`, 제목 `국산 괴물칩`. 썸네일 상행에 중립 사실을 두고 **화력은 전부 하행 빨간 따옴표 인용문에 몰았다.**

### 설계 원칙 — 패키징 체크리스트

**제목 (001 공식 계승 + 003 동사 차용)**
```
[세계 최강 브랜드] + [절대 부정 수량어] + [무명 국내사] | [권위자]도 [완료형 반응]
```
1. **어순 고정**: 아는 이름 → 모르는 이름. 절대 뒤집지 않는다
2. **절대 수량어로 숫자를 박는다** ("한 장도", "한 개도", "0장") — 프로필의 "제목에 숫자 필수"를 극단값으로 충족
3. **조사 `도`를 반드시 쓴다** — "~도 놀랐다/~도 인정했다"
4. **동사는 완료형·단정형.** 약자가 강자에게 하는 동사 계열(허를 찔렀다/판을 흔들었다급, 표현은 새로 짓는다)에서 고른다. **"이겼다"는 반박당하므로 피한다**
5. **장치 2개 이하, 35자 이내, 의문형 클로징 금지**
6. 후보 3안을 전부 concept.md·youtube.md에 수록하고 1순위로 진행

**썸네일 텍스트**
1. **메인 카피 2행 고정** (상단 11~12자 / 하단 10~12자, 공백 제외). 3행 이상 금지
2. **2층 구조**: 상행 = 중립적 사실(흰색), 하행 = 감정·인용(형광 노랑 또는 빨강). 003의 따옴표 인용 형식을 하행에 쓸 수 있다
3. **리액션 말풍선 1개(2~6자) 필수** — 인물의 1인칭 굴욕/당황 대사. 001 최대 무기
4. **제목을 복사하지 않는다.** 제목이 과정이면 썸네일은 결과, 제목이 3인칭이면 썸네일은 1인칭
