## 1. 검증된 제목 공식

### 레퍼런스가 증명한 골격 (구독 9만 채널이 46만뷰 = 5.2배 외부 노출 돌파)

```
"[구어체 인용 선언]" + [국민 인지 브랜드 A] + [사건 명명] + [경쟁사 B의 반응]
```

3요소 분해:
| 구성 | 기능 | 대체 불가 이유 |
|------|------|--------------|
| 따옴표 구어체 인용 | 회사가 아니라 **사람이 말한 것처럼** 들려 장면이 그려짐 | 뉴스체 제목과의 결정적 차이 |
| 국민 인지 브랜드 2개 정면 대치 | 사전 설명 0. 전 국민이 매일 쓰는 서비스 | 설명이 필요한 순간 CTR이 죽는다 |
| 3자 반응("초비상") | 화자가 우기지 않고 **사건 크기를 간접 증명** | 자화자찬형 제목보다 신뢰 높음 |

### 채널 가이드와의 정합 판정

pd-guide.md "강대국 몰락형/한국 급소형" 골격은 **비적용**(국내 기업 대결). 따라서 이식 항목만 적용:
- ✅ **구체적 숫자를 제목에 하나 박는다** — 레퍼는 숫자 0개였으나, 우리 채널 히트 DNA는 숫자를 요구한다. **인용 구어체 + 숫자 병행**이 이번 제목의 승부처.
- ✅ 결핍·반전 훅 1개 포함
- ❌ "충격/소름/세계 최초/근황" 류 추상 과장어 금지
- ❌ 공포·클릭베이트 시그니처 금지

### 결론 처방
> `"[구어체 결핍/선언 인용]" + [브랜드 대치] + [구체 숫자] + [반응·이유형 종결]`

## 2. 검증된 훅 전략 (hook_strategy: paradox)

### 레퍼런스 훅의 구조
기업 뉴스인데 **회사 이름으로 시작하지 않는다.** 시청자의 신체 경험 장면으로 연다.
- 시간 좌표("밤 11시") + 행동("주문 버튼") + 장소("문 앞") = 머릿속 자동 재생
- 이 장면이 후반 반전의 복선으로 회수되어 **훅과 결론이 하나의 고리로 닫힌다**

### 채널 hook_strategy(paradox)와 결합한 처방
- 생활 장면으로 열되, **모순 한 줄을 즉시 박는다**: "그 편리함이 사실은 선택권을 뺏어간 대가였다면?" 류
- 첫 15초 안에 기업명 등장 금지. 시청자 본인 이야기로 먼저 묶는다
- profile.md 열린 고리 필수 규칙 충족: 도입부 미해결 질문 1개 → 후반 회수

## 3. 검증된 본문 구조 — "자기부정 3단"

레퍼런스 26분을 지탱한 최대 장치는 나열이 아니라 **자기 논지 꺾기**다.

```
공감 훅 → 판 세팅 → 대조 성장사 → 약점 지목 → 빌드업 → 폭로(제목 회수)
→ 상대의 위기 → 공세 → ★자기부정(반론) → ★재반론 → ★대반전 → 근본 강점 → 남은 숙제 → 착지
```

★ 3단(전체의 약 68~72% 지점 배치)이 후반 이탈 방지의 핵심:
1. **반론** — "그런데 정말 그럴까" 식으로 자기 주장을 스스로 공격
2. **재반론** — 도전자 측 카운터 근거 제시
3. **대반전** — 기대와 반대되는 현실 데이터 제시

> profile.md 선호 서사("겉으로는 X인데 속은 Y")와 정확히 일치. pd-guide 서사 구조 표에서는 **비교형 + 추적형 혼합**에 해당.

## 4. 검증된 리텐션 장치

### 체인 오픈루프 (26분 동안 약 12개)
하나가 닫히면 다음이 열리는 연쇄 구조. 브릿지 공식은 **"그런데 + 여기서 + 예고"** 3요소.
> ⚠️ 공식(구조)은 차용하되 **레퍼 문장 35개는 전량 금지**(analysis.md 8절 대조표).

### 우리가 쓸 브릿지 유형 (문장은 새로 쓴다)
| 유형 | 배치 |
|------|------|
| 메인 오픈루프 선언(질문 연타) | 인트로 끝 |
| 약점 예고 | 초반 |
| 자문자답 + 즉시 부정 | 중반 |
| 사건 예고 브릿지 | 중반 |
| 논조 반전 스위치 | 중후반 진입 |
| 기대 배반 → 재집중 | 후반 |
| 프레임 전환 착지 | 결론 |

**간격 규칙**: 2~3분마다 최소 1개. 빈 구간 없이 전 구간 분포.

### 숫자 밀도
약 90초당 1개. 그리고 **숫자 직후 반드시 체감 환산** — profile.md 정보 전달 방식과 동일.
- 예: "3,370만 명" → "우리나라 인구 절반이 훌쩍 넘는"
- 예: "22.7% vs 20.7%" → "열 번 중 네 번은 이 둘 중 하나"

### 제3자 화법 (레퍼 최대 차별점 → 우리도 계승)
화자가 주장하지 않고 **남에게 말하게 한다**: 경쟁사 관계자 발언 / 실제 시청자·판매자 목소리.
효과: 편들기 인상 제거 → 신뢰 상승, 참여감 → 댓글 유발.

## 5. 검증된 감정 곡선

```
공감/향수 → 기대 → 반감 → 통쾌 → 냉정한 의심 → 허탈 → 재기대 → 이득감
```

- 지배 감정: **통쾌한 하극상 응원**. 도전자를 의도적으로 언더독으로 포지셔닝한 뒤 반격시킨다
- 후반 "허탈 → 재기대" 낙차가 클수록 마지막 응원 감정이 단단해진다
- 결론에서 **승패 판정을 유보**하고 판단 권한을 시청자에게 넘겨 댓글 토론 유도

### 채널 정서 필터 (자체 히트 DNA)
- **국내기업 응원 / 외국자본 반감** 축이 이 주제의 숨은 연료 — 레퍼는 한 번도 안 건드렸는데 시청자가 스스로 댓글로 꺼냈다. **우리는 팩트 기반으로 정면 배치한다**(감정적 매도 금지, 검증된 팩트만, 판단은 시청자에게)
- 피해자/소비자 시점 유지. 가해자·기업 시점 서술 금지

## 7. 착지(엔딩) 처방

레퍼의 "승자 미정, 수혜자는 소비자" 결론은 **이미 소진**됐고 댓글로 복창까지 됐다. 그대로 쓰면 복제다.
profile.md 엔딩 규칙(개별 사안을 넘어서는 한 줄 통찰)에 맞춰 **한 단계 위로 격상**한다.
방향: 편리함에 길들여진 것이 아니라 **선택권을 되찾는 문제**로 프레임 이동 → 시청자 자신의 소비·일·투자에 적용되는 메시지.
