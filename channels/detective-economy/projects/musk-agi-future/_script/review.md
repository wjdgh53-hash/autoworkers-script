## 치명적 항목 수정 지시

> ⚠️ **가장 중요한 원칙(tone-guide §4-1).** 아래 12개는 전부 "표현을 지우라"는 지적이다.
> **지운 자리를 숫자·날짜·기관명으로 때우지 마라.** 지워야 할 게 문장이면 채워야 할 것도 문장이다.
> 현재 숫자 밀도가 4.9로 여유가 크다고 해서 수치를 새로 넣는 방향으로 가면, 독창성은 고치고 톤을 망가뜨리는 최악의 교환이 된다.
> 그리고 **복제 표현을 되살려 다른 지표를 맞추는 것은 어떤 경우에도 금지**다.

### 위반 ① — 파트 6, 127행

```
현재: 그런데 좋은 얘기만 골라 드리면 그건 반쪽입니다.
```
001 원문 `물론 좋은 얘기만 골라드리면 그건 거짓말이겠죠`에서 명사 하나만 바꾼 것이다. **문장 골격을 통째로 버린다.**

```
수정 예: 그런데 이 얘기, 뒷장이 하나 더 있습니다. 자랑만 하고 끊으면 그건 반쪽짜리죠.
       또는: 여기까지가 어깨 펴는 얘기고, 이제 계산서를 봐야 합니다.
```
**outline 파트 6 핵심내용 6번의 지시 문장도 함께 고쳐야 한다.** outline이 001 금지 표현을 그대로 적어 내려보낸 것이 이번 사고의 발원지다.

### 위반 ② — Intro 5행 + 클로징 139행

```
현재(Intro): 다만 언제 되냐는 얘기는 반쯤 접어 들으셔야 해요.
현재(클로징): 그러니 날짜는 반쯤 접어 들으시고, 방향은 접어 두지 마십시오.
```
001 `그러니 날짜는 좀 걸러들으셔야 합니다`와 부사구만 다르다. concept.md가 "전부 배제" 확인했다고 적은 항목이므로 **반드시 두 곳 모두 교체한다.**

```
수정 예(Intro): 다만 몇 년도라는 말만큼은 그대로 믿으시면 안 됩니다.
수정 예(클로징): 그러니 몇 년도라는 말은 흘려보내시고, 어디로 가느냐만 붙잡으십시오.
```
Intro는 outline·hook-intro.md와 일치해야 하는 구조 항목이므로, **outline 19행과 hook-intro.md도 같은 문장으로 함께 갱신한다.** 대본만 고치면 다음 검수에서 구조 불일치(치명적)로 걸린다.

### 위반 ③④ — 감정 전환 선언 2건 (파트 3 53행 / 파트 6 119행)

```
현재(파트3): 불안한 얘기만 내리 했는데, 여기서 결이 한 번 바뀝니다.
현재(파트6): 여기서 분위기가 한 번 바뀝니다.
```
파트 6은 001 원문과 **완전히 같은 문장**이다. 감정 전환을 말로 선언하는 **기법은 유지하고, 문장을 새로 짓는다.** 두 자리가 서로 달라야 한다는 점도 함께 지킨다.

```
수정 예(파트3): 여기부터는 앞이랑 얘기가 좀 다릅니다. 지금까지는 계속 뺏기는 쪽만 봤잖아요. 이번엔 반대쪽입니다.
수정 예(파트6): 자, 이제 어깨 좀 펴셔도 되는 대목입니다.
```

### 위반 ⑤⑥⑦ — 파트 3 저울 대목 (55행·67행)

레퍼 001의 「고무줄자 → 분노에 이름 붙이기 → 화살을 시스템으로」 3연속 구문이 사물만 저울로 바뀐 채 통째로 이식됐다. **저울 비유 자체는 우리 고유이므로 살린다. 그 비유를 태우고 있는 문장들을 갈아엎는다.**

```
현재(55행): 왜 늘 뒤가 없는 쪽만 손해를 보는 것 같습니까.
            … 사람들이 화가 난 건 저울에 올라간 것 자체가 아니에요.
            저울추가 손님 따라 바뀐다는 것, 딱 그겁니다.
현재(67행): 부수자는 얘기가 아닙니다. 저울은 다시 맞출 수 있어요.
```

```
수정 방향(55행):
 · "왜 늘 ~ 손해를 보는 것 같습니까" 골격을 버린다.
   → 예: "그럴 때 드는 기분, 다들 아실 겁니다. 나만 순서를 못 얻은 것 같은 그 기분이요."
 · "화가 난 건 X 자체가 아니라 Y다" 골격을 버린다. 저울 쪽에서 새로 짓는다.
   → 예: "달아 보는 게 싫은 사람은 없습니다. 앞사람 저울하고 내 저울이 다르다는 걸 알아버린 게 문제죠."

수정 방향(67행):
 · "부수자는 게 아니라 바로잡힐 수 있다" 골격을 버린다.
   → 예: "저울을 엎으라는 얘기가 아닙니다. 추 하나 갈아 끼우면 되는 일이거든요.
          눈금이 틀어진 걸 온 시장이 알아버린 날, 그날부터가 이미 고쳐지는 중입니다."
```
**"어떤 사람도 아니고 어느 편도 아닙니다"라는 방향(분노를 시스템으로)은 절대 건드리지 않는다.** 정치 시비 차단선이다.

### ⑬ 데이터센터 풀이 반복 — 파트 6, 129행

outline에 `[회수]` 표시가 없다. 용어 순화표의 대체어일 뿐이므로 **설계된 오픈루프가 아니라 두 파트가 각자 처음 소개하듯 푼 것**이다. 파트 4에서 이미 풀었으니 파트 6은 짧게 받기만 한다.

```

        우리 아파트 옆이라면 얘기가 완전히 달라져요.
```

### ⑭ 친근함 장치 하한 미달 — 말 걸기 0.3 / 쉽게 풀어주기 0.7

> ⚠️ **"들어는 보셨을 겁니다" 같은 문구를 파트마다 하나씩 뿌리는 방식은 반대한다.** 그건 수치만 올리고 대본을 어색하게 만든다. tone-guide §1 대조쌍처럼 **그 자리에 원래 필요했던 문장을 만들어 넣는다.**

**말 걸기 — 파트 1·2·3에 몰려 있고 파트 4·5·6이 비었다.** 채울 자리가 실제로 있다.

| 자리 | 왜 여기인가 | 넣을 문장 |
|---|---|---|
| 파트 4, TSMC 첫 등장(79행) | 낯선 고유명사를 던지는 자리. 시니어가 가장 겁먹는 지점이다 | "TSMC라는 이름, 뉴스에서 한 번쯤 스쳐 들으셨을 겁니다." |
| 파트 4, 전기 대목(81행) | 시청 상황 자체를 끌어들일 수 있는 유일한 자리 | "지금 이 영상도 어딘가 그 창고 안에서 돌아가고 있는 겁니다." |
| 파트 5, 노트북(101행) | 손주 노트북은 이 시청층의 실제 지출 장면이다 | "요즘 전자상가 한 바퀴 돌아보신 분들은 무슨 말인지 아실 겁니다." |

**쉽게 풀어주기 — 현재 `쉽게 말하면` 4회가 전부이고 변주 문구가 없다.** 상한은 정형구에만 걸린다. 아래는 정형구가 아니라 새 문구이므로 상한과 무관하다.

### ⑮ 개념 설명 6.9% → 8% 이상

가장 얇은 곳이 **파트 1의 "코드"**다. 현재 `그러니까 프로그램을 굴러가게 만드는 글자들 말인데요` 한 마디로 끝났다. tone-guide §1 ①의 ❌ 사례와 같은 형태다. 정의 → 일상 사물 → 생활 비유 3단으로 늘린다. 장부 비유(11행)가 이미 3단째에 해당하므로 **가운데 한 칸만 채우면 된다.**

```
추가 예: 컴퓨터한테 이거 해라 저거 해라 순서대로 적어 놓은 글이 코드입니다.
        은행 현금인출기도, 손에 들고 계신 그 휴대폰도, 결국 누가 그 글을 한 줄 한 줄 적어 놨기 때문에 굴러가는 거예요.
```
파트 6 HBM도 정의 + 책상 비유 2단에서 멈췄다. 생활 비유 한 칸을 더하면 이 항목과 ⑭가 함께 올라간다.

```

```
