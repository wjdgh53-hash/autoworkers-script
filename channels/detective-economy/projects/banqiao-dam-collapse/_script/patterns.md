# 반차오댐 붕괴 — 공통 성공 패턴 & 설계 원칙

> 분석 대상: 001 `주린이경제학`(조회 534,077 / 좋아요 11,988) · 002 `운명의 비행`(조회 109,138 / 좋아요 2,342)
> hook_strategy: **paradox** → 훅 분석(관찰 A) + 역설 소재 수집(관찰 B) 모두 수행
> ⚠️ 001이 002 대비 조회수 약 4.9배. 공통 패턴을 뼈대로 삼되, 충돌 시 001의 검증된 선택에 가중치를 둔다.

## 1. 반복되는 훅 공식 & 역설 소재

### 관찰 A — 레퍼런스 훅 분석

**두 영상 훅 원문 비교:**

- **001**: "하룻밤 사이에 24만 명이 죽었습니다. 도시 하나가 지도에서 그냥 사라졌어요. **근데 놀랍게도 이 사건 이름 들어보신 분 거의 없습니다. 왜냐? 그 나라가 30년을 통째로 숨겼거든요.**"
- **002**: "마오쩌둥 (…) 대약진 운동을 떠올립니다. 하지만 그 댐들 가운데 일부가 **체르노빌보다도 타이타닉보다도 (…) 더 많은 희생자를 낳은 비극을 만들어냈다는 사실을 아는 사람은 많지 않습니다.**"

**공통 훅 패턴 (2개 모두 반복):**

1. **규모 충격 + 무지의 역설** — 거대 숫자(24만/23만 사망)를 던진 직후 "그런데 당신은 이걸 못 들어봤다"로 인지 부조화를 만든다. 두 영상 모두 "가장 큰 재난인데 왜 나만 몰랐지?"를 첫 문장에서 강제한다.
2. **은폐 프레임 즉시 설치** — 001 "30년을 통째로 숨겼거든요" / 002 "30년 동안 역사에서 지워져 있었습니다". 무지의 원인을 "은폐"로 지목해 호기심을 분노로 전환.
3. **누구나 아는 앵커로 규모 환산** — 001 "체르노빌을 사망자 60배로 제친" / 002 "체르노빌보다도 타이타닉보다도". 유명 재난을 저울에 올려 낯선 사건의 규모를 즉시 체감시킴.
4. **열린 고리 인물 심기** — 두 영상 모두 "경고했다가 축출·유배된 엔지니어(천신)"를 인트로에 미끼로 심는다. 001 "이 천신이라는 이름 기억해 두세요. 뒤에 다시 나옵니다" / 002 "이 참사를 정확히 예견했던 한 사람이 있었습니다. 하지만 (…) 유배되고 말았습니다".

**인트로 공통 역할:** 규모 재확인 → 국내/유명사건 비교 환산 → 현재진행형으로 격상(001 광시 재발 / 002 삼협댐) → 완주 예고.

**시청자 관심 방향 요약:** 시청자는 "24만 명이 죽은 초대형 참사가 존재하는데 왜 나는 몰랐는가(정보 격차)"와 "누가 이걸 숨겼고 그 대가는 무엇인가(은폐 분노)" 두 축의 궁금증에 반응한다. 규모의 충격보다 **은폐라는 배신감**이 클릭·완주의 진짜 엔진이다.

### 설계 원칙 (paradox 모드)

- **훅 소재 풀 확정 (포텐셜 상위 5개):**
  1. "체르노빌 60배 최악 참사인데 아무도 모른다" — 규모+무지 역설
  2. "물에 죽은 10만보다, 물 빠진 뒤 방치로 죽은 14만이 더 많다" — 인과 역전(최대 반전 카드)
  3. "천재지변인 줄 알았는데 흙으로 쌓고 철댐이라 우긴 인재였다" — 인과 역전
  4. "인재를 인정 못 해서 24만 죽음을 30년간 숨겼다" — 결과 모순(분노 앵커)
  5. "옳은 말을 한 전문가가 가장 먼저 잘려나갔다" — 행동 모순(인물 고리)
- **관심 방향 부합 우선순위:** 시청자 최대 반응이 "은폐 분노"에 있으므로, 훅은 규모 숫자로 시작하되 **3문장 안에 반드시 "숨겼다"를 심는다.** 은폐 없는 규모 나열은 001/002 어느 쪽도 하지 않았다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 — 두 영상의 배치 순서가 거의 동일:**

| 단계 | 001 | 002 |
|------|-----|-----|
| ① 원죄(부실 배경) | 1950년대 애국 경쟁으로 급조 | 마오 산업화 야망, 졸속 건설 문화 |
| ② 경고 묵살 | 천신을 "우파"로 몰아 축출 | 천신을 "우익"으로 몰아 유배 |
| ③ 부실 누적 | 흙+돌 댐, 수문 부족, 62개 동일 | 소련 철수·문혁·퇴적·방재물자 전무 |
| ④ 방아쇠(자연) | 태풍 니나 6시간 831mm | 태풍 니나 6시간 830mm |
| ⑤ 붕괴의 밤(3중 실패) | 수문 막힘+방류 지연+통신 두절 | 개방 지연+통신 두절+물자 미비 |
| ⑥ 1차 참사 | 물벽이 마을 덮침, 10만 익사 | 62개 연쇄 붕괴, 8.6만 익사 |
| ⑦ **반전(2차 참사)** | 고립·기근·전염병 14만 추가사 | 전염병·기근 14만 추가사 |
| ⑧ 은폐 | 체제가 틀렸다는 뜻 → 30년 은폐 | 당·마오 체면 → 보도 통제 |
| ⑨ 현재 연결 | 2026 광시 재발, 인구 67% 취약 | 삼협댐·2021 정저우 홍수 |
| ⑩ 삶으로 착지 | 강남 침수·밥상 물가 | 보편 교훈("침묵 강요=다음 비극") |

→ **공통 서사 뼈대:** `원죄(부실) → 경고 묵살 → 방아쇠(태풍) → 붕괴 → 1차 참사 → 숨은 2차 참사(반전) → 은폐 → 현재 재발 → 내 삶으로 확장`. "겉(천재지변)은 X인데 속(인재·은폐)은 Y"의 몰락+폭로 반전 구조. 채널 프로필의 선호 서사와 정확히 일치.

**전달 기법 (공통):**

- **비유 = 추상 수치의 시각 장면화** — 001 "종이배 접어놓고 잠수함이라 우기는 격", "어마어마한 양동이에 배수구는 딸랑 몇 개", "강에서 튀어나온 용(물벽)" / 002 "올림픽 수영장 28만 개", "싱가포르 면적 16배 임시 호수", "삶은 국수처럼 뒤틀린 철로", "2층집 두 배 높이 물의 벽". 두 영상 모두 숫자가 나올 때마다 즉시 비유를 붙인다.
- **숫자 = 대비 쌍으로 제시** — "설계 기준 300mm vs 실제 831mm", "물에 죽은 10만 vs 방치로 죽은 14만", "체르노빌 vs 그 60배". 단독 숫자가 아니라 항상 기준점과 짝지어 충격을 만든다.
- **인물 아크 = 서사의 축** — 두 영상 모두 엔지니어 천신을 초반에 심고(경고→축출) 후반에 회수(재난 후 명예)한다. 002는 증언자(우프탕·웨이더팡·샹샤오미)까지 1인칭으로 붙여 참상을 생생화.

**리텐션 장치 (공통 배치):**

- **인트로 오픈루프(메인 고리):** "천신 기억해 두세요"(001) / "예견했다 유배된 한 사람"(002) — 인물 정체를 후반까지 미룸.
- **중반 숫자 불일치 훅:** 001 "10만인데 24만이면 나머지 14만은 어디서? 진짜는 물이 다 빠진 지금부터" — 최대 궁금증 유발 후 2차 참사로 전환.
- **가짜 안도 → 반전:** 002 "물이 빠지고 있다 (…) 하지만 관리의 얼굴이 창백해졌습니다. 물이 저절로 사라질 리 없다" — 안도 직후 최악으로 뒤집는 서스펜스.
- **미결 질문 후 응답:** 002 "왜 아무도 대피 경고를 안 했을까요?" / 001 "그 많던 소리가 왜 갑자기 멈췄겠어요? 거기까진 차마 더 말 못 드리겠습니다"(절제·여백).
- **판단 참여 엔딩:** 001 "여러분이 판사라면 진짜 범인은? 1번 천재지변 / 2번 인재 / 3번 은폐".

### 설계 원칙

- **본론 뼈대는 위 10단계를 그대로 채택하되, ⑦ 2차 참사(반전)를 클라이맥스로 설계한다.** "물이 다 빠진 지금부터가 진짜 지옥"이라는 전환을 영상 중반(50~60% 지점)에 배치해 후반 이탈을 막는다.
- **비유 배치 규칙:** 추상적 수치(사망자·유량·면적·높이)가 나올 때마다 반드시 1개 비유를 붙인다. 비유는 "우리 일상 스케일(수영장/집/도시 인구)"로 환산 — 채널 정보 전달 방식(숫자→비유)과 일치. ⚠️ 단, 위 레퍼 비유 표현("종이배·잠수함", "삶은 국수", "강에서 튀어나온 용" 등)은 **그대로 복제 금지**. 개념만 차용하고 표현은 새로 만든다.
- **숫자 규칙:** 모든 핵심 숫자는 대비 쌍(기준 vs 실제, 1차 vs 2차)으로 제시한다. 단독 숫자 나열 금지.
- **인물 고리 필수:** 천신(경고한 전문가)을 초반에 심고 후반에 회수하는 메인 오픈루프 1개를 반드시 설치. "옳은 말을 한 사람이 먼저 잘렸다"는 행동 모순이 분노 축을 만든다.
- **리텐션 배치:** 중반 파트 전환 직전마다 "숫자 불일치 훅" 또는 "가짜 안도→반전"을 1개씩 심는다. 엔딩은 반드시 선택지형 판결 CTA로 마무리.
