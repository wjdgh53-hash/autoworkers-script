## 1. 반복되는 훅 공식 & 역설 소재 수집

### 관찰 A — 레퍼런스 훅 분석

**훅 원문 나란히 비교**

**공통 훅 패턴**
- **두 영상 모두 "결론/충격을 맨 앞에 당겨 붙인다."** 001은 미래 통계(324만 채)를, 002는 대담 후반의 결론(지방=서울 짝퉁)을 첫머리로 끌어와 "왜 그런가?"라는 역질문을 심는다.
- **질문형으로 무지를 자극한다.** 001 "알고 계세요?" / 002 인트로 "서울로 사람이 이렇게 몰리는 이유가 뭘까요?" — 답을 미뤄 궁금증을 축적.
- **추상을 즉시 체감 단위로 환산한다(001의 강점).** "324만 채" → "백채 중 13채" → "동네 한 블록이 통째로 비는 풍경". 큰 숫자→체감 단위→시각 장면의 3단 압축.

**인트로 공통 역할**
- 시청자의 실생활 고통을 즉시 건드림: 001은 "10억 오르고 옆은 5억 빠진다"(내 자산 위협), 002는 "싼 집이 아예 없어졌다"(체감 고통).
- **열린 고리 설치.** 001 "어떤 단지는 10억 오르고 바로 옆지는 5억 빠집니다"(왜 옆인데 갈리나?) / 002 "그럼에도 왜 사람들은 서울로 몰릴까?" — 본문 내내 미뤄뒀다 후반에 회수.
- 시청 보상 명시(001이 특히 강함): "4가지 기준 + 집 볼 때 체크리스트까지 다 알려드릴 겁니다. 끝까지 보면 보는 눈이 완전히 달라져요."

**시청자 관심 방향 요약**
> 두 훅이 공통으로 건드리는 것은 "내가 가진(혹은 사려는) 집이 앞으로 어느 편에 서게 되는가"라는 **자산 불안**과 "상식(인구 줄면 집값 하락 / 비쌀수록 떠난다)과 반대로 굴러가는 현실"에 대한 **모순 해소 욕구**다.

### 설계 원칙 (paradox 모드)

**훅 소재 풀 확정 — 포텐셜 상위 5개**
1. **"인구 줄어드는데 왜 어떤 집은 오히려 오르지?"** (001) — 하락장 속 양극화. 시청자 관심 방향(자산 불안)과 가장 직접 부합. **메인 열린 고리 후보 1순위.**
2. **"비쌀수록·가난할수록 오히려 서울을 못 떠난다"** (002) — 행동 모순. 밀도(시냅스) 원리로 해소.
3. **"같은 구, 바로 옆 단지인데 10억 오르고 5억 빠진다"** (001) — 가장 구체적 숫자 모순. 훅 첫 장면으로 강력.
4. **"빈집 900만 채·0엔 주택인데 도쿄 도심은 강남보다 비싸다"** (001) — 해외 실증. 미래 증명용.
5. **"똑같은 아파트가 되자 집이 화폐가 됐다"** (002) — 익숙한 것을 낯설게 만드는 반전 프레임.

**훅 설계 규칙**
- 첫 문장은 **충격 숫자 또는 결론을 먼저 던지고**, 3초 안에 체감 단위로 환산한다("324만 채 → 백채 중 13채"). 통계로 시작해 통계로 끝내지 말 것.
- 훅 직후 **모순 장면 하나를 열린 고리로 박는다**("옆 단지인데 왜 갈릴까"). 이 질문은 후반까지 답하지 않는다.
- 상위 5개 소재는 creative-strategy Phase 3의 역설형 훅 생성 입력으로 넘긴다. 그중 #1(하락장 속 양극화)을 메인 고리로 우선한다.

### 설계 원칙

- **본론 뼈대: 현상(양극화 충격) → 원인(인구 붕괴) → 기존 상식 붕괴(집값 정답의 무효화) → 새 기준(살아남는 집) → 해외 실증(일본) → 요약 → 실전 체크리스트 → 삶의 통찰.** 각 단계는 앞 단계의 "그래서 왜?"에 답하는 방식으로 연결한다. 절대 병렬 나열하지 말 것(채널 profile 기피 사항).
- **비유는 추상 개념·경제 용어가 등장하는 즉시 배치.** profile 시그니처 "쉽게 말하면"을 이 지점에 쓰되 영상당 최대 4회. 예: "빈집세", "양극화", "화폐화" 같은 단어가 나오면 바로 일상 장면으로 환산.
- **숫자는 반드시 대비 쌍으로.** 단독 수치 금지. "324만 채" 던지면 즉시 "백채 중 13채 / 동네 한 블록"으로, "출생아 23만"이면 "30년 전 70만의 1/3"로 묶는다(채널 profile 정보 전달 방식과 일치).
- **리텐션 장치 배치 규칙**: (1) 초반에 메인 열린 고리 1개 필수 설치("옆 단지인데 왜 갈릴까"). (2) 파트 전환 직전마다 오픈루프 또는 브릿지 멘트로 다음 파트 궁금증을 심는다. (3) **후반에 반드시 초반 고리를 명시적으로 회수한다** — profile 필수 항목 "앞에서 던진 질문 기억나시죠?" 식으로. 001의 "우연이 아니에요"가 모범 사례.
- profile 시그니처 "근데요, 여기서 진짜 핵심은"은 학군·역세권 붕괴 → 새 기준 전환 같은 **최대 반전 포인트에만** 배치(영상당 최대 2회).

- **1순위 감정은 '위기감 + 통쾌한 모순 공감'.** 001 최다 공감 댓글(55/44/34)이 모두 "나는 어느 편? / 이 상황은 비정상 / 집주인 통쾌"에 몰렸다. → **초반 2분 안에 "빈집 324만·옆 단지 5억 격차"로 위기감을 쌓되, 동시에 "인구 줄면 집값 떨어져야 정상인데 왜?"라는 모순을 시청자 대신 말해줘 공감(통쾌함)을 함께 터뜨린다.**
- **감정 흐름 설계 가이드**: 위기감·모순 공감(초반 30%) → 호기심(중반 40%, 열린 고리 유지) → 안도·통제감(후반 30%, 실전 체크리스트) → 마지막 한 줄 통찰로 격상.
- **후반 안도 파트를 반드시 '내가 통제 가능한 행동'으로 만든다.** 001이 공포를 "오전·오후 두 번 방문 / 평면도 동선 확인 / 입주민 카페 분위기 체크"라는 체크리스트로 전환한 것이 안도감의 핵심. 추상 조언 금지, 당장 실행 가능한 행동 지침으로.
- **댓글에서 드러난 반론을 선제 방어.** 001 시청자는 "커뮤니티는 퇴보다/혼자가 편하다"(31·24 공감)로 4번째 기준에 반발했다. → 커뮤니티 관련 소재를 쓸 땐 "사교 강요"가 아니라 "고립·고독사 방지"로 프레이밍. "서울·수도권도 안전한가?"(최다 공감 55)는 반드시 구체 단지 예시로 다룬다. "빈집세" 정책은 시청자가 스스로 꺼낸 관심사이므로 짧게라도 언급하면 공감 유발.
