## 1. 반복되는 훅 공식 & 역설 소재 수집

### 관찰 A — 레퍼런스 훅 분석

**두 영상 훅 원문 나란히 비교**

| 영상 | 훅 첫 문장 (원문) | 훅 유형 |
|------|-----------------|--------|
| 001 (18.4만) | "미국도 못 만드는 렌즈가 있습니다. 이유는 장비입니다. (…) 전 세계에 딱 두 대. 한 대는 싱가포르, 한 대는 대전." | 역설적 선언 + 희소성 숫자 |
| 002 (11.6만) | "연봉 35억 원. 우리 돈으로 평생 만져 보기도 힘든 액수죠. (…) 그런데 이 과학자 단 한 번의 고민도 없이 거절했습니다." | 큰 숫자 → 비상식적 선택 (인지 부조화) |

**공통 훅 패턴 (2편 모두)**
- **상식 파괴 선언을 첫 문장에 배치**한다. 001은 "미국도 못 만든다"로 미국>한국 통념을 깨고, 002는 "35억을 고민 없이 거절"로 손실-회피 상식을 깬다. 둘 다 "왜?"라는 미결 질문을 강제로 심는다.
- **"거절"이라는 역설 행동을 미끼로 공유**한다. 002는 훅에서 직접 사용, 001은 인트로 첫머리("구글의 연봉 35억 제한을 거절하고")에서 사용. 두 영상 모두 "구글 35억 거절"을 최상위 후크로 쓴다.
- **인물의 정체를 끝까지 숨긴다.** 두 제목 모두 이름 대신 "한국인 과학자" / "정체"로 처리 → 클릭 유인.

**인트로가 공통으로 수행하는 역할**
- **결말/성과 정점을 미리 압축 스포일러**로 던진다. 001: "네이처가 같은 사람 논문 두 편을 동시에 실었습니다. (…) 노벨 재단이 움직였습니다. 전 세계 26명만 부르는 자리." 002: "이 렌즈 하나가 지금 전 세계 카메라 산업과 디스플레이 산업의 판도를 통째로 뒤흔들고 있습니다."
- **강력한 오픈루프로 본문에 진입**시킨다. 001: "그런데 이 사람이 원래 만들려고 한 건 렌즈가 아니었습니다." 002: "그 선택의 진짜 의미가 몇 년이 지난 지금 드러나고 있습니다."
- ⚠️ 002는 인트로에서 채널 **금지 표현 "오늘은"**을 그대로 사용("오늘은 노준석 교수의 이야기를 해보려고 합니다") → **우리 영상에서는 반드시 회피**.

**시청자 관심 방향 요약**
두 훅이 공통으로 건드리는 것은 **"세계 최고(구글/미국)를 마다한 한국인이 대체 왜, 그리고 뭘 만들었길래"**라는 이중 궁금증이다. 손실(35억)의 크기와 거절의 비상식성이 클수록 "이유"에 대한 갈증이 커지고, 여기에 국뽕 자부심이 얹혀 클릭을 만든다.

### 설계 원칙 (paradox 모드)

- **훅 소재 풀 상위 5개 확정** (관찰 A의 시청자 관심 방향과 부합 순):
  1. **구글 35억을 고민 없이 거절 + 포항 잔류** (행동 모순) — 최우선. 두 영상 검증된 1순위 후크.
  2. **미국(MIT·스탠퍼드)도 못 만드는데 한국(포항+대전)만 만든다** (인과 역전) — 국뽕 자부심 즉발.
  3. **500만 원 → 5,000원, 1/1,000인데 성능은 더 좋다** (숫자 모순) — 체감 강력.
  4. **노벨 후보 석학이 학부 9년 만에 졸업한 늦깎이** (결과 모순) — 인간미·응원 심리.
  5. **35억을 거절한 진짜 이유가 '돈'이 아니었다** (인과 역전) — 후반 감동 회수용 오픈루프.
- **훅 첫 문장은 상식 파괴 선언으로 시작**하고, 그 즉시 "왜?"의 답을 뒤로 미뤄 오픈루프를 건다. "오늘은 ~" 류 약한 인트로 절대 금지(채널 금지 표현이기도 함).
- 이 소재 풀은 creative-strategy.md Phase 3의 역설형 훅 생성 입력이 된다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 — 두 영상의 정보 배치 나란히**

| 단계 | 001 (18.4만) | 002 (11.6만) |
|------|-------------|-------------|
| 미끼 | 미국도 못 만드는 렌즈 / 35억 거절 | 35억 거절 / 3개 학과 교수 반전 프로필 |
| 인물 서사 | 서울대 기계공학 8년, 14년 만에 박사 (늦깎이) | 외고 영어과 → 서울대 부적응 → 9년 학부 (늦깎이) |
| 전환점 | 뉴스 하나로 인생 전환, 투명망토의 꿈 | 유학 중 '투명망토' 뉴스 → 무작정 지도교수 방문 |
| 원리 설명 | 메타물질 = 빛의 경로를 바꾸는 구조 | 메타물질 = "재료가 아니라 구조", 빛을 휘게 |
| 실생활 연결 | (렌즈 상용화로 확장) | 스마트폰 '카툭튀' 소멸 |
| 장애물(반전) | "너무 비싸다" 500만 원 꼬리표 | "왜 진작 안 썼나?" 개당 500만 원, 20년 갇힘 |
| 돌파(진짜 업적) | 롤투롤로 5,000원, 협업(남기태팀) | 롤투롤 1초 300개, 5,000원 미만 |
| 클라이맥스 | 삼성 OLED 2D/3D 전환, 네이처 2편 동시 | 삼성 안경 없는 3D, 네이처 2편 동시 |
| 제목 회수 | 노벨 심포지엄 26명 초청 | 노벨 심포지엄 주제 = 메타물질, 후보 거론 |
| 감동 마무리 | 정부 10년 투자, 국가 인프라 서사 | 35억 거절 이유(지역·인재 평등), 제자 서사 |

**공통 서사 흐름 (핵심 공식)**
> **미끼(35억 거절) → 늦깎이 인물 서사(실패→전환) → 기술 원리(비유로 설명) → 장애물(가격 500만 원 벽) → 돌파(1/1,000 대량생산) → 확장·클라이맥스(삼성 3D·네이처 2편) → 미끼 회수(왜 거절했나) → 감동(가치·국가)**

- 두 영상 모두 **"벽 → 극복"을 계단식으로 반복**한다(투명망토 좌절 → 렌즈 전환 → 가격 벽 → 실용 벽). 몰락형이 아니라 **'늦깎이의 역전 + 기술 장벽 극복'의 이중 상승 서사**. 나열이 아니라 매 단계 벽과 극복을 교차 배치해 긴장 유지.
- **미끼(훅)를 후반에 반드시 회수**한다. 002: "이제 구글이 왜 35억을 들고 노교수를 찾아왔는지 조금은 이해가 되시죠?" → 완결감 부여.

**전달 기법 (공통)**
- *비유*: 두 영상 모두 **어려운 광학 개념마다 일상 비유를 1:1로 붙인다**.
  - 나노 인쇄 공정: 001 "신문은 금속판에 한번 새겨 놓으면 수만 장을 찍어냅니다" / 002 "신문을 인쇄하듯이 렌즈를 찍어내는" — **동일 비유가 두 영상에서 반복** → 이 주제의 표준 비유.
  - 3D 렌즈: 001 "거실 소파의 가족 네 명이 나란히 앉아도 전부 입체를" / 002 "디스플레이 위에 얇은 3D 전환 스티커를 붙이는 것".
  - 굴절 원리: 002 "강물이 바위를 만나면 부딪히지 않고 자연스럽게 옆으로 돌아 흐르듯이 빛이 물체를 그대로 타고 넘어가".
- *숫자*: **반드시 대비 쌍(before→after)으로 제시**한다. "500만 원 → 5,000원(1,000배)", "시야각 15도 → 100도(6배)", "생산성 100배", "35억(구글 300만 달러)". 절대 수치 단독이 아니라 배수·비교로 체감시킨다.
- *사례*: **실명·실기관을 총동원해 신뢰를 쌓는다**. 노준석·남기태·김주훈, 포스텍/서울대/버클리, 삼성전자·구글·애플, 네이처·조선비즈, 다보스 WEF, 대통령상.

**리텐션 장치 (공통 배치)**
- **파트 전환 직전마다 오픈루프**를 설치한다. 001: "이 사람이 원래 만들려고 한 건 렌즈가 아니었습니다", "포항을 택한 이유가 있는데 그건 뒤에서 이야기하겠습니다". 002: "바로 그 지점에서 진짜 이야기가 시작됩니다", "아직 가장 놀라운 장면이 남아 있습니다."
- **시청자의 의문을 선제적으로 대변**한 뒤 답한다. 002: "그렇게 좋은 기술이면 왜 진작 우리가 쓰고 있지 않은 거죠?" → 가격 장벽으로 연결. 001: "사람들은 미쳤다고 했습니다"류로 시청자 반응 대변.
- **성공 직후 좌절을 붙여 긴장 재점화**. 001: "박수가 끝나자마자 꼬리표가 붙었습니다. 혁신적이지만 너무 비싸다는 겁니다."

### 설계 원칙

- **본론 뼈대는 위 공통 공식을 그대로 채택**: 미끼(35억 거절) → 늦깎이 서사 → 원리 → 가격 벽 → 1/1,000 돌파 → 삼성·네이처 클라이맥스 → 미끼 회수 → 가치 감동. 몰락형 대신 **이중 상승(역전) 서사**로 간다.
- **훅에서 던진 "왜 거절했나"는 반드시 후반에 회수**한다. 회수 문장을 대본 마지막 감동 파트에 배치.
- **비유 배치 규칙**: 광학/제조 개념이 나올 때마다 일상 비유를 즉시 붙인다. 단, 레퍼의 "신문 인쇄" 비유는 두 영상이 공유하는 표준이므로 **아이디어(찍어낸다)는 쓰되 문장 표현은 우리 식으로 새로 쓴다**(표현 복제 금지).
- **숫자 제시 규칙**: 모든 핵심 수치는 대비 쌍(X → Y, N배)으로 제시하고, 채널 강점대로 일상 스케일로 한 번 더 환산한다("5,000원이면 껌값이죠").
- **리텐션 규칙**: 각 파트 끝에 오픈루프 1개 의무 배치. 가격 벽 파트 직전에 "왜 진작 안 썼을까?" 형태로 시청자 의문을 선제 제기.

**감정을 만든 장치 역추적**

- **존경(1순위)의 방아쇠 = 늦깎이 고생담 + 돈보다 사명.** 001: "구글의 35억을 거절한 이유가 여기 있었습니다. 돈으로 살 수 있는 것이 아니기 때문입니다." 8~9년 학부 방황담이 성공과 대비되며 응원 심리를 만든다.
- **가치 감동(3순위)의 방아쇠 = 거절 이유의 회수.** 002 댓글 5위가 직접 반응한 "지역·인재 평등" 발언. 스펙 나열이 아니라 "왜 포항에 남았나"의 인간적 이유가 감동을 만든다.

**감정 흐름 (두 영상 공통)**
> **호기심·놀람(초반, 35억 거절) → 안타까움·응원(중반, 늦깎이 좌절) → 통쾌·경이(중후반, 1/1,000 대량생산·3D) → 자부심·벅참(후반, 노벨·거절 이유·국가)**

### 설계 원칙

- **1순위 감정은 '자부심 + 인물 존경'** → 이걸 더 강하게·더 자주 자극한다.
  - "한국이 세계 최초/유일"을 **최소 3회** 명시적으로 박는다(초반 훅, 대량생산 돌파, 노벨 클라이맥스). 001의 최고 반응 지점("MIT도 스탠퍼드도 없는 조합")을 벤치마크.
  - **늦깎이 고생 서사를 초·중반에 충분히 쌓아** 존경·응원 감정의 토대를 만든다(9년 학부 등 인간적 디테일 활용).
- **감동 회수는 후반에 집중.** "35억을 거절한 진짜 이유(돈 아닌 가치)"를 대본 마지막에 배치해 가치 감동(3순위)을 터뜨린다.
- **1위 댓글이 가리키는 것 = '기초과학 → 산업 혁신'의 다리.** 원리 설명에서 그치지 말고 "이게 실제 스마트폰/카메라 제품이 된다"까지 반드시 연결. (002 1위 댓글 15개 하트)
- **우리 채널 관점 보강 (레퍼 대비 차별점):** 레퍼 댓글은 자부심 위주이나, 우리 채널은 소비자 관점이 강점이다. AR글래스·스마트폰 카메라 얇아짐·내시경 등 **"이게 내 폰/생활에 무슨 영향?"** 체감 포인트를 추가로 끌어내 자부심 + 소비자 체감을 결합한다.
- **감정 배치 가이드**: 놀람(초반 20%) → 응원·안타까움(중반 30%) → 통쾌·경이(중후반 30%) → 자부심·감동(후반 20%).
