## 1. 반복되는 훅 공식 & 역설 소재 수집

### 관찰 A — 레퍼런스 훅 비교

**공통 훅 패턴 (3개 모두):**
- **역설을 3초 안에 심는다.** 세 영상 전부 "상식과 충돌하는 상태"를 첫 문장에 배치한다 — "핵 없는 우리가"(003·002 암시), "강대국이 겁먹는다"(001), "이미 아는 스펙이 진짜가 아니다"(002).
- **결과(적의 공포/굴복)를 원인(우리 무기) 앞에 배치**해 정보 갭을 만든다. 001은 강대국 공황을, 003은 김정은의 무너지는 믿음을 먼저 던진다.
- **오픈루프를 명시적으로 설치.** 002 "진짜 소름 돋는 건 따로 있습니다", 003 "핵 없이 어떻게 적을 떨게 하나 / 왜 강대국이 긴장하나" 두 질문을 명시.

**인트로 공통 역할:**
- **희소성·권위로 무기 급 격상**: 003 "미·중·러 단 세 나라만 가진 기술, 대한민국이 네 번째", 001 "베이징이고 평양이고 단 5분 만에 잿더미".
- **어려운 개념을 일상 비유로 체감화**: 002 포커("상대가 아직 패를 안 보였는데 이미 깔린 카드 한 장이 너무 강할 때") = 억지력 개념.
- **감정 보상 예고 + 두 축 약속**: 001 "통쾌하고도 눈물 나는 반전 스토리 제가 싹 다 털어 드리겠습니다" — 위력(스펙)과 개발사(서사) 두 축을 동시에 약속.
- **약한 오프닝 회피**: 3개 모두 "오늘은 ~알아볼게요" 식이 아니라 호기심+통쾌함+자부심을 3중 증폭.

**시청자 관심 방향 요약:**
레퍼런스 훅들은 공통적으로 **"핵도 없는 약소국이 어떻게 핵보유 강대국을 떨게 만들었나(역설)"**라는 궁금증과 **"오만하던 적이 굴복하는 통쾌함"**을 건드린다. 시청자는 무기 스펙 자체보다 '약자의 역전'과 '적의 굴복'이라는 서사적 반전을 보고 싶어 클릭한다.

### 설계 원칙 (paradox 모드)

- **훅 소재 풀 확정 (상위 5개, 시청자 관심 방향 '약자의 역전'과 부합 우선):**
  1. 핵 없는 나라가 핵 쥔 적을 떨게 만든다 (인과 역전, 3개 공통 최강)
  2. 농기계 뜯던 가난한 나라 → 미·중·러 다음 4번째 기술 보유국 (결과 모순)
  3. 성공하자마자 우방 미국이 족쇄를 채운다 (인과 역전)
  4. 개발 주역 1,000명을 종이 한 장으로 해고 (결과 모순, 감정 앵커 겸용)
  5. 방사능 없어 대량살상은 못 하지만 그래서 '실제로 쓸 수 있어' 더 무섭다 (인과 역전 + 반박 방어)
- 이 소재 풀은 creative-strategy.md Phase 3 역설형 훅 생성의 입력으로 사용한다.
- **주의**: '핵보다 무섭다'는 최상급 주장은 3개 영상 모두 반박 댓글을 유발(1·2·3 섹션 참조). 훅에서 쓰되 본문에서 5번 소재("방사능 없어도 지휘부는 확실히 제거 = 실제 사용 가능한 억지력")로 논리 방어를 반드시 붙인다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**공통 서사 흐름 (3개 모두 동일한 뼈대):**

```
충격적 현재 결과(현무-5/7 위력, 적의 공포)
 → 스펙 티저
 → 과거 기원(1971~72 박정희 극비 개발 지시)
 → 좌절·몰락(1978 세계 7번째 성공 → 1979 미국 족쇄 → 1982 연구원 대량 해고 → 아웅산 테러)
 → 부활(2021 미사일 지침 42년 만에 해제)
 → 기술 대공개(3대 기술: 비핵 다탄두 / 열압력탄 / 극초음속 활공)
 → 스케일 클라이맥스(평양 3분·베이징 5분 등 사거리)
 → 감성 마무리(이름 없는 연구원 헌사 + 미래 질문)
```

- 001·002·003 전부 **"화려한 스펙(겉) → 50년 피눈물 개발사(속)"의 몰락·반전 서사**로 딱딱한 무기 설명을 감쌌다. 채널 선호 구조("겉으로는 X인데 속은 Y")에 정확히 부합.
- **현재 → 과거 회귀 → 현재**의 시간 구조. 002 "잠깐 예전틀이 뭔지 먼저 아셔야 해요. 이게 진짜 이야기의 시작이거든요"로 과거로 브릿지.
- 003만 무기별로 **"통념 제시 → 약점 노출 → 해결책(다음 무기) 등장"의 3막을 계단식 반복**(현무-5 등장 → 약점 → 현무-7 해결) — 003 고유의 정교화지만 002도 "현무-5의 치명적 약점"으로 동일 기법 사용.

### 설계 원칙

- **본론 뼈대 고정**: `충격 결과 → 스펙 티저 → 과거 기원(72년 박정희) → 좌절(족쇄·해고·테러) → 부활(2021 해제) → 3대 기술 해부 → 사거리 클라이맥스 → 연구원 헌사` 순서를 그대로 채택한다. 스펙과 역사 서사를 교차 배치해 감정 진폭을 키운다.
- **약점 폭로를 파트 전환 엔진으로**: 현무-5를 충분히 띄운 뒤 "치명적 약점(탄도=요격 가능)"을 노출하고, 그 약점을 해결하는 무기로 현무-7을 등장시킨다. 이 "띄우기→약점→해결" 3막을 최소 1회 반드시 배치.
- **비유 사용 규칙**: 다탄두·극초음속·관통·억지력 등 추상/군사 개념이 나올 때마다 반드시 일상·스포츠·게임 비유를 1개씩 붙인다. 단, 레퍼가 쓴 비유(산탄총·너클볼·포커·모래주머니·미꾸라지 등) 표현을 그대로 복제하지 말고 우리 고유 비유로 대체한다.
- **숫자 제시 규칙**: 모든 핵심 수치는 비교 쌍(X vs Y) 또는 일상 스케일 환산과 함께 제시한다. 단독 수치 금지.
- **리텐션 배치 규칙**: (1) 훅 직후 오픈루프 1개, (2) 각 파트 전환 직전 "이게 끝이 아니다/진짜는 따로 있다"형 계단식 오픈루프, (3) 개발사 성공 흐름 중간에 실패·해고를 패턴 인터럽트로 삽입, (4) 엔딩에서 인트로 질문을 명시적으로 회수.
