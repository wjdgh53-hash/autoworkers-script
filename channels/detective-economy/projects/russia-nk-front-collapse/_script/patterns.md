# 레퍼런스 공통 패턴 & 설계 원칙 — 러·북 전선 붕괴

- 대상 레퍼런스: 2편 (동일 채널 `달란트투자` 158만, 전문가 대담 포맷, 업로드 하루 차이)
- 우리 영상: 20분 / 약 8,800자 / 단독 내레이션
- `hook_strategy`: **paradox** → 관찰 A + B 모두 수행

> ⚠️ **표본 특성 주의**: 두 레퍼가 같은 채널·같은 포맷이라 "채널 습관"과 "주제 공식"이 섞여 있다. 아래에서 **포맷 의존 요소(게스트 권위·진행자 되받기)는 우리 포맷으로 번역**해서 적었다. 그대로 베끼면 안 되는 항목은 별도 표기했다.

## 1. 반복되는 훅 공식 & 역설 소재 수집

### 관찰 A — 레퍼런스 훅 분석

**두 편 모두 인사·자기소개 없이 콜드 오픈(본편 발언 선편집 몽타주)으로 연다.**

| | 002 (10.7만) | 001 (5.5만) |
|---|---|---|
| 훅 형식 | 결정적 발언 4개 몽타주 | 결정적 발언 4~5개 몽타주 |
| 1번 발언 | "우크라이나군이 수행하는 드론전의 역량은 굉장히 첨단을 달리고 있다." | "왜 북한에 한만 명 청구를 냈느냐?" |
| 결정타 | "전선에서 사망 또는 전투에 복귀할 수 없을 정도의 큰 부상을 입는 사람들이 **충원하는 병사들보다 더 높아지는** 그런 현상들이 벌어집니다." | "러시아가 벌써 **50만 명 이상** 지금 전사를 했다. 구조 병력 보충은 절대적으로 필요하다." |
| 인물 축소 | "이런 상황에서는 **푸틴 대통령도 상당히 곤란한 처지**에 놓여 있다." | "**김정은이 거래했을 것 같아요.**" (문장 끊김) |
| 규모/미끼 | "전체 병력수를 합하면 약 300만 정도가 된다" | (독일 잠수함 건조 슬롯 파편 — 이질적 미끼) |

**공통 훅 공식 4개 (2편 모두 반복):**

1. **제목의 극단어를 훅에서 "검증 가능한 명제"로 즉시 번역한다.**
   - 002: 제목 "몰살 직전" → 훅 "죽는 사람이 새로 들어오는 사람보다 많다"
   - 001: 제목 "몰살 위기" → 훅 "50만 명 이상 전사했다"
   - **왜 먹히나**: 시청자가 가장 먼저 하는 판단은 "이거 낚시인가?"다. 훅 3초 안에 근거를 먼저 지급해 이탈 창을 닫는다.
2. **추상적 전황을 한 사람의 곤경으로 축소한다.** "푸틴 대통령도 곤란한 처지" / "김정은이 거래했을 것 같아요". 시청자가 보고 싶은 건 전선 지도가 아니라 **한 놈의 표정**이다.
3. **문장을 끝내지 않거나, 답을 비운다.** 001의 "거래했을 것 같아요"는 무슨 거래인지 말하지 않는다. 002의 "충원보다 사상자가 많다"는 원인을 말하지 않는다. 둘 다 **15분 뒤에야 회수되는 최장 고리**다.
4. **화자의 자격증을 훅 직후에 깐다.** "제가 그 국방부 군비 검증단에 있으면서"(001) / "KBS에서 30년 정도 외교 안보… 다큐멘터리 30편"(002).
   - ⚠️ **포맷 의존**: 우리는 게스트가 없다. 이 자리를 **"자료가 아니라 목격"**으로 대체한다(→ 2번 설계 원칙 참조).

**인트로가 공통으로 하는 일 / 안 하는 일:**
- 하는 일: 최신 뉴스 확인("나도 그거 봤어") + 화자 신뢰 담보.
- **안 하는 일: 궁금증 증폭도, 시청 혜택 약속도 없다.** 001 분석의 진단대로 "18분짜리에서 리텐션 장치를 인트로에 심지 않은 건 명백한 약점"이다. **둘 다 훅이 강해서 약한 인트로가 버틴 케이스**다 → 우리는 여기를 그냥 먹을 수 있는 우위 구간으로 본다.

**시청자 관심 방향 요약**:
> 시청자는 전황을 배우러 오지 않는다. **"러시아·북한이 진짜로 무너지고 있다는 물증"**과 **"무너지는 이유가 내가 알던 것과 다르다"**는 반전, 이 두 개를 사러 온다. 그리고 영상이 끝날 때쯤엔 반드시 **"그래서 우리는 어떻게 되냐"**를 묻는다(001 댓글 12·002 댓글 8).

### 설계 원칙 (paradox)

**훅 소재 풀 — 상위 4개 확정.** (시청자 관심 방향 "물증 + 상식과 다른 이유"와 부합하는 순으로)

1. **돈은 멀쩡한데 사람이 없어서, 핵 든 나라가 옆집에서 사람을 사 온다** — 몰락 서사를 경제가 아니라 **인구**에 거는 앵글. 시청자가 "제재로 러시아 망했다"고 알던 상식을 정면으로 꺾는다. (⚠️ verified-data.md에서 재정 전제가 뒤집혔으므로, 채택 시 "돈도 사람도 같이 무너진다" 방향으로 조정)
2. **죽는 병사가 새로 오는 병사보다 많다** — 제목이 어떤 극단어를 쓰든 그 근거로 즉시 지급 가능한 유일한 숫자 명제. **훅에 반드시 넣는다.**
3. **초강대국 군대가 민간 회사 스위치 하나에 눈이 감겼다** — 통쾌함 지수 최상. "몰래 사다 쓰다 걸렸다"는 부정행위 적발 서사라 쾌감이 크다.
4. **인민은 굶는데 평양은 접촉사고를 걱정한다** — 국내 감정(분노) 연결이 가장 짧다.

**훅 작성 규칙 (체크리스트)**

- [ ] 첫 문장은 인사·주제 예고 없이 **결과 명제**로 연다. "오늘은/이번 영상에서는" 금지(profile 금지 표현).
- [ ] 훅 안에 **제목 극단어의 근거 숫자 1개**를 반드시 지급한다(위 소재 2번 계열). 근거 없는 극단어만 던지면 002의 "누구 말이 진실인지"(좋아요 64) 댓글이 그대로 재현된다.
- [ ] 훅 안에 **사람 이름 1개**를 건다 — 푸틴 / 김정은. 전선이 아니라 한 놈의 처지로 축소한다. (호칭: 존칭 절대 금지, "푸틴이", "김정은이")
- [ ] **답을 비운 문장 1개**를 심고, 최소 12분 뒤에 회수한다. profile의 "열린 고리" 필수 조항과 동일. 예: "그런데 러시아가 급한 건 돈이 아니었습니다."
- [ ] 레퍼가 안 한 것 하나를 더 한다: **인트로 30초 안에 "왜 채널마다 말이 다른가"를 짧게 처리**한다(→ 3번 설계 원칙).
- [ ] ⛔ 레퍼 문장 복제 금지. "몰살 직전이다", "사냥하듯이", "곤란한 처지" 같은 레퍼 고유 표현은 **구조만 가져오고 단어는 전부 새로 짓는다.**

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰 — 구조

| | 002 (10.7만) | 001 (5.5만) |
|---|---|---|
| 배치 패턴 | 현상 → 기술적 원인 → 정치 균열 → 근원 오판 → 개전 장면 회귀 | 예상 뒤집기 → 진짜 원인 → 도덕적 대조 → 별건 Q&A |
| 시간축 | **역행** (현재 → 두 달 전 → 4년 전 → 2008년) | 순방향 + 역사 대조 |
| 착지 | 좁은 길 전차 도륙 장면 + 1인칭 증언 | 후반 화제 이탈 |

**공통 뼈대 3단 (2편 모두 반복):**

1. **통념 꺾기** — 시청자가 알던 그림을 먼저 부순다.
   - 001: "일단 러시아의 재정 상태만 보면요, 이렇게 전쟁을 진행하고 있음에도 불구하고 **그렇게 부담스러워 보이지는 않습니다**" (제목의 "쫄딱 망한"과 정면충돌)
   - 002: "얼마 전까지만 하더라도 러시아가 압도적으로 이긴다"였는데 뒤집혔다
2. **진짜 원인은 표면이 아니라 구조에 있다** — 둘 다 원인을 "무기·돈"이 아닌 곳에 건다. 001은 **사람(성비 붕괴)**, 002는 **고도와 연결(위성 550km)**. 이게 이 주제에서 반복되는 승리 공식이다.
3. **원인을 그림 한 장으로 봉인** — 001은 "야, 세 배 보낼 테니까 좀 더 줘" 흥정 재연, 002는 "오도가도 못한 그 중간에 있는 전차들을 드론으로 사냥하듯이 격파".

**공통 약점(둘 다 앓는 병) — 후반 화제 이탈.**
001은 뒤 8분이 핵탄두·잠수함 별건이고, 002는 중반 4~5분이 우크라이나 내부 인사 이야기다. **제목이 판 감정과 무관한 구간**이며 두 편 모두 여기가 이탈 절벽으로 추정된다. → 우리의 최대 반사이익 지점.

### 관찰 — 전달 기법

- **대비 논증이 두 편 공통 최강 무기.**
  - "36,000km vs 550km" — 65배라고 계산해주지 않고 **두 숫자를 나란히 놓기만** 한 게 오히려 직관적이었다.
  - "중국이 이게 세계적인 영향을 못 끼치는 거는 자족이 안 되잖아요. 기름이 안 나다 보니까." — 러시아를 설명하려고 중국을 자로 쓴다.
  - "페도로우(35세, IT·드론) vs 시르스키(1965년생, 야전군)" — 세대·병과 대립을 인물 두 명으로 의인화.
- **체감 단위 번역은 딱 1회씩밖에 안 나온다.** 002의 "약 서울 면적의 절반 정도에 해당하는 그런 영토를 탈환했습니다"가 유일. 나머지는 전부 원시 수치 방치(36,000km, 300만, 30만~50만~100만, 6~7천도). **레퍼의 가장 큰 빈틈이자 우리 채널 profile이 이미 규정한 강점 구간.**
- **통계 대신 길거리 장면으로 증명** — 001의 "평양 거리가 지금 굉장히 활발해요… 교통사고도 많이 일어나 접촉 사고도 많이 일어나고". 북한 경제 호황을 GDP가 아니라 **접촉사고**로 증명했다. 이 대본 최고의 서술 기법.
- **1인칭 목격 증언이 신뢰의 본체** — "제가 그 길을 수차례 왕복했기 때문에 꼼짝 없이 당할 수밖에 없는가를 잘 압니다"(002). 위성 고도는 검색하면 나오지만 길의 폭은 가본 사람만 안다.
- **시니어가 아는 참조 프레임 얹기** — "적을 알고 나를 알 수 있는 손자병법 관점에서 본다면"(002).

| 패턴 인터럽트 | **"그게 다라고는 할 수 없습니다."** (진행자가 결론 내려는 순간 부정) | 002 | 중반 |
| 통념 깨기 | "많은 분들이 전쟁이 나면 모든 군인이 다 나가서 싸우는 줄 알고 있지만 사실 그렇지 않습니다" | 001 | 중반 |
| 요약 브릿지 | "그래서 지금 러시아 입장에서는 쉽게 말하면 교대 병력이 없는 거죠" | 001 | 어려운 설명 직후마다 |
| 문장 끊기 | "…부담스러웠을 것으로 보입니다. **왜냐하면**…" | 002 | 중반 |
| 역설 재점화 | "푸틴 대통령한테는 안 좋은 어떤 경험이었다고 할 수 있을까요?" | 002 | 후반 |

> **핵심 관찰**: 두 편 모두 **진행자의 되받기가 곧 리텐션 장치**다("그렇겠네요", "쉽게 말하면 교대 병력이 없는 거죠"). 단독 내레이션인 우리는 이 자리를 **자문자답**으로 대체해야 한다 — profile의 "감이 잘 안 오시죠 / 이게 무슨 뜻이냐면요 / 살림으로 치면요" 변주가 정확히 이 기능이다.

### 설계 원칙 — 본론 뼈대 (20분 / 8,800자)

**구조 선택: 질문형 + 추적형 혼합** (pd-guide 4번 표). 두 레퍼가 공통으로 쓴 "통념 꺾기 → 진짜 원인" 골격이 질문형과 동형이다.

| 파트 | 분량 | 내용 | 필수 장치 |
|---|---|---|---|
| 훅 | ~350자 | 결과 명제 + 근거 숫자 1개 + 인물 1명 + 빈 문장 | 오픈루프 A 설치 |
| 인트로 | ~450자 | "채널마다 말이 다르죠" 처리 + 판정 기준 하나 예고 | 오픈루프 B 설치 |
| P1 | ~1,300자 | **통념 꺾기** — 시청자가 알던 그림을 부순다 | "많은 분들이 ~라고 알고 계시죠. 근데 아닙니다" 계열 |
| P2 | ~1,300자 | **진짜 원인** — 표면이 아니라 구조 | 오픈루프 A 부분 회수 + 대비 숫자 1쌍 |
| P3 | ~1,300자 | **물증** — 죽는 병사 > 오는 병사 / 낮게 나는 쪽이 이겼다 | 체감 단위 번역 필수 2회 |
| 전환 블록 | ~500자 (5~7%) | 7~9분 지점. 감정의 방향을 바꾸는 자리 | pd-guide 1번 규정 |
| P4 | ~1,300자 | **북한 — 그 빈자리를 팔아 번 돈** (평양 호황 vs 유족) | 길거리 장면으로 증명 |
| P5 | ~1,300자 | **자업자득의 뿌리** (시간 역행 — 과거의 성공이 지금의 수렁) | 역설 재점화 |
| 엔딩 | ~1,000자 | 오픈루프 전량 회수 → 우리 쪽 착지 → 장면 + 감정 → 마무리 3단 | profile 엔딩 규정 |

**전달 기법 사용 규칙**

- [ ] **대비 숫자는 파트당 정확히 1쌍.** 두 숫자를 나란히 놓고 **비율은 계산해주지 않는다**(002 검증). 예: "저쪽은 3만 6천 km 위, 이쪽은 550 km 위."
- [ ] **한 문단 숫자 2개 상한 / 1,000자당 8개 이하**(profile). 레퍼는 이걸 어겼고(001의 "30만에서 50만, 심지어 100만"), 우리는 지킨다. `check_tone.py`로 검증.
- [ ] **숫자는 반올림하고 살림으로 착지**. "50만 명 이상 전사" → 도시 하나가 통째로 비는 그림 식. 002가 딱 1회 한 걸 **최소 4회** 한다. 단, "서울 면적 절반"은 레퍼 표현이므로 다른 단위로.
- [ ] **추상 개념이 나올 때마다 즉시 풀이.** 정형구("쉽게 말하면") 상한 4회는 지키되, **푸는 행위 자체는 8,800자에 18회 이상** (tone-guide §4).
- [ ] **파트당 최소 1개의 "눈에 보이는 장면"**을 심는다. 통계로 증명하지 말고 장면으로 증명한다(평양 접촉사고 방식). 표현은 새로 짓는다.
- [ ] **1인칭 목격 증언은 우리가 쓸 수 없다** — 대신 **구체적 장면 묘사**로 대체한다. "제가 가봤는데" 류 허위 체험 서술 절대 금지.

**리텐션 배치 규칙**

- [ ] 오픈루프 **2개**를 훅·인트로에 설치. A는 P2에서 부분 회수, **B(메인)는 엔딩까지 끌고 간다**. profile 필수 조항.
- [ ] **파트 전환 직전마다** 다음 파트 미끼를 한 줄 심는다. 002의 "몇 가지 기술적인 이유도 있는 것 같습니다"처럼 **개수를 흘리는 방식**이 가장 싸고 강하다.
- [ ] **패턴 인터럽트 1회 이상** — 시청자가 결론 냈다고 느끼는 지점(P2 끝 또는 P3 중간)에서 뒤집는다. 표현은 새로. 예: "여기까지면 얘기가 깔끔한데, 실제로는 여기서 한 겹 더 들어갑니다."
- [ ] **어려운 설명 직후 한 줄 요약 브릿지**를 무조건 붙인다(진행자 되받기 대체). 파트당 최소 2회.
- [ ] ⛔ **후반 화제 이탈 금지.** 두 레퍼 공통 최대 약점. **한 편 한 주제.** P4·P5는 반드시 훅이 판 감정선 안에 있어야 한다.

## 3. 감정 증폭 전략

### 관찰 — 댓글 감정 순위

| 순위 | 감정 유형 | 근거 (좋아요) | 출처 |
|---|---|---|---|
| 1 | **불신 / 진실 갈증** | 64 + 5 + 0 | 002 |
| 2 | **경멸·조롱 (적의 자멸)** | 14 | 001 |
| 3 | **안보 불안 → "그럼 우리는?"** | 12 | 001 |
| 4 | **자부심 방어 / 반발** | 11 + 7 + 3 = 21 (합산 최다) | 001 |
| 5 | **진영 대입** | 8 vs 3 | 002 |
| 6 | 화자 불신 | 2 | 001 |

**교차 관찰의 핵심**: 두 영상 모두 **최상위 댓글이 영상 내용에 대한 감탄이 아니다.** 002는 스타링크도 36,000km도 페도로우도 아무도 언급하지 않았다. 001도 마찬가지다. 전부 **"내 판단을 확인하거나 방어"**하는 반응이다.
→ **이 시청자는 정보를 받으러 온 게 아니라, "우리는 옳았고 저놈들은 저 꼴이 났다"는 확인을 받으러 왔다.**

### 관찰 — 감정을 만든 장치 역추적

**① 경멸·조롱을 만든 장치 (가장 재현 가치 높음)**
- "여성 1일 때 남성이 0.9가 안 되는 걸로" → 댓글 "러시아 얘넨 남자가 멸종하겠는데???"(14). **핵 든 강대국이 남자가 없어서 옆집 독재자한테 사람을 사 온다**는 그림이 조롱의 원천.
- "야, 우리 지난번에 만 명에 얼마였는데 이번에 세 배 보낼 테니까 좀 더 줘" — 국가 간 파병 협상을 **시장 흥정**으로 낮췄다. 김정은이 협상가가 아니라 인력 브로커가 된다.
- "지금 러시아군은 스타링크를 이용할 수 없다고 봐야 됩니다" — 몰래 사다 쓰다 시리얼 넘버로 하나하나 걸린 **부정행위 적발 서사**.

**② 분노를 만든 장치**
- "북한은 경제난이라든지 인민이 굶주리는 것과 상관없이… 핵은 꾸준히 개발을 해 왔습니다" / "인민이 굶건 어쩌건 떠나서 얘네는 핵은 만들 것이다."
- **세 장면 겹치기**: 굶는 인민 → 평양의 접촉사고 → 김정은의 선입금. 분노는 한 문장이 아니라 **세 장면의 병치**에서 나왔다.

**③ 불신을 만든 장치 (반드시 피할 것)**
- 002는 "몰살 직전"이라 해놓고 결론이 "언제 끝날지 모르는 러시아 우크라이나 전쟁입니다"였다. 전문가 본인이 "최격전지인 동부전선 도네츠크에서는 의미 있는 영토 탈환은 없었습니다"라고 제한까지 걸었다.
  → **제목이 판 카타르시스를 끝까지 지급하지 않은 것**이 좋아요 64짜리 불신 댓글의 직접 원인이다.
- 001은 게스트가 북한 파병을 월남전 파병과 동일시했다("우리가 월남전에 갔을 때도 똑같은 상황이에요"). **이 한 문장이 상위 댓글 세 개를 만들었고 전부 반발**이다.

### 관찰 — 감정 흐름

- 002: 규모 압도 → 감탄(기술 역전) → 불안(내분) → 조소·통쾌(오판·전차 사냥) → **무거운 여운으로 흐림**
- 001: 의외감(멀쩡하네) → 경멸·고소함 → 분함 → **자국을 향한 답답함으로 이탈**

**공통 패턴**: 초반 의외감 → 중반 경멸/감탄 → 후반 통쾌·조소. **공통 실패: 둘 다 마지막에 통쾌함을 정산하지 않고 무거움·답답함으로 끝냈다.** 시청자가 산 감정을 마지막에 돌려주지 않았다.

### 설계 원칙 — 감정 배치

**감정 흐름 설계 (8,800자 기준)**

```
의외감(0~20%) → 경멸·조롱(20~45%) → 분노(45~65%) → 통쾌함 정산(65~90%) → 우리 몫의 자각 + 여운(90~100%)
```

**실행 체크리스트**

- [ ] **1순위 처리: 불신을 초반 30초 안에 무장해제한다.** 좋아요 64짜리 최다 공감 댓글이 정확히 이 요구다("누구는 러시아가 승리 일보직전이라고 하고 누구는 우크라이나가 승리한다고 하니"). 두 레퍼 모두 이걸 안 했다.
  → 인트로에 짧게: "러시아가 이긴다는 영상도 있고 우크라이나가 이긴다는 영상도 있죠. **근데요, 여기서 진짜 핵심은** 둘 다 같은 숫자를 보고 다른 데를 짚었다는 겁니다." (시그니처, 영상당 2회 상한 중 1회 소진)
- [ ] **판정 기준 하나를 시청자 손에 쥐어준다.** 결론을 하나 더 얹는 게 아니라 "이 숫자 하나만 보시면 됩니다" 식으로. **추천: 사상자 대비 충원 병력.** 이게 곧 메인 오픈루프이자 엔딩 회수 지점이 된다.
- [ ] **경멸은 "자업자득" 프레임으로만 만든다.** 러시아가 약해서 진 게 아니라 **자기 판단으로 자기 무덤을 팠다**는 구조(002의 조지아 성공 → 독). 동정이 아니라 조소가 나오게. 감정 톤은 pd-guide 3번의 **경멸 + 자업자득** 고정.
- [ ] **분노는 세 장면 병치로 만든다.** 파트 4에서 ① 끌려간 북한 병사 ② 평양의 호황 장면 ③ 김정은 지갑으로 들어간 돈 — 세 그림을 연속 배치. 설명하지 말고 나란히 놓는다.
- [ ] **통쾌함을 반드시 마지막에 정산한다.** 두 레퍼 공통 실패 지점. 끝을 "언제 끝날지 모른다"로 흐리지 않는다. 단, profile의 엔딩 규정대로 **통찰은 한 줄만, 착지는 장면 + 감정**으로.
- [ ] ⛔ **월남전·산업화 등 우리 세대 경험과 북한 파병을 동일시하지 않는다.** 대조한다면 **차이 방향으로만**: "우리는 자원해서 갔고 그 돈이 나라로 들어왔다 / 저쪽은 끌려가고 그 돈은 김정은 지갑으로 들어간다." 001 상위 댓글 세 개가 스스로 써준 대본이다.
- [ ] ⛔ **"그럼 우리는?"을 던져놓고 끊지 않는다.** 001은 북한 핵 500기를 던지고 한국 대응을 안 줘서 좋아요 12짜리 미충족 댓글이 달렸다. 우리는 P5 또는 엔딩에서 **반드시 한국 착지**. 안보 소재이므로 pd-guide 연결 층위 규정에 따라 **재무가 아니라 안보 불안·일상 안전**으로 착지(억지 재무 연결 금지).
- [ ] ⛔ **독재자 호칭.** "김정은이", "푸틴이". 001은 게스트의 중립적 호칭 때문에 "범죄자는 존경해서 부르고"라는 불신 댓글을 받았다. **존칭 흔적 하나면 신뢰를 잃는다.**
- [ ] **감정 조절 밸브 1회**: 002의 "많은 병력들이 희생을 당하고 있는 그런 안타까운 상황"처럼, 통쾌함 일변도로 가지 않게 한 줄만 낮춘다. 이게 영상을 "관찰"로 격상시킨다. (표현은 새로 짓는다)
- [ ] **분산 감정 리액션 8~12회** (pd-guide 1번): "이 대목에서는 좀 화가 나더라고요" 계열의 한 문장을 전체에 흩는다. 분석가 말투 금지.

- 평균 메인 카피 총 글자수: **22자** (두 편 완전 일치)
- 고퍼포먼스 영상의 형식 특징: **상단 1줄을 색으로 2분절(주어 / 결과) + 하단 1줄 통짜 대형 카피.** 상단·하단이 각각 독립 문장으로 읽히면서도 이어 읽으면 제목이 된다.
- **권장 글자수: 상단 10~11자 (5~6자 + 4~6자로 색 분절) / 하단 11~12자. 메인 카피 합계 22자.**

> **도출 근거**: 조회수/일 1위는 001(약 5.5만/일 vs 002 약 5.3만/일)이나 **두 편의 메인 카피 글자수가 22자로 정확히 동일**해 논쟁 여지가 없다. 상단 10~11자 / 하단 11~12자는 **한국어 기준선(1줄·2줄 모두 9~12자) 안에 정확히 들어온다. 기준선 이탈 없음.**
> 화자 크레딧(5자)은 게스트 대담 포맷 고유 요소로 우리에겐 없다. 이 자리는 **비워두거나 리액션 텍스트(2~6자)로 대체**한다. 리액션 텍스트는 위 22자 계산에서 제외하되 매번 세트로 뽑는다.

### 관찰 — 썸네일 텍스트 패턴 분석

- **"몰살"이 두 편 모두에 등장한다.** 이 주제에서 가장 확실히 검증된 단어. 다만 **그대로 쓰면 레퍼 복제**이므로 강도만 계승한다.
- **색 = 의미 배분이 완전히 동일하다**: 흰색(주어/상황) → **노란색(핵심 결과어)** → 빨간색(상대의 파멸). 한 줄 안에서 흰/노랑을 갈라 **결과어에만 시선이 먼저 꽂히게** 한다. 이게 두 편이 공유하는 핵심 기술.
- **하단 빨간 줄이 항상 "누가 어떻게 됐다"의 완결 문장**이다: `러시아군 몰살 직전이다` / `러시아 북한 쫄딱 망한 이유`.
- **구어체 과장어 사용**: `쫄딱`, `압도적인`. 50~60대 남성이 실제 쓰는 말. "완전히 붕괴한" 같은 문어체를 피했다.
- **숫자가 한 개도 없다.** 두 편 모두. 이 주제에서는 숫자가 아니라 **감정 형용사가 클릭을 산다**는 뜻이다.

- 모바일 가시성: 화염 한 덩어리 + 굵은 검정 외곽선 텍스트라 160×90px에서도 "뭔가 불타고 있다 + 노란 글자"가 즉시 인식된다. **요소 수가 적어서 작동하는 썸네일.**

- [ ] **`~한 이유` / `~배경`으로 종결**해 감정어로 끌어온 클릭을 정보 약속으로 봉인한다(001 방식, pd-guide 골격 4번과도 일치).
- [ ] **숫자 1개는 넣는다.** 레퍼 2편은 둘 다 숫자가 0개지만, pd-guide "히트작 제목 공식"과 profile("제목은 예외다. 제목에는 구체적 숫자를 반드시 박는다")이 숫자를 요구한다. **이 주제는 pd-guide 적용 조건 중 "강대국 몰락형"에 정확히 해당**하므로 골격을 계승한다. 절충: **감정 형용사 + 숫자 1개**를 병치하고, 숫자가 제목을 무겁게 만들면 썸네일이 아닌 제목에만 둔다.
- [ ] ⛔ "세계 최초 / 충격적 근황 / 소름" 류 **추상 과장어 금지**(pd-guide).
- [ ] 게스트가 없으므로 `｜인물명 N부` 태그는 쓰지 않는다. 대신 **시리즈감이 필요하면 회차 대신 주제 태그**를 검토.

**역할 분담 공식**
```
썸네일 = 감정 + 결과 (22자, 색 3분할)
제목   = 썸네일 카피 그대로 + 숫자 1개 + "~한 이유"
```
→ 썸네일이 "쟤네 끝났다"를 팔고, 제목이 "왜?"를 봉인한다.

**썸네일 비주얼**
- [ ] **좌측 2/3 = 불타는 적의 상징 / 우측 1/3 = 인물.** 두 편 공통 구도를 계승.
- [ ] **승자를 그리지 않는다. 패자가 무너지는 그림만.** 10.7만 영상의 핵심 판단.

- [ ] **인물 표정을 극대화한다.** 레퍼는 "설명 중인 증언자 포즈"였지만, 게스트가 없는 우리는 **당사자(김정은·푸틴 또는 북한군 병사)의 표정**을 쓴다. 눈·입·손동작까지 프롬프트에 분해해 명시 — **표정만 보고 대본 내용이 유추되게.**
- [ ] **오브젝트는 2개까지.** 160×90px에서 "불타는 상징 + 얼굴" 두 덩어리만 남아야 한다.

## 부록 — 우리 영상 실행 체크리스트 (요약)

**반드시 계승**
1. 콜드 오픈 — 인사 없이 결과 명제 + 근거 숫자 + 인물 이름 + 빈 문장
2. 통념 꺾기 → 진짜 원인(표면 아닌 구조) → 그림으로 봉인, 3단 뼈대
3. 대비 숫자 쌍은 계산해주지 않고 나란히만
4. 통계 대신 길거리 장면으로 증명
5. 썸네일 메인 카피 22자(상 10~11 / 하 11~12), 흰-노랑-빨강 3색 분할
6. 좌 2/3 불타는 적의 상징 + 우 1/3 표정 극대화 인물, 승자 상징 없음
7. 썸네일 카피 = 제목 포함, 뒤에 "~한 이유"로 봉인

**반드시 차별화 (레퍼 공통 빈틈)**
1. 인트로 30초 안에 **"채널마다 말이 다르죠"** 처리 + 판정 기준 1개 지급 → 좋아요 64 댓글 정면 응답
2. **체감 단위 번역 4회 이상** (레퍼는 통틀어 1회)
3. **후반 화제 이탈 없음 — 한 편 한 주제** (두 레퍼 공통 최대 약점)
4. **통쾌함을 엔딩에서 정산** 후 장면 + 감정으로 착지 (레퍼는 둘 다 흐림)
5. **"그럼 우리는?"에 반드시 답한다** — 안보 층위로 착지, 억지 재무 연결 금지
6. **한 문단 숫자 2개 / 1,000자당 8개 이하** (레퍼는 고밀도 원시 수치 방치)

**절대 금지**
1. 월남전·산업화와 북한 파병 동일시 → 차이 방향으로만
2. 독재자 존칭·중립 호칭
3. 레퍼 고유 표현 복제 (`몰살 직전이다`, `사냥하듯이`, `쫄딱`, `압도적인`, `서울 면적 절반`, `곤란한 처지`)
4. 제목이 판 감정을 본문에서 미지급
5. 존재하지 않는 1인칭 취재 체험 서술
