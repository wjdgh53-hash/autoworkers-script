## 1. 훅 분석 & 역설 소재 수집

### 관찰 A — 레퍼런스 훅 비교

| | 001 (앵커) | 002 |
|---|---|---|
| 형식 | 장면 3컷 몽타주 | 결론 조각 7연발 콜드오픈 |
| 첫 문장 | "지금 이 순간에도 중국 안에서는 상상하기 어려운 일들이 벌어지고 있습니다" | "중국의 최대 약점을 미국이 잘 알고 있기 때문입니다" |
| 핵심 한 컷 | **"에스컬레이터는 돌아가는데 사람이 없습니다"** | **"전문가들이 제일 놀랐던 게, 아 이란 이거밖에 안 된다고"** |
| 숫자 | 첫 30초 0개 | 36분 전체에서도 극소수 |
| 근거 제시 | 없음 (장면만) | 없음 (결론만) |

**공통 패턴 3개 (2편 모두)**

1. **첫 30초에 숫자를 하나도 넣지 않는다.** 001은 카메라를 든 것처럼 장면만 보여주고, 002는 결론 문장만 던진다. 두 편 다 "설명"을 훅에서 완전히 제거했다.
2. **근거를 통째로 뒤로 미룬다.** 001은 "왜 텅 비었는지"를, 002는 "최대 약점이 뭔지"를 훅에서 말하지 않는다. 002는 이 오픈루프를 7개나 심고 본문에서 전부 회수했다.
3. **훅 안에서 스케일이 계단식으로 커진다.** 001: 쇼핑몰 한 채(공간) → 대출 상환 거부 수십만 명 → 청년 실업률(수천만 명). 002: 이란(사건) → 권위주의 국가의 공통 병(법칙) → 중국(대상). "이건 개별 사고가 아니다"를 논증 없이 체감시킨다.
4. **훅의 마지막은 사람의 목소리 / 화자의 도발로 닫는다.** 001: *"이들은 이제 아무것도 하지 않겠다고 선언합니다. 드러눕겠다. 내려놓겠다."* / 002: *"이 방송을 시진핑이 볼지 모르겠지만 너무 그렇게 숙청하지 마세요."* 통계가 아니라 감정으로 훅을 마감한다.

**인트로가 공통으로 수행하는 역할**

- **목차를 이름까지 미리 다 깐다** — 001: *"디플레이션, 부동산 붕괴, 인구 절벽, 청년 실업, 그리고 대부분의 사람들이 모르는 지방정부 부채까지"*. 39분 영상에서 "언제 끝나나"를 없앤다.
- **다섯 번째만 따로 떼어 희소성을 건다** — 001: *"대부분의 사람들이 모르는"*, 002: *"실명을 얘기할 수 없지만 중국의 모 지방성에서는"*. **두 편 다 "여기서만 들을 수 있는 것"을 최소 1개 예약해 둔다.**
- **시청 후 달라질 모습을 판다** — 001: *"이 영상 하나면 뉴스에서 중국 경제 이야기가 나올 때 더 이상 멍하니 듣고 있지 않으셔도 됩니다."* 정보량이 아니라 상태 변화를 약속한다. 50~60대가 뉴스 앞에서 느끼는 소외감을 정확히 겨눈다.
- **남의 나라 이야기를 내 문제로 미리 바꿔둔다** — 001: *"여러분의 지갑에 어떤 영향을 미치는지까지"* / 002 클로징: *"여러분 문제기도 하고."*

**개별 전략 (계승 대상 아님)**
- 002의 대담 포맷 콜드오픈·게스트 권위 배지("교보문고 1일 판매 1등")는 출연자가 있는 채널 고유의 선택이다. 우리는 화자 얼굴이 없으므로 **권위를 사람이 아니라 "은폐된 팩트"로 대체**한다(§3 참조).

**시청자 관심 방향 요약**

> 두 훅이 공통으로 건드리는 건 **"세계 2위라던 것이 사실은 속이 비어 있더라"를 안전한 거리에서 확인하고 싶은 욕구**다. 시청자는 중국 경제를 배우러 오는 게 아니라, **이미 믿고 있던 결론("중국은 무너진다")을 확인받으러** 온다. 그리고 그 확인 직후 반드시 **"그럼 우리는?"**으로 튄다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰 — 구조

| | 001 (39분) | 002 (36분) |
|---|---|---|
| 골격 | 5개 폭탄 × 동일 5단 템플릿 | 사례(이란) → 법칙 추출 → 대입(중국) → 파급(대만·한국) |
| 챕터당 길이 | 약 8분 | 가변(질문이 문을 여는 방식) |
| 배열 논리 | **인과 사슬** (1의 결과가 2, 2가 3의 이유…) | **깔때기** (남의 집 화재 → 같은 배선 → 우리 담장) |
| 클라이맥스 | 결론에서 다섯 개를 **한 줄 순환 고리로 꿰기** | 후반의 "중국이 우리한테 아쉬운 소리 하더라" |

**공통 패턴**

1. **나열이 아니라 사슬이다.** 001은 마지막에 다섯 개를 한 문장으로 이어 붙여 원을 닫는다: *"부동산이 무너집니다. 부동산이 무너지니까 토지 매각 수입이 사라집니다. (…) 청년 실업이 심해지니까 청년들이 소비를 포기합니다. (…) 가격이 내려가니까 디플레이션이 깊어집니다."* 002도 이란 → 법칙 → 중국으로 층이 물린다. **두 편 다 "목록"이 아니라 "구조"를 마지막에 지급한다.** 이게 30분 넘게 붙잡아 둔 값이다.
2. **챕터마다 같은 자리에 한국 착지 브릿지가 반복된다.** 001은 5회: *"그래서 이게 우리한테는 어떤 의미냐면요"* / *"그래서 이게 여러분 상황에 대입하면 어떻게 되냐면요"*. 002는 클로징 한 번(*"여러분 문제기도 하고"*)뿐인데, 바로 그 부족분이 최다 공감 댓글(439)로 터졌다.
3. **훅 장면을 후반에 다시 호명해 수미상관으로 닫는다** — 001: *"영상 처음에 저는 여러분께 질문을 던졌습니다. (…) 텅 빈 쇼핑몰, 공사가 중단된 아파트, 드러눕겠다고 선언하는 청년들."* / 002: 콜드오픈 7개를 본문에서 전부 회수.

### 관찰 — 전달 기법

**비유: 두 편 다 국제정세를 "직장·살림 스케일"로 내린다. 이게 최대 공통 무기다.**

- 002 직장 비유(가장 강력): *"우리도 직장 생활 다 하고 있지만, 부장님이 계속 조지면 그 밑에 있는 과장들은 진짜 얘기를 부장님들한테 안 해요. 못 하죠." / "듣기 좋은 말만 한다는 거죠."* — 로켓군 숙청이라는 남의 나라 군사 얘기를 회식 자리 얘기로 바꿔버린다.
- 001: 선분양 → *"돌려막기입니다. 완벽한 돌려막기 구조입니다."* / LGFV → *"쉽게 말해서 지방정부가 만든 유령 회사입니다."* / 유동성 함정 → *"아무리 물을 부어도 빠져나가는 구멍이 더 큰 상태"* / 한중 관계 → *"중국 경제가 기침하면 한국 경제가 감기에 걸리는 구조"*
- **규칙성**: 전문 용어를 쓰되 **한 번도 그냥 두지 않고 반드시 생활어로 다시 번역**한다. 001은 이 풀어주기가 대본 전반에 촘촘히 깔려 있다.

**숫자**
- 002는 36분에 숫자가 극히 적다 — 기간("37년간 독재", "12~15년 = 거의 한 세대 뒤로")과 규모만. **정보가 아니라 서사로 끈다는 증거.**

### 설계 원칙 — 본론 (20분)

**뼈대: 5개 챕터를 그대로 쓰지 않는다. 20분이면 3개 축 + 한국 파트다.**

001의 5개(디플레·부동산·인구·청년실업·지방부채)를 20분에 그대로 옮기면 챕터당 3분으로 쪼개져 사슬이 안 잡힌다. **인과 사슬은 유지하되 3개로 묶는다.**

```
훅 (0:00~1:30)      장면 3컷 + 모순 한 컷, 숫자 0개
인트로 (1:30~2:30)  다룰 3개 이름 공개 + 하나는 "잘 안 알려진 것"으로 예약 + 지갑 약속
축 1 (2:30~7:00)    「집과 돈」 — 부동산 붕괴 + 디플레를 한 덩어리로 (원인→결과가 붙어 있음)
축 2 (7:00~11:30)   「사람」 — 청년 실업 + 인구 감소. 통계 은폐를 여기 앞쪽에 배치
  └ 8~9분 지점: 전환 블록 1개 (pd-guide, 전체의 5~7% = 60~85초)
축 3 (11:30~15:30)  「나라 살림」 — 지방정부 부채 + 숨기는 정권. 예약해 둔 "잘 안 알려진 것" 회수
한국 파트 (15:30~18:30)  ★ 독립 파트로 세운다 (레퍼가 놓친 자리)
결론 (18:30~20:00)  3개 축을 한 줄 사슬로 꿰기 → 훅 장면 재호명 → 장면+감정 착지 → 마무리 3단
```

**본론 규칙 (체크리스트)**

- [ ] 각 축은 **동일 템플릿**으로 처리한다: `생활 비유로 개념 풀기 → 실제 수치 1~2개 → 이름 붙은 주체의 사례 → 우리 살림 착지 → 다음 축 예고`
- [ ] 축의 순서는 **인과 사슬**로 배열한다. 앞 축의 결과가 뒤 축의 원인이어야 한다. 나열형은 profile.md 기피 대상
- [ ] **결론에서 3개 축을 한 문장 사슬로 꿴다.** 이걸 안 하면 20분의 보상이 지급되지 않는다
- [ ] **한국 착지 브릿지를 축마다 1회씩, 총 3회 이상** 넣는다. 매번 다른 표현으로(정형구 반복 = 양산형)
- [ ] **비유는 추상 개념이 나올 때마다 즉시.** 전문 용어를 그냥 두고 넘어가는 문장이 하나도 없어야 한다. 002 직장 비유처럼 **회사·가게·살림 스케일**로 내린다
- [ ] **숫자는 반올림 + '몇 중에 몇'으로.** 다른 숫자로 환산하지 않는다 (레퍼 001의 "한국 예산의 60%" 방식은 금지). 착지는 장바구니·전기요금·자식 일자리로
- [ ] 한 문단에 숫자 2개까지, 1,000자당 8개 이하
- [ ] **축 전환마다 "이것도 심각하지만 다음이 더 크다" 오픈루프**를 건다. 3개 축이므로 2회
- [ ] 설명이 길어지면 **짧은 확인 질문**과 **핵심 단어 한 문장 반복**으로 리듬을 끊는다 ("전액입니다" 자리)
- [ ] **한 문장짜리 감정 리액션 8~12회를 전체에 흩는다** + 8~9분 전환 블록 1개 (pd-guide). 분석 덩어리 금지
- [ ] 등장 주체는 **국가·최고권력자·기업 실명**으로. 무명 시민은 배경 군중으로만 쓰고 주인공 자리에 세우지 않는다
- [ ] 레퍼의 고유 표현(에스컬레이터, 돌려막기, 종이호랑이, 황금알 낳는 거위, 부장님-과장 비유, ASMR)은 **한 개도 그대로 쓰지 않는다.** 골격만 가져오고 표현은 새로 짓는다

### 관찰 — 감정 흐름 공통 패턴

- 001: 서늘한 구경거리 → 이해의 쾌감 → 안타까움 → 규모의 압도 → 납득 → 내 돈 경각심

### 설계 원칙 — 감정 (20분)

**1순위 감정은 "그래서 우리는?"이다. 레퍼 두 편이 공통으로 못 채운 자리이고, 여기가 우리 차별점이다.**

- [ ] **한국 파트를 독립 파트로 세운다** (15:30~18:30, 전체의 15%). 레퍼는 챕터 끝 브릿지로 흘리기만 했다. 우리는 **제목·인트로에서 예고하고 후반에 한 덩어리로 지급**한다
- [ ] 한국 파트의 착지는 **손에 잡히는 층위**로. 레퍼 수준("수출 20%", "포트폴리오 점검", "환율 주시")은 전부 버린다 → 장바구니 물가, 전기·난방비, 자식 일자리, 우리 동네 공장
- [ ] **"중국이 우리한테 아쉬운 소리 하더라" 장면을 감정 정점(14~16분)에 배치**한다. 002에서 검증됐고 pd-guide "한국 급소형"과 일치. 이 자리에 반드시 하나 넣는다
- [ ] **통계 은폐·연구 삭제 소재를 앞으로 당긴다.** 001은 20분대(4번 챕터)에 뒀는데, 우리는 **축 2 초입(7~8분)**에 배치한다. 시청자가 애초에 중국 발표를 안 믿으므로(001 댓글 10위) 여기서 신뢰가 조기에 잡힌다
- [ ] **경멸은 사실 나열로만 만든다.** 중국을 직접 욕하는 문장을 쓰지 않는다. 은폐·실패·자충수 사실만 담담히 붙여 놓으면 시청자가 알아서 꺼내 간다. 동시에 **가해국 시점 변호 금지** — "중국 입장에서는 어쩔 수 없었다" 류는 한 줄도 쓰지 않는다 (pd-guide §3)
- [ ] **경제 용어 밀도를 레퍼보다 더 낮춘다.** 시청자는 용어를 가져가지 않는다. **장면 비중을 올리고 용어를 줄인다**
- [ ] 화자 신뢰(공통 3순위)는 우리 채널에 얼굴이 없으니 **"검증된 숫자 + 은폐된 팩트"로 대체**한다. "제가 취재했다" 류는 쓸 수 없다


- 고퍼포먼스 영상의 형식 특징: **요소당 12자 안팎으로 균일하게 맞추고, 색을 요소마다 달리 써서 시선이 위→아래로 순차 이동하게 만든다.** 001은 노랑→빨강→연두, 002는 흰색(전제)→빨강(감정어)→노랑(결론)
- **권장 글자수: 상단 12자 / 하단 12자 (하단 2줄 구성 시 각 9~12자)**
  - 도출 근거: 조회수/일 1위 앵커 = **001**. 001의 요소 글자수가 12 / 9 / 12자다. 002도 13 / 12자로 거의 동일해 갈리지 않는다
  - 한국어 기준선(9~12자) **부합.** 이탈 없음
  - 요소 수는 앵커를 따라 **3개**(상단 1 + 하단 2). 리액션 텍스트(2~6자)는 이 계산에서 제외하되 세트로 별도 배치

**텍스트 패턴 분석 (공통)**

1. **"무엇을" + "어떤 상태" 2단 분업.** 001: 상단이 대상(`중국의 5가지 시한폭탄`), 하단이 상태(`공포에 빠진 중국` / `드디어 폭로된 지옥실체`). 002: 1행이 전제·비교(`이란 전쟁보다 끔찍한 대참사`), 2행이 결론(`중국 지금 쫄딱 망할 판이다`). **두 편 다 한 문장을 늘리지 않고 역할이 다른 덩어리로 쪼갠다.**
2. **구어체 저속어가 최상단 카피에 들어간다** — `쫄딱 망할 판이다`, `지옥실체`. 001은 "폭로"라는 동사까지 넣어 "감춰져 있던 것"임을 표시한다. 근엄한 명사구가 아니다
3. **주어는 언제나 `중국`.** 양편 모두 카피에 국가명을 명시한다. "그 나라", "아시아 대국" 같은 우회 표현이 없다
4. **숫자는 001에만 있다**(`5가지`). 그런데 이 숫자가 목차를 예고해 39분 길이 부담을 덜어준다 — 우리도 계승 대상

### 제목 비교

| 영상 | 제목 |
|---|---|
| 001 | `중국 청년들이 완전히 포기한 중국 현재 최악의 상황 \| 14억 경제를 덮친 다섯 개의 시한폭탄｜디플레·부동산 붕괴·인구 절벽의 충격` |
| 002 | `이란 전쟁보다 끔찍한 대참사. 중국 지금 쫄딱 망할 판이다｜김진 앵커 풀버전1` |

**공통 구조**
1. **파이프(｜)로 역할을 쪼갠다.** 앞은 감정, 뒤는 정보·검색 키워드. 001은 3단, 002는 2단
2. **지표가 아니라 사람·상태를 주어로 세운다.** "GDP 둔화"가 아니라 `청년들이 완전히 포기한`, `쫄딱 망할 판이다`
3. **현재진행·임박형 프레이밍.** `시한폭탄`(아직 안 터짐), `지금 ~할 판이다`. 결말이 안 났으니 지금 봐야 한다
4. **아는 것을 자로 쓴다.** 002의 `이란 전쟁보다`는 시청자가 이미 뉴스로 아는 사건을 기준점으로 세워 설명 없이 스케일을 올린다
5. **과장어를 쓰되 반드시 근거를 붙인다.** 001은 `최악의`, `충격`을 쓰되 `14억`, `다섯 개`, 고유 키워드(디플레·부동산·인구)로 눌러준다. 002는 `｜김진 앵커`라는 권위 배지로 눌렀다 — 우리는 출연자가 없으니 **숫자로만 누른다**

**썸네일-제목 역할 분담**

| | 썸네일이 맡은 것 | 제목이 맡은 것 |
|---|---|---|
| 001 | 감정·상태 (`공포에 빠진`, `지옥실체`) + 목차 수(`5가지`) | 인물 서사(`청년들이 완전히 포기한`) + 항목 이름 나열(디플레·부동산·인구) |
| 002 | 결론 선언 (`쫄딱 망할 판이다`) | 비교 기준(`이란 전쟁보다`) + 신뢰 배지(`김진 앵커`) + 시리즈(`풀버전1`) |

→ **공식: 썸네일 = 상태·감정 + 개수 / 제목 = 주인공 + 구체 항목 + 숫자.** 같은 정보를 반복하지 않는다.
