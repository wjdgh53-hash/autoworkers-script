# 공통 성공 패턴 & 설계 원칙 — 엔화 폭락 / 한국은?

- 레퍼런스: 001 「엔화의 끝없는 추락, 한국은 안전한가?」(박종훈의 지식한방, 146만) / 002 「어디서도 말 안해주는 엔화가 똥값된 진짜 이유」(스튜디오 경향, 26.6만·구독 대비 3.8배)
- 목표 러닝타임: **20분** (약 8,000~8,500자)
- `hook_strategy`: **paradox** → 관찰 A + B 모두 수행

> ⚠️ **가장 중요한 발견 먼저.** 두 편 다 "엔화가 왜 무너졌나"는 오버딜리버했지만, **두 편 다 한국 파트를 맨 뒤 20~25%에 몰아넣었다**(001: 33분 중 후반 8분 / 002: 23분 중 20:02 이후 3분). 그런데 **두 편의 댓글은 거의 전부 한국 얘기다.** 001 상위 댓글 3개가 전부 한국 금리·부동산, 002 최다 공감 댓글(193)이 "영상 서론이 긴데 이것만 알면 됌"이다.
> → **우리 영상의 승부처는 "엔화 설명을 더 잘하는 것"이 아니라 "한국 얘기를 더 일찍, 더 크게 하는 것"이다.**

**공통 패턴 4개** (2편 모두 확인됨):

1. **60초 안에 "통화의 사망 선고"를 구어체 동사로 때린다.** 001 "죽어가고 있죠 / 휴지가 되고 있는 거죠", 002 "똥값이야". 둘 다 경제 용어("약세", "평가절하")를 쓰지 않는다. 심리: 시니어가 뉴스에서 못 듣던 단어라 스크롤이 멈춘다.
2. **강도 표현 바로 뒤에 숫자 하나만 붙인다.** 001 "163엔", 002 "50억 달러에서 100억 달러". 숫자를 나열하지 않고 **딱 1개**만 박아 감정과 사실을 동시에 성립시킨다.
3. **답을 알려주는 게 아니라 "답이 있다"까지만 알려주고 끊는다.** 001은 "이걸 알아보기 위해서 이번에는 엔화를 심층적으로 분석해 보겠습니다", 002는 "그 의도가 뭘까 했더니 바로 이게 있었습니다". 답의 **존재**만 확정하고 내용은 감춘다.
4. **"왜 남의 나라 얘기를 들어야 하는지" 계약을 인트로 안에서 맺는다.** 이 계약이 없으면 "일본 얘기"로 이탈한다. 001은 명시적("우리 원화의 미래"), 002는 비명시적("놓치면 평생 후회")이며 — **원화 예고가 없던 002의 최다 공감 댓글이 "서론이 길다"였다.** 계약은 반드시 **한국·내 돈으로** 걸어야 한다는 반증.

**개별 전략** (1편 고유, 구조 차용 금지 / 소재만 활용 가능):
- 001의 "내가 전에 예고했잖아요" 권위형 오프닝 — 120만 구독 경제 전문가 채널의 자산이라 우리 채널에서는 공허하다.
- 002의 콜드오픈 콩트(스태프와 주고받는 재연 개그)와 "오늘의 클래스"·칠판·"윤선생 영어 교실" — 강의실 콘셉트는 그 채널 고유 IP. **표현·포맷 모두 복제 금지.**

**시청자 관심 방향 (요약)**: 두 훅이 공통으로 건드리는 것은 *"세계 3~4위 부자 나라의 돈이 저렇게 쉽게 종잇조각이 될 수 있다면, 그보다 약한 내 돈은 어떻게 되는가"* 하는 **자산 보유자의 생존 불안**이다. 궁금증은 일본이 아니라 **자기 통장**을 향해 있다.

### 설계 원칙 — 훅 소재 풀 (상위 5개 확정)

creative-strategy Phase 3의 입력으로 아래 5개를 넘긴다. 선정 기준은 **관찰 A의 "자기 통장 불안"과의 정합성**이다.

3. **일본 월급 100 → 96** (#3) — 시니어 체감 최강. "환율"을 "내 월급"으로 번역해주는 유일한 숫자.
4. **145조 쏟아붓고 더 떨어졌다** (#6) + **금리 올렸는데 더 떨어졌다** (#5) — 행동 모순 2연타. "손 쓸 방법이 없다"는 공포를 사실로만 만든다.
5. **리라보다 약해진 엔 / 한국에 역전당함** (#10) — 경멸과 자부심을 동시에 주는 유일한 소재. **두 레퍼 모두 한 줄로 스치고 지나간 최대 미개발 광맥.**

**핵심 공통 뼈대**: `과거 위상 → 역설적 붕괴 → 방어 실패 → 원인 계단 파기 → 막다른 길 → 뿌리(중앙은행) → 사람 피해 → 우리 차례`

**계단 파기가 리텐션의 본체다.** 두 편 다 원인을 한 번에 주지 않는다. 001은 "그런데 이상한 점이 있지 않습니까? 원래 금리를 올리면 엔화 가치가 올라가야 되죠. (…) 근데 왜 엔 가치는 계속해서 떨어지냐?"로 층을 내려가고, 002는 "그럼 이 시점에서 제 얘기를 다 들으신 분들은 이걸 생각하겠지. **중앙은행 뭐 하니? 그럼 금리를 올리면 되잖아.**"로 시청자의 반론을 대신 말해준 뒤 다음 층으로 내려간다.

### 관찰 — 전달 기법

**① 퍼센트를 살림으로 착지시킨다** (2편 공통, 가장 효과가 검증된 기법)

146만 조회 영상(001)의 최고 실댓글 좋아요가 **7개**다. 26만 조회 영상(002)에서 가장 많은 공감을 받은 댓글은 감동도 분노도 아닌 **"서론이 길다"는 불만**이다. 두 편 모두 **시청자가 정보를 처리하느라 감정을 뭉칠 자리가 없었다.**

→ 이 주제는 원래 뜨거운 소재인데 **아무도 뜨겁게 만들지 못했다. 이것이 우리의 가장 큰 기회다.**

### 관찰 — 감정을 만든 장치 역추적

가장 강한 감정을 만든 대목은 두 편 다 **숫자가 사람의 살림으로 바뀌는 순간**이었다.

- 001: "**미국은 30년 전에 100이었다면 235 (…) 일본은 96이에요.**" + "일본을 갔던 사람들 다 이런 얘기 하잖아요. 일본은 30년 전에 갔든 20년 전에 갔든 지금 갔든 똑같더라." → 통계가 아니라 **시청자 본인의 여행 기억**과 붙는다. 시니어 체감 최강 대목.
- 001: "이렇게 억지로 금리를 낮춰서 일본 돈을 타락시키는 걸 금융 억압이라고 하는데 (…) 서민들은 점점 가난해지고 중산층은 붕괴됩니다. **부자들만 좋아요.**" → **가해자와 피해자를 갈라놓는 한 줄**. 분노가 여기서 만들어진다.
- 002: "**이놈의 일본이 공항이 몇 개인 줄 알아요?**" / "아니 어떻게 된 나라가 선진국이라면서 수단, 바레인, 그리스 나라보다 더 높아." → 분노가 아니라 **코웃음**이다. 격하게 화내지 않고 경멸만 얹는다. 자기 전에 듣기 좋은 온도.
- 002: "**여러분 애화 싸다고 좋아만 하셨나요? (…) 저도 일본 여행가 가지고 막 안경 싸게 사고 좋다고 좋다고 막 그랬거든요. 근데 이 엔화가 고꾸라지는 거 사실 남일 아닙니다.**" → **자기 자신을 먼저 자백**하고 나서 뒤집는다. 시청자를 꾸짖지 않고 같은 편에 세운 채 불안을 심는 방식. 이 영상 최고의 감정 전환 기법.

### 관찰 — 감정 흐름 비교

- **001**: 신뢰 → 놀람(역설) → 어이없음·통쾌함(리라보다 약한 엔, 한국에 역전) → 분노(정부가 쓰고 서민이 갚는다) → 불안(우리도 90년대 일본) → 정책 촉구
- **002**: 호기심 → 웃음 → 놀라움(대지진 때 엔화는 올랐다) → 답답함(딜레마) → 통쾌한 폭로(미국의 속셈) → 씁쓸함(일본 청년) → 불안(원화도 곧) → 관망

**공통 흐름**: `놀람(역설) → 어이없음·경멸 → 답답함/분노 → 불안(우리 차례) → (힘 빠지는 마무리)`

**공통 약점 2개**:
1. **끝이 흐린다.** 001은 "제발 그런 예산안이 나오기를 학수고대하면서", 002는 "앞으로 지켜봐야 될 거 같네요"로 끝난다. 20~30분간 쌓은 감정이 마지막 10초에 증발한다.
2. **자부심(국뽕) 축이 방치돼 있다.** "엔화가 리라보다 약해졌다", "2022년 한국에 1인당 GDP 역전당했다"는 001에서 각 한 줄씩 스치고 만다. 우리 채널 타깃(50~60대 남성 시니어)에게 **가장 크게 걸릴 감정을 두 편 다 안 썼다.**

### 설계 원칙 — 감정 배치

**감정 순위 (우리 영상)**: ① 어이없음·경멸 ② 자부심 ③ 불안 ④ 분노

**감정 흐름 설계 (20분)**
```
놀람(0~10%) → 어이없음·경멸(10~35%) → 자부심(35~45%) →
분노(45~60%) → 씁쓸함(60~70%) → 불안(70~90%) → 장면 착지(90~100%)
```

**실행 체크리스트**
- [ ] **경멸의 온도는 "코웃음"으로 고정.** 002가 검증했다. 격노가 아니라 "이게 말이 되나" 톤. 자기 전에 듣는 채널이라 고성이 안 맞는다.
- [ ] **자부심 블록을 35~45% 지점(7~9분)에 명시적으로 세운다** — 두 레퍼가 비운 자리다. "한때 우리보다 몇 배 잘살던 나라의 1인당 GDP를 우리가 넘어섰다"를 **한 줄이 아니라 한 블록으로.** pd-guide §1의 전환 블록(7~9분)과 위치가 겹치므로, **자랑을 충분히 준 다음 "그런데 아직 우리 손에 없는 게 하나 있다"로 감정을 꺾는** 전환으로 설계한다.
- [ ] **피해자(한국) 시점 고정** (pd-guide §3). "일본으로서는 어쩔 수 없었다" 류의 가해국 대변 금지. 상대의 행동은 관찰자 서술("그들은 ~했습니다")로.
- [ ] **가해자·피해자를 갈라놓는 문장을 최소 2회.** 001의 "부자들만 좋아요" 자리를 우리 표현으로 만든다. 단 정당 이름은 쓰지 않는다 — 001 댓글이 이미 정권 이름으로 갈라졌다. "누가 했냐"가 아니라 "이런 방식이 문제다".
- [ ] **자백형 반전 1회** — 002 최고 기법. "엔화 싸서 좋았던 사람" 자리에 화자 본인을 먼저 세우고 뒤집는다. 시청자를 꾸짖지 않는다.
- [ ] **감정이 5분 이상 같은 색으로 지속되지 않게 한다** (002가 23분간 7번 갈아탔다). 20분 기준 **최소 6번 전환.**
- [ ] **분산 감정 리액션 8~12회** (pd-guide §1). 한 덩어리 분석 금지. "이거 정리하다가 좀 얼떨떨했습니다" 류 한 문장짜리를 대본 전체에 흩는다.
- [ ] **엔딩은 통찰이 아니라 장면으로 착지** (profile 엔딩 규정). 두 레퍼가 실패한 지점이다. 환전소 전광판 앞에 선 사람, 통장 잔고를 들여다보는 손 같은 그림으로 끝내고, 마무리 3단 구조(열린 질문 → 시청자 위치시키기 → 감사·약속·CTA, 200~300자)를 붙인다.

**댓글을 뭉치게 할 응집점 (레퍼 2편이 못 만든 것)**
- [ ] 시청자가 **한 줄로 복창할 수 있는 문장**을 결론에 심는다. 001에서 유일하게 성공한 사례가 "800조원을 제대로 쓸 거냐"였고, 실제로 댓글 5위가 그걸 그대로 복창했다. 우리도 딱 한 문장을 반복 가능한 형태로 만든다.
- [ ] **부동산·집값을 반드시 연결한다.** 001 댓글 3위 "부동산 터질꺼봐 못올린거 아니겠음?" — 영상은 부동산을 거의 안 다뤘는데 시청자가 스스로 연결했다. **환율 → 금리 → 집값·전세 → 내 통장**을 한 줄로 잇는다.
- [ ] **"그래서 나는 뭘 해야 하나"에 답한다.** 두 편 다 결론이 "정부가 잘해야 한다" / "지켜봐야겠다"로 끝나 개인이 할 게 없다. 오늘 밤 생각해볼 한 가지(예금·달러·자산 배분에 대한 **태도**)를 남긴다. 단정적 투자 권유는 하지 않는다.

### 관찰 — 썸네일 텍스트 형식 패턴

| 영상 | 텍스트 요소 수 | 각 요소 글자수 (공백 제외) | 총 글자수 | 줄 수 | 배치 방식 |

**형식 패턴 요약**
- 평균 텍스트 요소 수: **2개** (본문 기준)
- 평균 요소당 글자수: **4~8자**
- 평균 총 글자수: **12.5자**
- 고퍼포먼스 영상의 형식 특징: **2블록 계층형.** 1블록은 "무슨 일이 일어났나"(엔화 + 붕괴 동사), 2블록은 "그래서 뭐가 궁금한가"(질문형). 조회수 1위인 001은 **잡글자가 로고 하나뿐**이라 160×90px에서도 두 블록이 전부 읽힌다.
- **권장 글자수 도출**: 조회수/일 1위는 002(업로드 2일차, 약 13만/일)지만 관측 기간이 짧아 앵커로 삼기 애매하다 → 규칙 2번을 적용해 **절대 조회수 상위 001(4자 + 8자 = 12자)** 기준. 그런데 이 값은 한국어 기준선(각 줄 9~12자)을 **아래로 크게 이탈**한다.
- ⚠️ **기준선 이탈 — 9~12자로 맞출 것.** 최종 권장: **상단 9~11자 / 하단 10~12자** (총 20~22자), 2블록 계층형. 여기에 **리액션 텍스트 2~6자 1개**를 별도 세트로 뽑는다(위 계산에서 제외).

**텍스트 패턴 분석 (조회수와의 상관)**
- 두 편 다 1블록에 **`엔화` + 붕괴 동사**를 붙였다(`폭락` / `나락간`). 주어를 매번 명시한다 — "폭락"만 있으면 무엇이 폭락했는지 모른다.
- 두 편 다 2블록이 **물음표로 끝난다**(`한국이 다음 차례?` / `트럼프가 왜?`). 썸네일이 답을 주지 않고 **질문을 심는다.**
- 조회수 1위(001)의 2블록은 **"한국"**이 들어간다. 26만짜리(002)의 2블록은 "트럼프"다. **한국을 쓴 쪽이 5.5배 더 봤다.** 우리 타깃에서는 이 차이가 더 벌어진다.
- 002의 소형 텍스트 3개(헤드라인 인용·기자명·로고)는 모바일에서 판독 불가다. **소형 텍스트는 넣지 않는다.**

### 관찰 — 썸네일 비주얼 비교표

| 영상 | 조회수 | 구도 패턴 | 핵심 오브젝트 | 색채 | 감정 | 텍스트 공간 |
|------|--------|----------|-------------|------|------|------------|
| 001 | 146만 | 좌우 2분할 + 하락 그래프 + 상징물 파괴 | ① 계단식으로 짧아지는 일본 지폐 막대 ② 화염에 녹아내리는 ¥ | 좌 흰회색 / 우 검정 + 빨강 화살표, 주황 화염, **형광 민트그린** | 붕괴 | 하단 전폭 2줄, 세로 45% |
| 002 | 26.6만 | 상징물 파괴(균열) + 인물 감정 | ① 세로로 찢어진 1만엔권 다발 ② 지폐를 가리키는 여성 기자 | 짙은 청록 배경 + **형광 하늘색·청록** 포인트 | 어이없음 | 하단 1/3 + 우상단 1/4, 약 35% |

**비주얼 형식 패턴 요약**
- 가장 많이 사용된 구도: **상징물 파괴(지폐)** — 2편 공통. 그래프도 환율판도 아닌 **지폐 실물이 망가지는 그림**이다.
- 색채 공통점: **어두운 배경 + 형광 청록 계열 포인트 컬러.** 001은 형광 민트그린, 002는 형광 하늘청록. 우연이 아니라 유튜브 피드(흰 배경·붉은 UI)에서 가장 튀는 조합이다.
- 방향성: 두 편 다 **하향 화살표**를 넣었다. 텍스트를 못 읽어도 "떨어진다"가 읽힌다.
- 고퍼포먼스 영상의 비주얼 특징: 조회수 1위(001)는 **인물이 아예 없다.** 진행자 얼굴도 안 넣고 "돈이 불타는" 오브젝트가 감정을 대신한다. 대신 빨간 화살표가 **왼쪽 지폐 그래프 → 오른쪽 불타는 ¥로 꽂혀** "떨어진다 → 그래서 타 없어진다"는 인과가 그림 하나로 읽힌다.
- 모바일 가시성: **001 완승.** 160×90px에서 001은 오브젝트 2개 + 텍스트 2블록이 전부 인식된다. 002는 대형 카피와 인물 표정만 남고 소형 3요소는 소실된다.

### 관찰 — 제목

| 영상 | 제목 (원문) | 글자수 | 구조 |
|---|---|---|---|
| 001 | 「엔화의 끝없는 추락, 한국은 안전한가?」 | 18자 | 진행형 부사 + 쉼표 방향 전환 + 질문형 |
| 002 | 「어디서도 말 안해주는 엔화가 똥값된 진짜 이유」 | 23자 | 정보 독점 주장 + 비속어급 구어 + "진짜 이유" |

**공통 구조 4개**
1. **`엔화` + 붕괴 동사**를 앞자리에 둔다 (추락 / 똥값).
2. **미완결로 끝낸다** — 001은 물음표, 002는 "진짜 이유"(내용을 안 밝힌 명사구). 둘 다 답을 안 준다.
3. **격식어를 안 쓴다** — "평가절하", "약세" 같은 단어는 한 번도 안 나온다.
4. **제목에 숫자가 없다.** 두 편 다 숫자를 썸네일(002의 "15년 만에 공조")이나 영상 첫 30초(001의 163엔·39년)로 밀었다.

> ⚠️ **채널 규칙과의 충돌 지점**: pd-guide §2는 "구체적 숫자·규모를 제목에 박는다"를 필수로 둔다. 레퍼 2편은 정반대다. **절충안** — 숫자를 넣되 **감정어 뒤 자리**에 짧게 붙인다("반토막", "39년 만에", "163엔" 중 1개). 제목 앞머리는 레퍼처럼 감정어가 잡고, 숫자는 신뢰의 못으로 뒤에 박는다.

**pd-guide 히트작 제목 공식 적용 조건 판정**: 이 주제는 **"강대국 몰락형"에 해당한다**(한때 G2였던 일본의 통화가 무너지는 서사). 단 "한국 급소형"은 아니므로 "한국에 손 벌린다"는 역전 행동 요소는 억지로 넣지 않는다. **결핍 훅 인용구 + 강대국 주어 + 구체적 숫자**까지는 계승하고, 마지막 종결은 레퍼 공통 패턴인 **미완결형("~이유", "~인가?")**으로 간다.

### 관찰 — 썸네일·제목 역할 분담

- **001**: 썸네일 = 감정(폭락·화재) + 내 문제 질문, 제목 = 진행형 + 질문. → 둘 다 질문이라 **약간 중복된다**. 그래도 썸네일 쪽이 "한국"을 선점해서 성립했다.
- **002**: 제목 = 원인 약속("진짜 이유"), 썸네일 = **제목에 없는 두 번째 궁금증**("트럼프가 왜?"). 단어까지 바꿨다("똥값" vs "나락간"). → **역할 분담이 더 정교하다.** 지면 낭비가 없다.

### 설계 원칙 — 썸네일 & 제목

**썸네일 텍스트 원칙 (체크리스트)**
- [ ] **본문 텍스트 2블록. 소형 텍스트·부제·기자명·헤드라인 인용은 넣지 않는다.**
- [ ] 상단 **9~11자** / 하단 **10~12자** (공백 제외). 총 20~22자.
- [ ] 1블록: **`엔화` 또는 `엔화 값` + 붕괴 표현.** 주어를 생략하지 않는다. 단 "폭락"·"나락"·"똥값"은 레퍼 원문이므로 **다른 단어로.**
- [ ] 2블록: **한국이 들어간 질문형.** 조회수 1위가 검증했고, 우리 타깃엔 더 강하다. 물음표로 끝낸다.
- [ ] **리액션 텍스트 2~6자 1개**를 세트로 뽑는다 (`prompts/ctr-reference.md` 문구 규칙 1번).
- [ ] 배치: **하단 전폭 2줄 계층형** (001 방식). 분산 배치는 모바일에서 손실된다.
- [ ] 텍스트는 흰색·형광 청록 계열 + **검정 외곽선** 필수.

**제목 원칙 (체크리스트)**
- [ ] 앞자리에 **`엔화` + 붕괴 동사** (레퍼 2편 공통).
- [ ] **미완결 종결** — "~인가?" 또는 "~이유". 답을 제목에서 주지 않는다.
- [ ] **숫자 1개**를 감정어 뒤에 박는다 (pd-guide 검증 공식). 다만 앞머리를 숫자로 시작하지 않는다.
- [ ] **한국·원화를 제목 안에 넣는다.** 001의 "한국은 안전한가?"가 146만을 만든 절반이다.
- [ ] "충격/소름/경악/세계 최초" 류 추상 과장어 금지 (profile 금지 표현 + pd-guide §2).
- [ ] 기준 35자 이내.
- [ ] 3안을 concept.md·youtube.md에 모두 수록하고 1순위로 진행한다.

**역할 분담 공식**
```
제목    = [엔화 붕괴 사실] + [숫자] + [한국 연결] + 미완결 종결
썸네일  = [엔화 붕괴 감정어] / [한국을 향한 질문]  ← 제목과 같은 단어를 쓰지 않는다
```
002가 "똥값"과 "나락간"으로 단어를 갈라 쓴 것을 따른다. **같은 낱말이 제목과 썸네일에 동시에 등장하면 지면을 낭비한 것이다.**

**썸네일 비주얼 원칙 (체크리스트)**
- [ ] 핵심 오브젝트: **망가지는 엔화 지폐 실물** (찢김·불탐·녹아내림 중 1택). 그래프나 환율 전광판만으로는 안 된다 — 2편 다 지폐 실물을 썼다.
- [ ] **하향 방향성** 1개 (굵은 화살표 또는 계단식 하강). 텍스트를 못 읽어도 "떨어진다"가 전달돼야 한다.
- [ ] 배경 **어둡게** + 포인트 컬러 **형광 청록/민트 계열**. 2편 공통.
- [ ] 인물: 조회수 1위(001)는 인물이 없었다. 다만 채널 계승 3장 규칙과 정세형 실사 합성 규칙(메모리: 실사 사진 + 시사 그래픽, oil painting 계열 단어 금지)을 우선 적용한다. **인물을 넣는다면 국가는 원수급 실명 인물로**(무명인 금지), 표정은 002가 검증한 **"눈썹 올린 어이없음 + 입 살짝 벌린 황당함"** 방향으로 눈·입·손동작까지 프롬프트에 분해 명시한다.
- [ ] 세이프존 3/8 준수, 텍스트를 프롬프트 맨 앞에 배치하지 않는다 (메모리: 세이프존 3대 원인).
