# 레퍼런스 영상 분석 — 004

**채널**: 만화 경제학 | **조회수**: 91,767 | **좋아요**: 3,303 | **길이**: 27:44

---

## 1. 주제 요약

**러시아**의 한국 원유 공급 구애가, **호르무즈 봉쇄로 촉발된 에너지 위기** 속에서 **전쟁 자금·고립 탈피·아시아 시장 장기 포석**이라는 러시아의 실리 계산에서 비롯됐다는 구조를 폭로한다.

## 2. 썸네일 & 제목 분석

### 썸네일 텍스트 추출

| 위치 | 텍스트 |
|------|--------|
| 상단 말풍선 | "한국 고마워요" |
| 하단 대형 자막 (흰색) | 러시아 한국에만 원유 제공한다? |
| 하단 강조 자막 (빨간색) | 한국에 원유를 퍼주는 이유 |

### 썸네일 비주얼 분석

- **구도**: 이재명 대통령(좌) vs 푸틴(우) 투샷. 두 인물 가운데 쇄빙선이 배치되어 '거래'의 매개물을 암시.
- **오브젝트**: 북극 쇄빙선 — 러시아산 원유 수송 루트를 시각화.
- **색채**: 차가운 바다색 배경 + 빨간 강조 텍스트 → 위기감과 긴박감 동시 연출.
- **인물**: 두 정상이 나란히 엄지 척 → 의도치 않은 '밀월' 이미지. 아이러니 효과.
- **텍스트 공간**: 하단 1/3을 텍스트 블록이 차지. 흰색·빨간색 2단 레이어로 위계 설정.
- **시각 장치**: 푸틴 옆 말풍선("한국 고마워요") → 의인화·드라마화로 호기심 극대화.
- **감정**: 의아함("왜 우리한테만?") + 불안감("뭔가 이상한데?")

### 제목 분석

> **''러시아 한국만 원유 공급?'' 러시아가 한국에게 잘 해줄수 밖에 없는 진짜 이유+중동 역대급 위기**

- **따옴표 인용 훅**: `''러시아 한국만 원유 공급?''` — 뉴스 헤드라인을 직접 인용해 실제 사건처럼 체감시킴.
- **진짜 이유** 프레임: 표면적 사실(원유 공급)과 숨겨진 의도(진짜 이유) 사이의 긴장 조성 → 클릭 동기 직결.
- **+중동 역대급 위기**: 단일 주제 소화 후 보너스 정보 예고 → 체류 시간 늘리는 장치.

### 썸네일-제목 조합 기대감

> "러시아가 한국한테 원유를 퍼주고 있는데, 거기엔 우리가 모르는 속셈이 있다." → 반전 서사 예고. 시청자는 '내가 모르는 이면'을 확인하기 위해 재생 버튼을 누름.

## 3. 훅 & 인트로 분석

### 직접 인용

> "러시아가 한국의 원유를 주겠다고 달려들고 있는 겁니다. 그것도 엄청나게 적극적으로요. 3년 넘게 우리가 등돌리고 제재에 동참했던 바로 그 러시아가 이제 와서 한국한테 달라붙으면서 역시 똑똑하다고 칭찬까지 하고 있어요."

### 심리·역할·강도 분석

| 항목 | 내용 |
|------|------|
| **심리** | 배신감 역전: "우리가 제재까지 했는데 왜 갑자기 친절?" → 인지 부조화 자극 |
| **역할** | 시청자를 '피해자/수혜자 경계' 포지션에 세움 — 내가 이득 보는 건지 이용당하는 건지 불확실 |
| **강도** | 첫 문장부터 결론 선폭발 ("달려들고 있다") 후 역사적 맥락으로 보강 → 강도 MAX |
| **전환 장치** | "먼저 지금 상황이 어떻게 시작됐는지부터 정확하게 이해하셔야 합니다." → 내러티브 입장 유도 |

## 4. 본문 구조 분석

### 구조 요약 (5단 전개)

| 단계 | 내용 |
|------|------|
| ① 위기 발단 | 미-이스라엘의 이란 핵시설 공습 → 호르무즈 봉쇄 → 국제유가 120달러 |
| ② 한국의 취약성 폭로 | 원유 수입 70% 중동 의존, 에너지 수입 의존도 93.7%, 정유사 물량 30% 감소 |
| ③ 러시아 원유 카드 등장 | 미국의 제재 한시 완화 (4/11까지) → 러시아의 구애 시작 |
| ④ 러시아의 속셈 3가지 | 전쟁 자금 + 국제 고립 탈피 + 아시아 에너지 시장 장기 포석 |
| ⑤ 한국의 딜레마 + 구조적 교훈 | 설비·제재 재개·외교·공급 불확실 4중 딜레마 → 에너지 자립 구조 전환 촉구 |

### 전달 기법

- **숫자 → 비유 변환**: "에너지 수입액 230조원" → "국가 예산의 1/3" / "폴리우레탄 50~60% 상승" → "소파·침대 속 스펀지 가격 인상"
- **적의 대사 직인용**: 푸틴 측근 드미트리에프 X 포스팅 "like everyone else who is smart" — 러시아의 의도를 당사자 목소리로 폭로.
- **숫자 이중 제시**: 우랄유 가격 45달러 → 90달러(한 달 2배), 일일 원유 수익 1.35억 → 2.7억달러 → 체감 가능한 변화율로 변환.

## 종합 인사이트 (우리 영상 활용 포인트)

1. **반전 프레임이 성과의 핵심**: "친절한 러시아가 아니라 이해타산으로 움직이는 러시아"라는 역설 구조가 91,767 조회를 만든 엔진. 우리 채널 서사 구조("겉으로는 X, 속은 Y")와 직접 호환.
2. **숫자 → 쓰레기 봉투 체감 루트**: 거시 수치를 일상 물가로 번역하는 방식이 리텐션을 유지. 우리도 동일 공식 적용 필요.
3. **27분 영상 대비 댓글 175개는 낮은 편**: 토론 유발 질문 장치(예: "여러분이라면 러시아 원유 사겠습니까?")가 없어 댓글 전환율이 낮음. 우리 영상은 중반에 시청자에게 직접 질문 던지는 장치를 추가하면 차별화 가능.
