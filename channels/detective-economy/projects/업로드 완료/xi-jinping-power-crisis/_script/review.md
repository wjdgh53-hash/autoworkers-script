# 대본 검수 결과

## 핵심약속 검수

- [x] Hook에서 핵심약속을 바로 이행하고 있는가 — "자기 사람까지 숙청"이라는 역설을 Hook 첫 문장에서 제시하고 "왜 자기 사람까지 죽여야만 하는 걸까요"로 미스터리를 즉시 설치함.
- [x] 각 파트가 핵심약속 이행에 기여하는가 — 파트1(숙청 단서) → 파트2(권력 게임) → 파트3(진짜 목적=전쟁) → 파트4(경제 영향)까지 모두 핵심약속("자기 사람 죽이는 이유 + 내 월급에 미치는 영향")에 직결됨.
- [x] 마무리에서 핵심약속이 완결되는가 — "목적은 전쟁"이라는 답 + "한반도가 직격탄"이라는 경제/안보 착지로 완결.

## 구조 검수

- [x] outline.md의 본문 구조(파트 순서, 내용)대로 작성되었는가 — 4파트 + 클로징 순서 정확히 일치.
- [x] 확정 제목이 암시하는 구조를 정확히 따르는가 — "큰 그림"을 미스터리 추적으로 점진 공개하는 구조 충실.
- [✗] 타겟 러닝타임 범위 안에 들어가는가 — 타겟 20분(~8,000자)인데 본문 약 5,980자(공백 제외). 약 15분 분량으로 타겟 대비 약 75% 수준. 다소 짧음.
- [x] Hook과 Intro가 outline.md의 hook-intro와 일치하는가 — outline.md Hook/Intro 문구와 동일.
- [x] 각 파트의 감정 흐름이 outline.md 설계와 맞는가 — 충격·공포 → 분노·경이 → 소름·통쾌 → 경각심 아크 정확히 구현.
- [x] 리텐션 장치(오픈루프, 전환 멘트)가 파트 전환 지점에 배치되었는가 — outline.md의 재참여 포인트 10개가 모두 대본에 반영됨. "근데요, 여기서 진짜 무서운 건", "근데 이 계획에 치명적인 구멍이 하나 있어요" 등.
- [x] verified-data.md의 검증된 데이터만 사용했는가 — 아래 신규 주장 검수에서 별도 확인.

## 문체 검수

- [x] 쉼표를 남발하지 않았는가 — 문장이 간결하게 끊어져 있음. 불필요한 쉼표 나열 없음.
- [x] 따옴표를 남발하지 않았는가 — 공식 발표문 인용, 시그니처 표현 등 적절한 용도로만 사용.
- [x] 초등학생도 이해할 수 있는 쉬운 말로 쓰였는가 — "회사로 치면 임원 7명 중 5명이 횡령으로 잘린 건데" 등 일상 비유 적극 활용.
- [x] 용어 순화가 적용되었는가 — outline.md 매핑대로 적용됨: 중앙군사위→"200만 대군의 사령탑", 집단지도체제→"여러 명이서 같이 결정하던 시스템", 파벌→"패거리" 등.
- [x] 한 문장에 숫자가 3개 이상 몰려있지 않은가 — 대부분 비교 쌍(2개) 이하로 사용. 위반 없음.
- [x] 분량이 목표 대비 130% 이상인 파트에 장황한 반복·불필요한 부연이 없는가 — 전체적으로 타겟보다 짧아 해당 없음.

## 톤 검수

- [x] 채널 프로필의 말투와 톤 규칙을 따랐는가 — 존댓말 베이스("~거든요", "~인 거예요"), 친한 형이 설명해주는 느낌 유지. 금지 표현("오늘은", "학자들에 의하면", "과학적으로 증명된") 사용 없음.
- [x] outline.md에 정의된 프로젝트별 톤을 따랐는가 — 시그니처 표현 "근데요, 여기서 진짜 무서운 건" 6회, "쉽게 말하면" 4회 사용. 단정적 끊어주기 활용.

## 심각도 분류

### 치명적
- **클로징 역사 사실 오류**: "강희황제도 진시황도 그렇게 만든 권력은 결국 안에서 무너졌거든요" — 강희황제는 61년 성공적 통치 후 청나라 전성기로 이어짐. 안에서 무너진 사례가 아님. 클로징 핵심 문장이므로 반드시 수정 필요.

### 경미한
- **수치 과장 (한국 대중 수출 비중)**: "20% 이상" → 2025년 기준 18~19% 수준. "약 20%" 또는 "5분의 1 가까이"로 완화 권장.
- **미검증 주장 단정 표현 (장유샤 대만 반대)**: "대만 전쟁에 반대한 인물이에요"를 "~로 알려진 인물이에요" 또는 "~라는 분석이 있어요"로 완화 권장.
- **분량 부족**: 타겟 8,000자 대비 약 5,980자(75%). 파트3, 파트4가 outline.md 설계 분량보다 다소 짧음. 필수 수정 사항은 아니나 러닝타임 20분에 못 미칠 수 있음.
- **"근데요, 여기서 진짜 무서운 건" 과다 사용**: 시그니처 표현이지만 전체 대본에서 6회 등장. 반복 피로 우려. 4회 이하로 줄이고 일부를 다른 전환 표현으로 교체 권장.
