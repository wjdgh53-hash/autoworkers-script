## 2. 반복되는 본론 구조 & 전달 기법

### 관찰 — 구조 비교

| 영상 | 구조 패턴 |
|------|-----------|
| 002 | 위기 → 사건 → 원인 해부(4가지) → 실행 메커니즘 → 의미 부여 |
| 003 | 모순 제시 → 배경 → 이해관계(4국) → 체감 위기 → 해결 → 의미화 |
| 004 | 위기 발단 → 취약성 폭로 → 카드 등장 → 속셈 3가지 → 딜레마 + 교훈 |

**공통 뼈대 (4/4)**: `위기/충격 → "왜?" 의문 투척 → 원인 N가지 해부 → 한국의 포지션 재정의 → 의미 부여`

| 장치 | 사용 빈도 | 배치 위치 |
|------|-----------|-----------|

### 설계 원칙

**본론 뼈대**:
- [ ] 위기/충격으로 시작 → 의문("왜?") → 원인 해부(3~4가지) → 한국 포지션 재정의 → 의미 부여
- [ ] 원인 해부 파트는 포텐셜 오름차순 배치 (가장 강한 카드를 마지막에)

**전달 기법 규칙**:
- [ ] 거시 숫자 등장 시 반드시 3초 내에 일상 비유로 번역 ("나프타가 없으면 → 종량제봉투가 사라진다")
- [ ] 각 원인 파트마다 최소 1개의 구체적 숫자 + 1개의 체감 비유 배치
- [ ] 러시아/강대국의 대사를 1인칭으로 직접 인용하는 장면 최소 1회 삽입

**리텐션 배치 규칙**:
- [ ] 인트로 종료 시점에 "N가지" 구조 예고로 시청 이유 못 박기
- [ ] 40% 지점에 "근데요, 여기서 진짜 무서운 건" 시그니처 표현으로 클라이맥스 예고
- [ ] 각 파트 전환마다 새 질문 투척 ("그러면 왜 ~일까요?")
- [ ] 70% 이후에 반전 폭로 카드 배치 (쇄빙선 = 메이드인 코리아 급)

| 영상 | 감정 흐름 |
|------|-----------|

| 003 | 불안 → 호기심 → 놀라움(반전) → 체감 공포 → 자부심 → 냉소적 안도 → 성찰 |

**공통 감정 구조 (4/4)**: `불안/공포 → 분노/궁금 → 반전 쾌감 → 자국 자부심 → 경계/각성`

|------|-----------|------|

| 분노/굴욕 | 중국의 37.5% 할인 강요, 러시아 협박 | 3/4 |

| 자국 자부심 | 쇄빙 LNG선 기술, 천궁2 성능, "기술 있는 나라에 줄을 선다" | 4/4 |

### 설계 원칙

**감정 자극 전략**:
- [ ] 초반 3분 이내에 "내 일상이 위협받는다"는 체감 위기를 반드시 삽입 (나프타 → 봉투/기저귀/플라스틱)
- [ ] 중반에 중국 할인 강요(37.5%) 또는 러시아 협박 장면으로 분노/굴욕 자극
- [ ] 후반에 "기름이 아니라 기술"급 반전 한 방으로 자부심 폭발
- [ ] 마지막에 "멈추면 따라잡힌다"는 경계심으로 마무리 → 댓글 참여 유도

**감정 흐름 가이드**:
```
불안(내 생활 위협) → 궁금(왜 러시아가?) → 분노(강대국 착취 구조) → 반전 쾌감(한국 기술의 진짜 가치) → 자부심(기술 강국) → 경계(멈추면 끝)
```
