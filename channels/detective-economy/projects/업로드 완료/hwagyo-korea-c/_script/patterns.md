**공통 훅 패턴 (3개 이상 영상에서 반복)**:

1. **"상식 vs 사실" 충돌 구조** (002, 003, 004, 006): "중국 음식인데 중국에 없다", "전 세계에서 유일하게 정착 실패", "사람 사는 곳엔 중국인이 있다", "20위 중 18개가 화교" — 시청자가 알고 있다고 믿는 상식과 실제 팩트 사이의 간극을 첫 문장에서 드러낸다.
2. **오픈루프(답 유보)** (003, 006): "이따가 말씀드릴게요", "뭐로 적혀 있는 줄 알아" — 핵심 답을 의도적으로 지연하여 끝까지 보게 만든다.
3. **친숙한 소재 진입** (002, 004): 짜장면, 차이나타운 등 시청자가 직접 경험한 일상 소재로 낯선 주제(화교 역사)에 대한 진입 장벽을 제거한다.

**인트로의 공통 역할** (4개 이상 영상에서 반복):
- 훅에서 던진 모순/궁금증을 **구체적 숫자로 규모를 증명**한 뒤(004: 6천만 명·26개국·103개 도시, 006: 18/20 화교), **"왜?"라는 핵심 질문을 명시적으로 선언**하여 본문 진입 이유를 잠근다.
- "오늘은 ~에 대해 알아볼게요" 식의 약한 인트로는 0건. 전 영상이 호기심을 먼저 증폭시킨 뒤 주제를 꺼내는 구조.

**시청자 관심 방향 요약**: "전 세계를 장악한 화교가 한국에서만 힘을 못 쓴다는데, 대체 왜? 그리고 지금은 어떤 상황인가?" — 과거의 역설적 사실에 대한 호기심과, 현재 자신의 삶에 미치는 영향에 대한 경계심이 동시에 작동한다.

### 설계 원칙

**역설 소재 풀 (포텐셜 상위 5개, 훅 후보)**:

1. **"인도네시아 재계 20위 중 18개가 화교 — 한국에선 차이나타운조차 없다"**: 글로벌 장악 vs 한국 실패의 극단적 대비. 시청자 관심 방향("왜 한국만 다른가")과 정확히 부합.
2. **"1960년대 명동 건물 30%가 화교 소유였다 — 지금 명동을 걸으면 상상도 안 되는 사실"**: 시청자의 일상 공간(명동)과 직접 연결되어 체감도가 높다.
3. **"짜장면 가격을 국가가 통제하고 쌀밥 판매를 금지했다 — 밥 먹는 것까지 국가가 개입"**: 일상 음식(짜장면)이라는 친숙한 소재 + 국가 통제라는 충격의 조합.
4. **"규제에도 중국인이 집을 쓸어 담고, 전세금 243억을 떼먹었는데 회수율 2%"**: 현재 진행형 위협으로 시청자 공포/분노를 직격.
5. **"박정희의 1차 통화 개혁은 실패했다 — 화교 자산은 현금이 아니라 금과 부동산이었기 때문"**: 실패 → 재도전 서사가 영상의 긴장감을 올려준다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 — 공통 서사 흐름**:

6개 영상의 정보 배치를 비교하면, **5개 영상(002·003·004·005·006)**에서 다음 공통 구조가 반복된다:

> **배경/기원 (화교는 누구인가) → 세계적 성공/확장 (얼마나 대단한가) → 한국 상륙 & 성장 → 반전: 탄압/축출 정책 → 결과: 화교 엑소더스 → 현재적 의미/질문**

- **줌인(Zoom-in) 서사**: 세계사 → 동남아 → 한국으로 점점 좁히는 구조가 002·003·004에서 공통. 넓은 맥락에서 시작해 "그렇다면 한국은?"으로 수렴.
- **실패 → 재도전 구조**: 005에서 가장 명확. "1차 통화 개혁 실패 → 더 정교한 토지법으로 재도전 → 성공"이라는 서사가 긴장감을 유지.
- **개별 전략** (007만): 뉴스 보도 형식으로 "피해 결과 → 수치 → 원인 → 정부 대응" 순서. 역사 서사가 아닌 현재 시점 보도 구조.

**전달 기법 — 공통 패턴**:

*비유 (5개 영상에서 반복)*:
- **일상 소재를 역사의 메타포로 활용**: "짜장면처럼 화교들은 아슬아슬한 경계를 줄타기하며 생존해왔습니다" (002), "정확히 중국집 테이블 네다섯 개를 놓을 수 있는 크기였습니다" (005), "마치 끝없는 파도처럼 밀려 들어왔습니다" (004)
- 공통점: 추상적 수치/제도를 시청자가 머릿속에 그릴 수 있는 물리적 장면으로 전환한다.

*숫자 (6개 영상 전부)*:
- **대비 쌍 제시**: "1인당 GNP 79달러 → 1,647달러(20배)" (005), "화교 인구 83,000명 → 25,000명 → 18,000명" (005), "인도네시아 재계 20위 중 18개 화교" (006), "103건 243억 원, 회수 2%" (007)
- 공통점: 숫자를 단독으로 던지지 않고, 반드시 비교 대상(before/after, X vs Y, 한국인 기준)과 함께 제시하여 규모를 체감시킨다.

*사례 (5개 영상에서 반복)*:
- 실제 인물/사건을 이름과 함께 제시: 싱가포르 화교 학살(002·003·004), 만보산 사건(006), 인천 화교협회 관계자(003), 정주영·이병철(005), 신격호 소공동 매입(006), "1992년생 중국인 성북동 119억 현금 매입"(007)

### 설계 원칙

**본론 뼈대**:
1. 영상의 구조는 **줌인 서사**를 따른다: "전 세계 화교의 경제력(규모 증명) → 동남아 장악 사례 → 한국은 왜 달랐나? → 구체적 정책/사건 → 현재 상황 → 시청자에게 의미"
2. 반드시 **반전 포인트**를 배치한다: 화교의 성공 서사를 충분히 쌓은 뒤(최소 전체의 30%), "그런데 한국은 달랐다"로 전환. 성공이 클수록 실패의 충격이 커진다.
3. **실패 → 재도전** 서사를 활용한다: 1차 통화 개혁 실패 → 토지법 → 짜장면 가격 통제 → 쌀밥 금지로 점점 촘촘해지는 정책의 단계적 조임을 보여준다.

**전달 기법 사용 규칙**:
- **비유는 추상적 수치/제도가 등장할 때마다 배치**: "165㎡ = 중국집 테이블 4~5개" 식으로 머릿속에 장면이 그려지게.
- **숫자는 반드시 대비 쌍으로 제시**: 단독 수치 금지. "X인데 Y"(before/after), "A는 B인데 한국은 C"(국가 간 비교), "한국 GDP의 몇 배"(한국인 기준 환산) 중 하나를 적용.
- **사례는 실명+구체적 수치와 함께**: "어떤 중국인"이 아니라 "1992년생 중국인이 성북동 3층 주택 119억 현금 매입" 수준의 구체성.

**리텐션 장치 배치 규칙**:
- **파트 전환 직전에 전환 질문을 배치**: "그렇다면 한국에서는?" 형태로 다음 파트에 대한 궁금증을 심는다.
- **성공 서사가 정점에 도달하면 패턴 인터럽트**: "그러나 꿀만 빨 수 없었습니다" 식으로 흐름을 끊고 반전으로 전환.
- **후반부에 수사의문문 연타**: 3개 이상의 질문을 연속 배치해 시청자를 서사에 능동적으로 끌어들인다.

- **분노 유발 장치**: "명동 건물 30%가 화교 소유" (005), "재계 20위 중 18개가 화교" (006), "103건 243억 원 회수율 2%" (007), "짜장면 가격 통제, 쌀밥 판매 금지" (002·003·005) — 공통점: **"내 땅/내 돈이 위협받는다"는 구체적 수치**.
- **통쾌함 유발 장치**: "화교 인구 83,000 → 18,000으로 감소" (005), "그 자리를 누가 채웠습니까? 바로 한국인입니다" (005), "삼성 갤럭시를 들고 현대 자동차를 타고" (005) — 공통점: **수치로 증명된 역전 + 현재 일상과의 연결**.
- **경계심 유발 장치**: "이미 늦은 것 같다" (002 댓글), "이미 알짜배기는 다 넘어갔음" (007 댓글), "서울 일부 지역 중국 집단화" (006 댓글) — 공통점: **과거 역사를 현재 진행형 위협으로 전환**.

**감정 흐름 공통 패턴** (4개 이상 영상):

> 호기심(훅) → 경이감(화교 규모에 놀람) → 분노(탄압/침투 실태) → 통쾌함 또는 경각심(결과)

### 설계 원칙

**감정 설계 가이드**:

1. **분노가 1순위 감정이므로, 초반~중반에 "내 것이 빼앗길 수 있다"는 구체적 수치를 집중 배치한다**: "명동 30% 화교 소유", "재계 18/20", "56,301가구" 같은 팩트를 초반 30%에 몰아넣어 분노를 충분히 쌓는다.
2. **중반에 통쾌함(역전 카타르시스)을 배치한다**: 박정희 정책의 단계별 조임과 화교 엑소더스 결과를 수치로 제시. "83,000 → 18,000", "1인당 GNP 20배 성장"으로 역전을 체감시킨다.
3. **후반에 경각심으로 마무리한다**: "그런데 지금은?" — 현재 외국인 부동산 매집 현황, 전세 먹튀 실태로 연결하여 "과거에 막았지만 지금은 뚫리고 있다"는 새로운 긴장을 만든다.

**감정 흐름 설계**:

> 호기심/충격(초반 15%: 역설형 훅) → 경이감(15~30%: 화교 글로벌 규모) → 분노(30~50%: 한국 침투 실태·탄압 배경) → 통쾌함(50~75%: 박정희 정책·화교 엑소더스·한강의 기적) → 경각심(75~100%: 현재 상황·시청자 삶과의 연결)
