## 1. 반복되는 훅 공식

### 관찰

**훅 원문 비교**:

| 영상 | 훅 원문 (첫 3~5초) |
|------|-------------------|
| 002 | "여러분, 지금 세계지도 위에서 중국을 향해 네 개의 핀이 동시에 꽂히고 있다는 거 알고 계셨나요? (…) 총 한 발 안 쏘고 세계 2위 경제 국가에 숨통을 조여오는 소름 끼치는 전쟁의 실체가 드러납니다." |
| 003 | "여러분 혹시 우리 머리 위를 빈틈없이 뒤덮고 있는 수억 개의 CCTV 렌즈들 상상해 보신 적 있나요? (…) 정말 완벽하고도 숨막히는 디지털 통제 시스템 말입니다." |
| 004 | "한나라가 병력 200만에 세계 2위 경제력까지 쥐고서 바다 건너 작은 섬을 집어삼키겠다고 수십년째 큰 소리를 쳐왔습니다. (…) 호랑이인 줄 알았는데 고양이였던 겁니다." |

**공통 패턴 1 — "강한 전제 → 반전 파괴" 공식** (3/3 영상):
- 002: "서로 아무 상관없어 보이는 점" → "하나의 선으로 연결하면 소름 끼치는 전쟁"
- 003: "완벽한 디지털 통제" → (인트로에서) "그 견고한 장벽 아래 상상초유의 지각 변동"
- 004: "병력 200만 + 세계 2위 경제력" → "호랑이인 줄 알았는데 고양이"

세 영상 모두 시청자가 이미 알고 있는 '상식'(중국은 강하다 / 감시가 완벽하다 / 사건들은 별개다)을 먼저 극대화한 뒤, 한 문장으로 뒤집는다. 이 인지 불일치가 "왜?"라는 질문을 만들어 시청 지속을 유도한다.

**공통 패턴 2 — 질문형/상상 유도형 오프닝** (3/3 영상):
- 002: "알고 계셨나요?"
- 003: "상상해 보신 적 있나요?"
- 004: (서술형이지만 "큰 소리를 쳐왔습니다"로 시청자의 기존 인식을 소환)

시청자에게 먼저 장면을 떠올리게 만든 뒤 반전을 꽂는 구조다. 수동적 정보 수용이 아니라 능동적 상상을 하게 만들어야 반전의 충격이 배가된다.

**공통 패턴 3 — 인트로에서 "겉 vs 속" 대비 + 시청 혜택 약속** (3/3 영상):
- 002: "따로따로 보면 각 나라 사정 → 전체를 보면 전부 중국으로 향한다" + "4개 연결 고리를 모두 보여주겠다"
- 003: "겉으로는 초강대국 위장 → 한 꺼풀 걷으면 뼈대부터 썩어" + "월스트리트 데이터를 해체 재조립해 드리겠다"
- 004: "밖에서는 에너지 목줄, 안쪽은 더 끔찍" + "이 영상 하나면 에너지부터 인터넷 통제까지 한 번에 정리"

인트로의 핵심 역할은 두 가지다: (1) "겉보기와 실체가 다르다"는 서사적 긴장 설치, (2) "이 영상을 끝까지 보면 무엇을 알게 되는가"를 구체적으로 약속.

**개별 전략**:
- 003만의 고유 장치: "월스트리트 투자기관, 세계 최고 권위 싱크탱크"라는 권위 소스 예고로 정보 신뢰도를 미리 올리는 기법. 다만 본문에서 구체 출처가 빠져 약속 미달이 된 사례이기도 하다.
- 004만의 고유 장치: "호랑이인 줄 알았는데 고양이"라는 동물 비유로 복잡한 지정학을 한 이미지로 압축. 비유의 각인력이 매우 높다.

### 설계 원칙

1. **첫 문장에서 시청자의 기존 상식을 극대화하고, 두 번째 문장에서 한 방에 뒤집어라.** "중국이 무너진다"를 바로 말하지 말고, 먼저 "중국이 이렇게 강해 보인다"를 충분히 세운 뒤 "근데 실체는 이렇다"로 전환한다.
2. **훅은 질문형 또는 상상 유도형으로 시작하여 시청자를 능동적으로 끌어들여라.** "알고 계셨나요?", "상상해 보신 적 있나요?" 같은 형식으로 시청자가 먼저 장면을 그리게 한 뒤 반전을 꽂는다.
3. **인트로에서 반드시 (1) "겉 vs 속" 대비를 설치하고 (2) 영상 전체의 로드맵(몇 개의 포인트를 다룰 것인지)을 구체적으로 약속하라.** "오늘은 중국 붕괴에 대해 알아볼게요"는 금지. "이 영상 하나면 A부터 B, C, D까지 한 번에 정리됩니다" 수준의 구체적 혜택을 선언한다.
4. **권위 소스를 예고할 경우 반드시 본문에서 구체적 이름을 이행하라.** 003의 사례처럼 "싱크탱크 데이터"를 예고하고 출처를 안 밝히면 신뢰도가 오히려 하락한다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**구조 비교**:

| 영상 | 정보 배치 순서 | 핵심 패턴 |
|------|-------------|----------|
| 002 | 약점 노출 → 우회 전략 → 우회 차단 → 다음 전선 (×4회 반복) | 압박-반격-재압박 나선 |
| 003 | 현상 폭로 → 원인 해부 → 피해 확산 → 구조적 자멸 → 외부 반격 → 내부 추가 붕괴 | 층위별 누적 폭로 |
| 004 | 충격 반전 → 원인 계층 해부 (외부→내부) → 결론 역추적 → 시청자 관점 전환 | 외부→내부 심화 |

**공통 구조 — "누적 충격 + 심화 계층" 서사** (3/3 영상):
세 영상 모두 하나의 문제를 제시한 뒤 "그런데 이게 끝이 아니다"로 다음 층위를 까는 계층 구조를 쓴다. 하나의 충격이 해소되기 전에 다음 충격을 누적시켜 "도대체 얼마나 심각한 거야?"라는 감각을 만든다.
- 002: 에너지 → 물류 → 남미 → 광물 (4전선 순차 폭로)
- 003: 시위 → 재정 → 부동산 → 부채 → 청년 → 제조 → 서방 반격 → 군부 (8단계 누적)
- 004: 에너지 → 자본 → 군사 → 드론 → 정보통제 (5층위 심화)

**공통 구조 — "외부 위기 → 내부 부패 → 한국 연결" 3막 흐름** (3/3 영상):
- 초반~중반: 외부 환경의 압박 (에너지 봉쇄, 서방 관세, 공급망 재편)
- 중반~후반: 내부 구조의 붕괴 (군부 비리, 부동산 파탄, 청년 실업)
- 결미: 한국 시청자에게 직접 연결 (물가, 투자, 제조업 기회)

**전달 기법**:

*비유* (공통 패턴 — 3/3 영상):
- 경제/군사 현상을 **신체·의료 비유**로 전환: "경제 혈관이 꽉 막힌 심정지 상태"(003), "나라 전체의 심장이 멈추는 구조"(004), "두 개의 기도를 미해군이 동시에 쥐고"(004)
- **동물 비유**: "호랑이인 줄 알았는데 고양이"(004), "착즙 대상"(002)
- 모든 비유가 "추상적 거시경제 → 체감 가능한 신체/일상 이미지"라는 동일한 방향으로 작동한다.

*숫자/데이터* (공통 패턴 — 3/3 영상):
- 절대 수치 + 체감 비교를 쌍으로 제시: "전략비축 14억 배럴 = 120일치"(002), "GDP의 30~40%"(003), "드론 수백만 원 vs 패트리엇 40억 원"(004)
- 단독 수치는 사용하지 않고, 반드시 비교 대상(기간, 배수, vs 대비)을 붙인다.

*사례* (공통 패턴 — 3/3 영상):
- 실제 인물/사건을 서사의 전환점에 배치: 이란 핵심 인사 암살(002), 헝다 파산(003), 마윈·앤트그룹 상장 취소(004)
- 추상적 추세 설명 → 구체 사례 → "그래서 이런 일이 실제로 벌어졌다"의 3단계로 신뢰도를 높인다.

**리텐션 장치**:

*오픈루프 배치 패턴* (공통 — 3/3 영상):
- **파트 전환 직전**에 "근데 이게 끝이 아닙니다" / "안쪽은 더 끔찍하죠" / "근데 여기서 등골이 서늘해지는 숫자가 나옵니다" 형태로 다음 파트의 존재를 예고한다.
- 002: "근데 여기서 등골이 서늘해지는 숫자가 나옵니다" (중반)
- 003: "도대체 어떤 참담한 현실이 사람들을 벼랑 끝으로 몰고 간 걸까요?" (중반)
- 004: "그런데 안쪽은 더 끔찍하죠" (초반), "더 끔찍한 진실이 안에 있었습니다" (중반)

*패턴 인터럽트 배치 패턴* (공통 — 3/3 영상):
- 경제 분석이 길어질 때 **완전히 다른 영역**(군사, 감시, 개인 이해관계)으로 갑자기 전환하며 시청자를 재각성시킨다.
- 002: "이 화려한 친환경의 장막을 걷어내면"
- 003: "엎친 데 덮친 격으로 체제를 수호해야 할 군대 내부에서는 상상을 초월하는 참사가"
- 004: "벤츠 타고 베이징에서 호위호식하는 공산당 순혜부가 자기 목숨과 재산을 걸고 이 드론 지옥 속으로 군대를 밀어넣을 수 있을까요?"

### 설계 원칙

1. **본론은 "계층 누적 폭로" 구조로 설계하라.** 하나의 문제를 완결한 뒤 "그런데 이게 끝이 아닙니다"로 다음 층위를 여는 구조를 최소 3~4회 반복한다. 각 층위는 독립적으로도 충격적이되, 이전 층위의 결론이 다음 층위의 전제가 되어야 한다.
2. **"외부 압박 → 내부 붕괴 → 한국 직접 연결"의 3막 뼈대를 유지하라.** 초반~중반은 외부 환경(봉쇄, 관세, 공급망), 중반~후반은 내부 구조(부패, 부동산, 청년), 결미는 한국 시청자의 삶·자산에 직접 연결한다.
3. **비유는 추상적 거시경제 개념이 나올 때마다 배치하되, 방향은 항상 "신체/일상 이미지"로 전환하라.** "해협 봉쇄"를 "기도를 쥐고 있다"로, "경제 침체"를 "심정지"로 바꾸는 식이다.
4. **숫자는 반드시 대비 쌍으로 제시하라.** 절대 수치 단독 사용 금지. "X억 배럴"이 아니라 "X억 배럴 = Y일치", "드론 X만 원 vs 미사일 Y억 원" 형태로 체감 가능한 비교를 붙인다.
5. **파트 전환 직전에 반드시 오픈루프를 설치하라.** "근데 이게 끝이 아닙니다", "안쪽은 더 끔찍합니다" 형태로 다음 파트의 존재를 예고하여 이탈을 방지한다.
6. **경제 분석이 3분 이상 이어지면 패턴 인터럽트로 영역을 전환하라.** 거시경제 → 군사, 경제 → 개인 이해관계, 정책 → 현장 사례 등 완전히 다른 영역으로 급전환하여 시청자를 재각성시킨다.

| 중반 | 공포 (에너지 급소) | 충격·분노 (약탈·비리) | 공포 (에너지·군사) |
| 중후반 | 배신감 (이란 착즙) | 연민·허무 (청년 탕핑) | 통쾌함 (종이호랑이) |
| 후반 | 경각심 (내 물가) | 경각심 (자산 방어) | 경각심 (한국 기회) |

**공통 감정 흐름**: 호기심/충격(초반) → 공포/분노(중반) → 통쾌함/배신감(중후반) → 경각심(후반)

세 영상 모두 초반에 부정적 감정(공포, 분노)을 충분히 쌓은 뒤, 중후반에 카타르시스(통쾌함, 위선 폭로)를 제공하고, 후반에 경각심으로 착지한다.

### 설계 원칙

1. **경멸/통쾌함이 1순위 감정이므로, 초반에 중국의 '허세'를 충분히 세운 뒤 중반부터 민낯 폭로 포인트를 촘촘하게 배치하라.** "이렇게 강한 척했는데 실체는 이렇다"의 낙차가 클수록 통쾌함이 강해진다. 군부 비리(미사일 물 채움), 외교 배신(이란 착즙), 경제 허세(종이호랑이) 중 최소 2개 이상의 폭로 포인트를 배치한다.
2. **분노를 쌓는 구간(초반 30%)에서는 권력자의 약자 착취 에피소드를 구체적으로 넣어라.** "벌금 폭탄 난발", "혈세로 만든 미사일이 비리 자판기" 같은 구체적 장면이 추상적 수치보다 분노를 강하게 유발한다.
3. **감정 흐름 설계: 호기심/충격(초반 20%) → 공포/분노(중반 30%) → 통쾌함(중후반 30%) → 경각심+한국 연결(후반 20%).** 통쾌함 구간이 없으면 공포 일변도가 되어 시청 피로를 유발한다. 반드시 "강자의 추락" 카타르시스를 중후반에 배치한다.
4. **결미에서 반드시 "이게 내 삶에 무슨 영향인가"로 착지하라.** 댓글 3위가 한국 직접 영향(미세먼지, 제조업, 물가)인 것은 시청자의 미충족 수요를 보여준다. 물가·환율·투자·일자리 등 개인 체감 연결이 필수다.
