# 대본 검수 결과

## 핵심약속 검수

- [x] Hook에서 핵심약속을 바로 이행하고 있는가 — "미사일에 물"이라는 충격 팩트로 즉시 "종이호랑이의 속사정"이라는 핵심약속에 진입한다.
- [x] 각 파트가 핵심약속 이행에 기여하는가 — 군사(파트1) → 경제(파트2) → 에너지(파트3) → 한국 영향(파트4) 모두 "강한 척한 중국의 진짜 속사정 + 내 삶에 던지는 의미"라는 약속에 기여한다.
- [x] 마무리에서 핵심약속이 완결되는가 — "겉은 세계 2위, 속은 이미 무너지고 있습니다"로 종이호랑이 결론을 명확히 완결한다.

## 구조 검수

- [x] outline.md의 본문 구조(파트 순서, 내용)대로 작성되었는가 — 파트1~4 + 클로징 순서와 내용이 outline.md와 정확히 일치한다.
- [x] 확정 제목이 암시하는 구조를 정확히 따르는가 — "미사일에 물" 폭로 → 계층별 민낯 벗기기 미스터리 추적 구조를 따른다.
- [ ] 타겟 러닝타임 범위 안에 들어가는가 — 목표 20분(약 8,000자). 대본 전체가 약 5,400자 수준으로 목표 대비 약 68%. **파트4가 outline 기준 ~1,200자인데 실제로는 약 800자 수준으로 빈약하다.**
- [x] 확정된 Hook과 Intro가 outline.md와 일치하는가
- [x] 각 파트의 감정 흐름이 outline.md 설계와 맞는가 — 충격 → 경멸 → 공포/통쾌함 → 경각심 순서가 유지된다.
- [x] 리텐션 장치(오픈루프, 전환 멘트)가 파트 전환 지점에 배치되었는가 — 매 파트 전환에 오픈루프가 배치되어 있다.
- [x] verified-data.md의 검증된 데이터만 사용했는가 — 아래 신규 주장 검수 참조.
- [ ] **[치명적] Hook+Intro 본문 중복**: Hook & Intro 텍스트(1~5행)가 파트1 도입부(9~11행)에 거의 동일하게 반복된다. 파트1은 "자, 그러면 첫 번째 민낯부터 벗겨볼게요"로 시작해야지, Hook+Intro 전문을 다시 복사해선 안 된다.
- [ ] **[치명적] 파트 전환부 중복**: 파트2 도입(37~39행)이 파트1 마지막 전환 멘트(33행)와 동일 문장을 반복한다. 파트3 도입(69~70행)도 파트2 마지막 전환 멘트(65행)와 동일 문장을 반복한다. 전환 멘트가 앞 파트의 마지막에 한 번만 나와야 하며, 다음 파트 머리에 다시 쓰면 안 된다.

## 문체 검수

- [x] 따옴표를 남발하지 않았는가 — 적절하게 사용됐다.

- [x] 용어 순화가 적용되었는가 — outline.md 용어 순화 매핑과 일치한다.
- [x] 한 문장에 숫자가 3개 이상 몰려있지 않은가 — 대체로 1~2개 수준으로 잘 통제했다.

- [ ] **오탈자**: 파트2 63행 "중국 정부 스스로가" → "스스로" (맞춤법 오류, "스스로"가 맞음). 정확히는 "스스로"도 비표준이며 올바른 표기는 **"스스로"**. 재확인하니 표준어는 "스스로"이다. 해당 표기는 오류 없음. — 아니, 재검토: 표준국어대사전 기준 "스스로"가 맞다. 원문 "스스로"는 올바르다. 취소.

## 톤 검수

- [x] 채널 프로필의 말투와 톤 규칙을 따랐는가 — "~거든요", "~인 거예요", "~인 셈이죠" 존댓말 베이스가 일관되게 유지된다. 친한 형이 설명해주는 느낌이 잘 살아 있다.
- [x] outline.md에 정의된 프로젝트별 톤을 따랐는가 — 핵심 포인트에서 단정적으로 끊어주는 패턴이 잘 구현되었다.
- [x] 금지 표현("오늘은", "학자들에 의하면", "과학적으로 증명된")이 사용되지 않았는가 — 없음.
- [x] 시그니처 표현("근데요, 여기서 진짜 무서운 건", "쉽게 말하면")이 적절히 사용되었는가 — 다수 사용됨. 다만 "근데요, 여기서 진짜 무서운 건"이 전체 대본에서 5회 이상 반복되어 과다 사용에 가깝다. 3회 이내로 줄이는 것을 권장.

## 심각도 분류

### 치명적
1. **Hook+Intro 본문 중복**: Hook & Intro 전문이 파트1 도입부에 그대로 반복된다. 시청자가 같은 말을 두 번 듣게 되므로 이탈 유발. 파트1 시작 시 Hook+Intro 복사분(9~11행)을 삭제하고 "자, 그러면 첫 번째 민낯부터 벗겨볼게요. 군사입니다."로 바로 진입해야 한다.
2. **파트 전환부 중복**: 파트1→2 전환 멘트(33행)와 파트2 도입(37~39행), 파트2→3 전환 멘트(65행)와 파트3 도입(69~70행)이 각각 동일 문장을 반복한다. 각 파트 도입부의 중복 문장을 삭제해야 한다.

### 경미한
1. **분량 부족**: 전체 약 5,400자로 목표 8,000자 대비 약 68%. 특히 파트4가 얇다. 분량 보강이 필요하나, 중복 삭제 후 기준으로 재산정 필요.
2. **시그니처 표현 과다 사용**: "근데요, 여기서 진짜 무서운 건"이 5회 이상 등장. 3회 이내로 줄이고 변형 표현("근데요, 여기서 소름 돋는 건" 등)으로 분산 권장.
3. **레퍼런스 비유 원문 차용**: "공산당이 숨 쉬는 데 필요한 두 개의 기도" 표현이 004 원문과 거의 동일. 독자적 비유로 변형 권장.
4. **파트4 제목에 글자수 지시 잔재**: "파트 4: 종이호랑이 빈자리 — 우리에게 튀는 파편 (~1,200자)"에서 "(~1,200자)"는 outline 작업 메모이므로 삭제 필요.

## verdict: 수정

Hook+Intro 본문 중복과 파트 전환부 중복은 같은 내용을 연속 반복하게 만들어 시청자 이탈을 유발하는 서사 구조 파괴에 해당한다. 두 곳의 중복을 삭제하면 나머지는 양호하므로, 중복 제거 후 재검수 없이 통과 가능하다.
