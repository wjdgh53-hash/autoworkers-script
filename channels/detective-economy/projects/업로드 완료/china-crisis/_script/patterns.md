# 공통 성공 패턴 & 설계 원칙

## 1. 반복되는 훅 공식

### 관찰

**각 영상 훅 원문 비교**

| 영상 | 조회수 | 훅 원문 | 패턴 |

| 001 | 329,845 | "여러분, GDP 5% 성장을 자랑하던 나라에서 노인들이 밥 달라고 거리로 쏟아져 나왔다는 거 아시나요?" | 인지 부조화(긍정 통념 vs 극단적 현실) + 질문형 |
| 004 | 202,530 | "넘어가서 중국의 성장률 반토막 좀 보겠습니다. 시장 개혁 없이는 성장률이 2.5%까지 떨어질 수 있다라는 경고의 목소리가 어제 나오기도 했습니다." | 단정형 선언("반토막") + 속보성("어제") |
| 003 | 125,473 | "완하면 중국의 부동산에 있어서 가장 대표적이고 자존심으로 뽑히고 있는데요. 지금 채무 지부를 90일 정도 더 연장 요청을 했다고 합니다." | 구체적 기업명 + 숫자(90일) 긴박감 |

**공통 훅 패턴**

1. **인지 부조화 충돌** (최고 퍼포먼스 001에서 가장 극적으로 구사): "GDP 5% 성장"이라는 긍정적 기대와 "노인이 밥 달라고 거리에 나왔다"는 충격적 현실을 한 문장 안에서 충돌시킨다. 뇌가 모순을 해소하려는 본능 때문에 영상을 계속 본다.
2. **단정형 선언**: "사실상 붕괴", "반토막" 등 결론을 먼저 던져 시청자의 확증 욕구를 즉각 건드린다. 002, 004처럼 썸네일-제목에서 이미 충격을 받고 클릭한 시청자에게 "맞습니다"로 확인해주는 방식.
3. **질문형 마무리**: 001의 "아시나요?"처럼 시청자를 대화에 끌어들여 수동 관람을 능동 참여로 전환.

**인트로 공통 역할**

001 인트로가 압도적으로 정교하다:
> "2026년 초 베이징 정부 청사 앞에서 실제로 벌어진 일입니다. (...) 천안문 사태 이후 무려 36년 만에 (...) 대체 세계 2위 경제 대국의 속사정이 어떻길래 이 지경까지 온 걸까요? 지금부터 낱낱이 파헤쳐 드리겠습니다."

4개 영상 인트로에서 공통적으로 수행하는 역할:
- **사실 기반 못박기**: "실제로 벌어진 일"(001), "어제 나오기도 했습니다"(004) -- 허구가 아님을 선언
- **스케일 증명**: "36년 만에 최초"(001), "50조원 적자"(002), "90일 연장"(003), "지방정부 20곳 하향"(004) -- 구체적 숫자/역사성으로 '이번은 다르다'를 입증
- **오픈루프 설치**: "어떻길래 이 지경까지 온 걸까요?"(001), "어떻게 해석을 좀 해 봐야 될까요?"(003) -- 본문 전체를 관통하는 질문을 설정해 끝까지 보게 만듦

### 설계 원칙

- [ ] 첫 문장에서 **인지 부조화 구조**를 사용한다: 중국 경제에 대한 통념(세계 2위, GDP 5% 등)과 충격적 현실(서민 생존 위기, 은행 파산 등)을 한 문장 안에 충돌시킨다.
- [ ] 훅 마지막은 **질문형**으로 닫아 시청자를 대화에 끌어들인다 ("~거 아시나요?", "~어떻길래?").
- [ ] 인트로에서 반드시 3가지를 수행한다: (1) '실제 사건'임을 선언, (2) 구체적 숫자/역사성으로 스케일 증명, (3) 본문 전체를 관통하는 오픈루프 질문 설치.
- [ ] 인트로 마무리에 "파헤쳐 드리겠습니다" 류의 **전문성 + 약속 선언**을 넣어 시청자가 본문에 기대하는 가치를 명시한다.

## 2. 반복되는 본론 구조 & 전달 기법

### 관찰

**정보 배치 순서 비교**

| 영상 | 흐름 |
|------|------|
| 001 (329K) | 거짓 성장 폭로 → 불황형 흑자 → 디플레이션 → 부채 → 은행 파산 → 정책 실패(3대 레드라인) → 기업 몰락(헝다) → 민간 탄압(마윈) → 제로코로나 → 관세 → LGFV → 인구 절벽 → 시나리오 → 한국 영향 |
| 004 (202K) | 성장률 반토막 경고 → 부동산 수요 절벽 → 저출산 → (반전: K배터리 수혜) |
| 003 (125K) | 기업 위기(완커 디폴트) → 숫자 충격(GDP 302%) → 일본 비교 → 좀비기업 → 정책 한계 |
| 002 (27K) | 현황 진단(적자 규모) → 구조 설명(악순환) → 규모(공실 8천만) → 연쇄 효과 → 정부 대응 한계 → 한국 시사점 |

**공통 서사 흐름: "화장발 폭로 → 악순환 구조 → 정부 무력 → 내 일로의 전환"**

4개 영상 모두 동일한 뼈대를 공유한다:
1. **화장발 폭로**: 겉으로 보이는 수치(GDP 5%, 무역 흑자)의 허위성을 벗긴다
2. **악순환 구조 제시**: A가 무너지면 B가 흔들리고 C까지 온다는 인과 사슬
3. **정부/권력의 무력함**: 시진핑의 정책 실패, 16조 위안을 쏟아도 소용없다
4. **내 일로의 전환**: 한국 수출 의존도, K배터리 등 시청자 자기화

001이 가장 성공한 이유는 이 뼈대 위에 **인간 서사**(헝다 창업자 몰락, 예금자 40만 명 잔액 0원, 마윈 증발)를 촘촘하게 얹었기 때문이다.

**전달 기법 비교**

*비유*:
- 001: "화장발 성장", "아파서 못 먹으니 식비가 줄어든 것", "비행기 엔진을 하늘 한가운데서 꺼버린 것", "유령 회사 = 비밀 금고" -- 추상적 경제 개념을 신체적/일상적 이미지로 번역
- 003: "부유해지기도 전에 빚더미에 올라앉은 셈" -- 일본 대비 중국의 취약성을 한 문장으로 압축
- 004: "시한 폭탄", "수요 절벽", "인구 절벽" -- 감각적 메타포

공통점: **추상적 경제 지표가 등장할 때마다 반드시 일상 비유가 따라붙는다**. 001이 가장 다양하고 구체적인 비유를 구사하며, 조회수도 가장 높다.

*숫자*:
- 001: "8경 원 = 한국 GDP의 3,700배", "377개 은행 소멸(일주일에 4~7개)", "40만 명 예금 증발" -- **대비 쌍 + 체감 단위 변환**
- 002: "50조 적자, 17조 최대 적자, 8천만 가구, 소매 0.9%" -- **연속 숫자 폭격**
- 003: "GDP 302%, 좀비기업 8%→17% 두 배 폭증" -- **변화율 대비**
- 004: "8경원, 성장률 2.5%, 출산율 0.7명" -- **최악치 제시**

공통점: 숫자를 단독으로 던지지 않는다. 반드시 **(1) 비교 대상**(한국 GDP, 일본 버블, 이전 수치)과 **(2) 체감 번역**(일주일에 4~7개, 한국 GDP의 3,700배)이 함께 온다.

*사례/스토리텔링*:
- 001(최고 퍼포먼스): 헝다 창업자 쉬자인의 서사(시골 고구마죽 → 42조 갑부 → 체포), 예금자 40만 명의 1인칭 공포, 마윈 증발 -- **개인의 이야기로 거시 경제를 번역**
- 002~004: 기업명(완커, 이케아, 万科)은 언급하나 개인 서사는 없음

**핵심 차이**: 001만이 "사람의 이야기"를 서사 중심에 놓았고, 나머지 3개는 숫자+지표 나열에 머물렀다. 조회수 차이(329K vs 27K~202K)의 핵심 변수.

### 설계 원칙

**본론 뼈대**:
- [ ] 4단계 서사 흐름을 따른다: (1) 화장발 폭로(겉 수치의 허위성) → (2) 악순환 인과 사슬(A→B→C 도미노) → (3) 권력의 무력함(정부/시진핑도 못 막는다) → (4) 내 일로의 전환(한국 시청자의 지갑/일자리에 미치는 영향)
- [ ] 에피소드는 7개 이내로 압축한다 (001의 14개는 후반 집중도 분산 약점)
- [ ] 각 에피소드에 **최소 1개의 인간 서사**(개인/기업의 구체적 사례)를 배치한다 -- 숫자만 나열하지 않는다

**전달 규칙**:
- [ ] 추상적 경제 지표가 등장할 때마다 **일상 비유**를 반드시 1개 이상 붙인다 (예: "화장발 성장", "엔진을 하늘에서 꺼버린 것")
- [ ] 숫자는 단독 제시 금지. 반드시 **(1) 비교 대상 + (2) 체감 번역**과 함께 제시한다 (예: "8경 원 = 한국 GDP의 3,700배", "일주일에 은행 4~7개 사라짐")
- [ ] 핵심 데이터는 **권위 출처**(S&P, 골드만삭스, 피치 등)를 명시해 신뢰도를 확보한다

**리텐션 배치 규칙**:
- [ ] 도입부: 본문 전체를 관통하는 **오픈루프 질문** 1개 설치
- [ ] 파트 전환 직전: **"근데요, 여기서 진짜 무서운 건"** 류의 패턴 인터럽트로 다음 파트 궁금증 설치
- [ ] 중반 (전체의 40~60% 지점): **1인칭 이입 가능한 감정 강타** 장면 배치 (예: "내 통장 잔액이 0원")
- [ ] 훅에서 사용한 핵심 이미지를 본문 중간에 **앵커로 재사용**하여 감정 일관성 유지
- [ ] 엔딩: 댓글 유도형 질문("여러분은 어떻게 보시나요?")으로 참여 전환
