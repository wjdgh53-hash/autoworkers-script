# 대본 검수 결과

## 체크리스트 결과

### 1. 핵심약속 검수 — 통과
- Hook에서 핵심약속("자산인지 소비재인지 판별 + 뭘 사야 하나") 열린 고리("우리는 대체 그동안 뭘 산 걸까요")를 즉시 심고, 감정 빌드업만 하고 미루지 않는다.
- 각 파트가 핵심약속에 기여: 파트4가 자산/소비재 판별을 직접 이행, 파트6이 실용 결론(가진 사람/살 사람/한국 사례)으로 완결.
- 마무리에서 열린 고리 명시 회수: "우리가 산 건 그 작은 돌덩이 자체가 아니었어요. '이건 특별하고, 영원하다'는 이야기를 산 거였죠." — 핵심약속 완결됨.

### 2. 구조 검수 — 통과
- outline 구조대로: Hook&Intro → 파트1~6 → 클로징. 파트 순서·내용 일치.
- 확정 제목이 암시하는 몰락/원인 규명 시간순 서사(통념→상술→범인→여파→결론) 정확히 따름.
- Hook/Intro가 outline·hook-intro 원문과 완전 일치(대조 확인).
- 러닝타임: 타겟 20분·8,000자에 부합(±10% 내).
- verified-data 데이터만 사용. verified-data에 없는 신규 주장 없음.
- 리텐션 장치: 파트 전환마다 오픈루프/브릿지 배치 확인.

### 3. 문체 검수 — 통과
- 쉼표·따옴표 남발 없음. 초등학생도 이해할 쉬운 말(숯, 얼음, 통장, 명품 재고, 금은방 시세) 유지. 숫자 과밀 없음.

### 4. 톤 검수 — 통과
- "친한 형" 존댓말 톤 일관.
- 시그니처 카운트 준수: "근데요, 여기서 진짜 핵심은" = 2회(파트3, 클로징). "쉽게 말하면" = 4회(파트2·3·4·5).
- 금지 표현 없음, 제목 금지어 없음.
- 크리에이터 분석 섹션 존재(파트4) + 면책. 엔딩 통찰 존재(레퍼 "영원한 제국은 없다" 회피).

### 5. 신규 주장 검수 — 통과 (신규 주장 없음)
- 대본의 모든 수치를 verified-data와 1:1 대조 → 전부 범위 내. WebSearch 필요 항목 없음.
- 기계 5만대 = "추정치"로 명시됨. GIA 구별 단서 반영됨. "2011 사상최고" 미사용.

### 6. 독창성 검수 — 위반 발견 (치명적 1건, 리비전에서 수정)
- 레퍼 고유 비유 대부분 성공적 교체(연필심→숯, 수도꼭지/댐→명품 재고, 압력솥→열·압력 재현, 똥값→헐값, 코미디→헛웃음 등).
- 그러나 파트5 감정 펀치라인 융합 복제 1건 발견 → 수정.
