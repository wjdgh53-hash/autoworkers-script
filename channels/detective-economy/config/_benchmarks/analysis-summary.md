## 공통 패턴
- 톤: 존댓말 베이스, 친한 형이 설명해주는 느낌. "~거든요", "~인 거예요" 체. 단정적이고 직접적인 어조.
- 서사 구조: 몰락 서사 + 반전 서사. 충격적 팩트로 훅 → 배경 설명 → 데이터 심층 분석 → 연쇄 결과 → 마무리. "겉으로는 X인데 속은 Y" 구조 반복.
- 훅 기법: 첫 문장에서 충격적 장면/사실을 던짐 ("노인들이 밥 달라고 거리로", "중국 국기를 단 배들만 빠져나가고"). 질문형 마무리로 다음 내용 유도.
- 전달 방식: 숫자 데이터 + 일상 비유 혼합. 추상적 수치를 체감 가능한 비교로 전환 ("한국 GDP의 3,700배", "일주일에 은행 40개 증발").

## profile.md에 반영한 내용
- 톤: 친한 형 스타일, 존댓말 베이스
- 금지 표현: "오늘은", "학자들에 의하면", "과학적으로 증명된"
- 시그니처: "근데요, 여기서 진짜 무서운 건", "쉽게 말하면"
- 서사: 몰락 서사 + 반전 서사 선호, 나열형 기피
- 관점: 소비자/일반인 시점
- 전달: 숫자 데이터 → 일상 비유 혼합
