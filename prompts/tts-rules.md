# TTS 대본 전처리 규칙

⚠ 절대 원칙: 원본 내용(문장, 단어 선택, 어순, 의미)은 절대 변경하지 않는다. 형식만 정리한다.
- 문장을 다시 쓰거나, 표현을 바꾸거나, 요약하거나, 순서를 바꾸지 않는다.
- 아래 규칙에 해당하는 형식 요소만 제거/수정한다.

> 🚨 **이 문서가 정하는 건 「표기 형식」뿐이다. 「어떤 값을 쓸지」는 `prompts/tone-guide.md`가 정한다.**
> tone-guide가 이미 "7,917억 원 → 8천억 어치쯤", "19.4% → 다섯 곳 중 한 곳"으로 바꿔 놓은 것을
> **정밀 수치나 `%` 기호로 되돌리지 않는다.** 아래 표는 *남아 있는* 숫자를 어떻게 적을지에만 적용한다.
> 충돌하면 **tone-guide가 우선**이다.
>
> 🚨 **`script.txt`는 한 줄 형식이다.** 아래 4번(문단 구분은 빈 줄)은 **draft 단계 규칙이며 `script.txt`에는 적용하지 않는다.**
> `finalize.py`가 물리적으로 한 줄로 합치므로, TTS 검수 때 줄바꿈을 새로 넣지 않는다.

## 정리 규칙

1. 나레이션 텍스트만 출력 (제목, 장면번호, 연출지시 등 제거)
2. 문장이 끝나면 온점(.) 뒤에 공백 1칸
3. 따옴표("") 사용 최소화 — 직접 인용이 아니면 제거
4. 문단 구분은 빈 줄(줄바꿈)로
5. 특수문자(※ ★ → 등), 이모지 사용 금지
6. URL, 이메일 주소 삽입 금지
7. 단어 뒤 괄호 설명 금지 (예: 클로드(Claude) → 클로드)
8. 숫자 표기 — 아래 표를 따른다. **연도·금액·규모를 한글로 풀어 쓰지 않는다** (글자 수가 부풀어 분량 검증이 왜곡됨)

| 대상 | 표기 | 예 |
|------|------|-----|
| 연도·월·일 | 아라비아 | `2026년 7월 1일` |
| 시각 | 아라비아 | `오후 5시 49분` |
| 금액·규모 | 아라비아 + 한글 단위 | `55조 원`, `14억`, `600만 명`, `8,000명` |
| 순위·배수·기간 | 아라비아 | `2위`, `7배`, `70년`, `31년째` |
| 조항·법 번호·대수 | 아라비아 | `63조`, `65개 조항`, `14대 달라이 라마` |
| 퍼센트 | **`%` 기호** | `78%`, `16.5%`, `0.1%` |
| 무게·부피·길이 | 아라비아 + 단위 | `20톤`, `300킬로그램`, `5리터`, `12미터` |
| 나이 | 한글 | `쉰두 살`, `여섯 살` |
| 구어체 소수 | 한글 (**고유어 단위에만**) | `하나`, `둘`, `세 가지`, `네 단계` |

- 🔴 **수를 한글로 쓸 때는 단위를 보고 고른다.**

  | 단위 | 수 | 예 |
  |---|---|---|
  | 고유어 단위 (개·명·살·가지·마리·곳·단계) | 고유어 | `스무 개` ○, `쉰두 살` ○ |
  | 외래어·한자어 단위 (톤·킬로그램·미터·리터·퍼센트·분·초·년·원) | **한자어** | `이십 톤` ○ / `스무 톤` ✗ |

  → 헷갈리면 **아라비아로 쓴다** (`20톤`). 툴이 알아서 「이십 톤」으로 읽는다.

- 천 단위 구분 쉼표를 쓴다: `8,000명`, `4조 6,000억 원`
- 소수점 표기 그대로: `78.7%`, `16.5%`
- 범위는 물결표 대신 `에서`로 읽는다: `97에서 98%`
