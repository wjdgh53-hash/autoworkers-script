# 대본 검수 체크리스트

## 핵심약속 검수

- [ ] Hook에서 핵심약속을 바로 이행하고 있는가 (감정 빌드업만 하고 미루지 않는가)
- [ ] 각 파트가 핵심약속 이행에 기여하는가 (핵심약속과 무관한 파트가 없는가)
- [ ] 마무리에서 핵심약속이 완결되는가
- [ ] **클로징이 통찰 착지 + 마무리 3단(열린 질문 → 시청자 위치 → 감사·약속·CTA)으로 끝나는가** — 3단 블록이 200~300자를 넘지 않고, 이전 영상과 같은 문구를 재사용하지 않았는가

## 구조 검수

- [ ] outline.md의 본문 구조(파트 순서, 내용)대로 작성되었는가
- [ ] 확정 제목이 암시하는 구조를 정확히 따르는가 (예: "3가지 이유" → 정확히 3섹션)
- [ ] 타겟 러닝타임 범위 안에 들어가는가
- [ ] Hook과 Intro가 hook-intro.md와 일치하는가
- [ ] 각 파트의 감정 흐름이 outline.md 설계와 맞는가
- [ ] 리텐션 장치(오픈루프, 전환 멘트)가 파트 전환 지점에 배치되었는가
- [ ] verified-data.md의 검증된 데이터만 사용했는가

## 문체 검수

- [ ] 쉼표를 남발하지 않았는가 (이어붙일 수 있으면 이어붙인다)
- [ ] 따옴표를 남발하지 않았는가
- [ ] 초등학생도 이해할 수 있는 쉬운 말로 쓰였는가
- [ ] 용어 순화가 적용되었는가 (outline.md 용어 순화 매핑 참고)
- [ ] 한 문장에 숫자가 3개 이상 몰려있지 않은가 (비교용 2개까지는 OK)
- [ ] **숫자 밀도가 과하지 않은가** — 파트당 핵심 수치 2~3개를 크게 넘어 나열되고 있지 않은가. 귀로 들었을 때 흘러가버릴 만큼 촘촘하지 않은가 (기준: 1,000자당 8개 이하)
- [ ] **숫자를 던진 뒤 감정으로 번역하는 문장이 붙어 있는가** — 수치를 던지고 곧바로 다음 수치로 넘어가는 구간이 없는가
- [ ] **각 파트 도입 500자에 숫자가 3개 이상 몰려있지 않은가** — 장면·상황을 먼저 세우고 수치는 뒤에 붙였는가
- [ ] 분량이 목표 대비 130% 이상인 파트에 장황한 반복·불필요한 부연이 없는가 (같은 말 되풀이, 비유 연속 중첩, 이미 전달된 메시지 재설명 등)
- [ ] **독재자에게 존칭·경어를 쓰지 않았는가** — 김일성·김정일·김정은, 푸틴, 히틀러, 스탈린, 마오쩌둥 등 독재자·권위주의 지도자에게 "돌아가셨다 / 서거했다 / 별세했다 / ~하셨다"를 썼으면 위반. "사망했다 / 죽었다 / ~했다"로 써야 한다
- [ ] **공포·클릭베이트 과장어를 쓰지 않았는가** — "진짜 무서운 건", "소름이 돋는", "충격적인", "경악할" 등. 전환 문구는 "진짜 핵심은"으로 쓴다. (사실을 그대로 서술하는 "충격을 받았다" 같은 표현은 무방)

## 톤 검수

- [ ] 채널 프로필(`prompts/channels/`)의 말투와 톤 규칙을 따랐는가
- [ ] outline.md에 정의된 프로젝트별 톤을 따랐는가
- [ ] 시그니처 표현이 profile.md에 명시된 영상당 최대 횟수를 초과하지 않았는가

## 신규 주장 검수

- [ ] draft.md에 있지만 verified-data.md에 없는 사실적 주장(비교, 수치, 구체적 사례)이 있는가
- [ ] 있다면 각 주장을 WebSearch로 검증했는가
- [ ] 검증 결과를 아래 표에 빠짐없이 정리했는가

신규 주장이란: 검증 가능한 사실적 주장. 비교("A 돈이면 B를 할 수 있다"), 수치("X%가 Y이다"), 구체적 사례("Z 회사가 W했다") 등.
신규 주장이 아닌 것: 수사적 표현("취미가 아니라 짐이 됩니다"), 일반 상식("겨울이 짧아지고 있다"), 의견("어느 쪽을 고르겠습니까").

### 신규 주장 검증 결과

| # | 주장 | 위치(파트) | 유형 | 검증 | 실제 | 수정제안 | 출처 |
|---|------|-----------|------|------|------|----------|------|
| 1 | (예: "170만원이면 동남아 해변에서 일주일") | 파트 4 스키 | 비교 | ❌ | ... | ... | ... |

목록이 비어있으면 "없음"으로 표기.

## 독창성 검수

⚠️ 레퍼런스 과의존은 채널 신뢰도를 훼손하고 시청자 이탈을 유발하는 치명적 문제다. **사실(공개 정보)의 중복은 불가피하지만, "표현"의 중복은 베꼈다는 인상을 준다.** 레퍼런스 분석 파일(`_refs/*/analysis.md`)에 기록된 레퍼런스 고유 표현과 대조하여 검수한다.

- [ ] 본문의 서사 구조(전개 순서)가 특정 레퍼런스 1개의 구조를 그대로 따르고 있지 않은가
- [ ] Hook/Intro가 특정 레퍼런스의 Hook을 핵심 명사만 바꾼 수준으로 복제하지 않았는가
- [ ] 핵심 펀치라인(마무리 인사이트, 반복 인용될 문장)이 레퍼런스 원문과 동일하지 않은가
- [ ] **레퍼런스 고유의 비유가 그대로(또는 핵심 명사만 바꿔) 재사용되지 않았는가** (예: 레퍼의 "반도체가 쌀이면 텅스텐은 가마솥"을 그대로 사용 → 위반)
- [ ] **레퍼런스 고유의 시그니처/캐치프레이즈·말버릇·특이 표현이 재사용되지 않았는가** (그 레퍼 채널을 떠올리게 하는 관용구·독특한 문장 패턴·농담/말장난)
- [ ] **누가 봐도 "대본을 긁어왔다"고 의심할 만한 지점(인상적 문구, 특정 단어 조합, 리스트 구성, 인용 멘트)이 없는가**
- [ ] 영상 전체에서 "우리 영상만의 고유한 관점/정보/표현"이 최소 3가지 이상 식별되는가
- [ ] 레퍼런스 영상을 이미 본 시청자가 "같은 내용·같은 말"이라고 느낄 가능성이 있는가

> **판정 기준**: 사실·수치·사건이 같은 것은 위반이 아니다. **비유·캐치프레이즈·인상적 문구·펀치라인 등 "표현"이 레퍼런스와 동일하거나 핵심 명사만 바꾼 수준이면, 단 1개라도 치명적으로 본다.** 같은 사실은 반드시 우리만의 다른 표현/비유로 바꿔 쓴다. verified-data.md·outline.md에 레퍼런스에서 흘러든 비유가 있더라도 대본에서는 새 표현으로 교체되어야 한다.

### 독창성 심각도 분류
- **치명적**: 서사 구조/엔딩 멘트/핵심 펀치라인이 특정 레퍼런스를 복제 → verdict: 수정
- **치명적**: 레퍼런스 고유 비유·시그니처/캐치프레이즈·특이 표현을 그대로(또는 핵심 명사만 바꿔) 재사용 (1개라도) → verdict: 수정
- **경미한**: 고유한 관점/표현이 2가지 이하 → 개선 권장
