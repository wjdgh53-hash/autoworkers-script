# 문체 가이드 — 친구가 자기 전에 풀어주는 채널

> 이 문서는 **작가(script-writer)와 검수자(script-reviewer)가 반드시 읽는다.**
> 규칙 문장보다 **아래 대조쌍**이 우선이다. 규칙이 헷갈리면 대조쌍을 보고 판단한다.
> 모든 ❌ 예시는 **우리가 실제로 내보낸 대본 원문**이다. 지어낸 예시가 아니다.
>
> 🚨 **적용 범위: 시니어 타겟 경제 채널 전체 — `detective-economy` 계열과 `bangguseok-economy` 계열 둘 다.**
> 두 계열은 **소재축이 정반대**지만(무대·주어가 중국 vs 시청자 본인의 돈) **크리에이터·TTS·시청자층이 같아** 문체 기준은 공유한다.
> 축·소재 판단은 각 채널의 `config/profile.md`와 `direction.md`·`expansion-strategy.md`가 따로 정한다.
> 아래 0장의 타겟·톤 서술은 그 채널을 전제로 쓰였다. **타겟이 다른 채널은
> `channels/{채널}/config/profile.md`가 우선한다** — 상충하면 profile을 따르고, 이 문서에서는
> 문체 기법(대조쌍·치환표·숫자 처리)만 가져다 쓴다. 숫자 밀도·용어 상한 같은 기계 검증 기준은 채널과 무관하게 공통이다.

## 0. 이 채널이 뭐 하는 채널인지부터

| | |
|---|---|
| **아닌 것** | 정보를 얻으러 오는 채널. 정확하고 정교한 분석을 주는 채널. 강의. |
| **인 것** | **자기 전에 가볍게 요즘 정세·시사를 읽는 채널.** 친구가 옆에서 풀어주는 이야기. |
| **시청자** | **50~60대 이상 남성 시니어.** 경제 용어에 익숙하지 않고, 메모하며 보지 않는다. |
| **시청자가 원하는 것** | 정확한 정보가 아니라 **감정**. 통쾌함, 자부심, 분함, 어이없음, 안도. |

> 사람은 물건을 살 때도 **감정으로 사고 이성으로 합리화한다.** 대본도 같다.
> 팩트는 감정을 정당화하는 근거일 뿐, 팩트 자체가 목적이 아니다.
> **정확한 사실은 끝까지 지킨다. 다만 "정확해 보이려는 어휘"는 전부 버린다.**

### 한 줄 판정법

> **"이 문장, 술자리에서 친구한테 말로 하겠는가?"**
> 말로 안 할 문장이면 대본에도 쓰지 않는다.

## 1. 대조쌍 — 실제 대본에서

### ① 용어는 한 문장으로 끝낸다. 깊은 이해는 블록 3이 맡는다

**❌ 옛 규칙 — "정의 → 일상 사물 → 생활 비유로 세 번 다르게" (2026-08-10 폐기)**

같은 개념을 세 번 말하면 시청자는 **같은 얘기를 또 듣는다**고 느낀다.
이 규칙이 비유를 문장마다 뿌리게 만든 발원지였다. 실측: 우리 비유 밀도 3.4~4.1 vs 벤치마크 0.2~2.4.

**⭕ 이렇게 쓴다 — 필요한 그 순간에, 한 문장으로**

> 프리IPO 지분이라는 겁니다. **상장하기 전에 미리 받아 두는 회사 몫이에요.**
> KPI가 뭐냐면 **회사가 반드시 달성해야 하는 공식 실적 지표**거든요.
> 초도함. **그러니까 그 모델의 첫 번째 배라고 부릅니다.**

- 용어는 **서사가 그것을 필요로 하는 순간에** 처음 등장시킨다. 미리 정의하고 시작하지 않는다
- 정의는 **한 문장**이다. 두 번 세 번 바꿔 말하지 않는다
- 깊은 이해가 필요한 핵심 개념은 [`script-skeleton.md`](script-skeleton.md) **블록 3**이 통째로 맡는다.
  거기서 60초 이상 들여 하나를 제대로 세운다 — **수단은 확장 비유 / 실제 사례 / 숫자 전개 중 소재가 정한다.**
  나머지 자리에서는 짧게 정의하고 지나간다

### ② 숫자는 던지고 나서 반드시 살림으로 착지시킨다

**❌ 우리가 실제로 쓴 것** (changwon)
> 부채비율이 386%에서 116%로 떨어져요. 쉽게 말하면 빚에 눌려 숨을 못 쉬던 회사가, 주인이 바뀌는 그날 숨통이 트인 겁니다.

용어를 안 풀어줬고, "숨통"이라는 추상어로 넘어갔다.

**⭕ 이렇게 쓴다**
> 여기서 부채비율이라는 말이 나오는데요, 겁먹으실 것 없습니다. **내 재산에 견줘서 빚이 몇 배냐**, 딱 그겁니다.
> 헬러가 386이었어요. **재산이 백만 원인데 빚이 삼백팔십육만 원이라는 소리입니다.**
> 이자 날짜만 다가오면 달력을 쳐다보게 되는 처지죠. 132년 된 명가가 겉은 멀쩡한데 속은 그렇게 곪아 있었던 겁니다.
> 그게 116까지 내려왔습니다. 아직 빚쟁이인 건 맞아요. 다만 **이제는 이자 내고도 뭘 좀 해볼 돈이 남는다**는 뜻입니다.

### ③ 퍼센트는 "몇 중에 몇"으로 바꾼다

**❌ 우리가 실제로 쓴 것** (china-rice-cadmium)
> 전국의 땅을 찍어 보니 기준을 넘은 지점이 16.1%, 농사짓는 땅만 떼면 19.4%로 올라갑니다. (…) 물질별로 보면 1위가 카드뮴입니다. 7.0%. 2위 니켈이 4.8%였어요. 광산이 낀 지역만 보면 33.4%까지 뜁니다.

**한 문단에 퍼센트 5개.** 귀로 들으면 하나도 안 남는다.

**⭕ 이렇게 쓴다**
> 중국 땅을 찍어 봤더니 **여섯 곳 중 한 곳**이 기준을 넘었습니다.
> 그런데 농사짓는 땅만 따로 떼면 **다섯 곳 중 한 곳**으로 올라가요.
> 공장 터도 아니고 산도 아니고, **하필 밥이 나오는 땅이 제일 나빴다는 겁니다.**
> 그중에서도 제일 많이 나온 게 카드뮴이었고요.

퍼센트 5개 → **"여섯 곳 중 한 곳", "다섯 곳 중 한 곳"** 둘로. 니켈·광산 수치는 버린다.

### ④ 정확한 숫자는 반올림한다

**❌ 우리가 실제로 쓴 것** (changwon)
> 2024년 헬러의 매출은 우리 돈으로 7,917억 원이었어요. (…) 그런데 같은 해 새로 받아 든 주문은 3억 9,100만 유로에 그쳤어요. 판 것의 4분의 3에도 못 미치는 금액입니다.

**⭕ 이렇게 쓴다**
> 그해 헬러가 판 물건이 **8천억 어치쯤** 됩니다. 숫자만 보면 그럭저럭 굴러가는 회사죠.
> 그런데 **새로 들어온 주문은 그 4분의 3도 안 됐어요.**
> 이게 무슨 뜻이냐면요. **올해 만든 건 작년에 받아둔 주문이고, 내년에 만들 게 지금 안 들어오고 있다**는 겁니다.
> 가게로 치면 오늘 손님은 있는데 **예약 장부가 비어가는 거예요.** 이게 제일 무서운 신호입니다.

- 7,917억 → **8천억 어치쯤**
- 3억 9,100만 유로 → **버린다** (원화도 유로도 둘 다 말할 필요 없다)
- 2만 3,900곳 → **2만 곳이 넘는다** / 5만 1,500개 → **5만 개**

> 검증된 정확한 값은 `verified-data.md`와 `youtube.md` 출처에 그대로 남는다. **대본에서만 반올림한다.**

### ⑤ 서류를 뜯어보지 않는다

**❌ 우리가 실제로 쓴 것** (changwon)
> 처음엔 678억이라고 적혀 있었는데, 정정공시가 나오면서 3,243억으로 늘어납니다. (…) 한쪽은 기존 주주들이 갖고 있던 주식을 사 온 값입니다. 4,200만 유로, 우리 돈으로 약 700억이에요. 다른 한쪽은 헬러가 새로 찍어낸 주식을 받고 넣어준 돈입니다. 1억 5,000만 유로, 2,533억이고요.

정확하다. 그런데 이건 **애널리스트가 하는 일**이다. 시청자는 공시를 뜯어보러 오지 않았다.

**⭕ 이렇게 쓴다**
> 창원이 낸 돈이 3,243억입니다. 그런데 이 돈, **전부 독일 주인 손에 간 게 아니에요.**
> 주인 몫으로 간 건 700억뿐입니다. 나머지 2,533억은 **회사 금고에 그대로 들어갔어요.**
> 무슨 얘기냐면요. **낡은 집을 사면서 집값만 치른 게 아니라, 새는 지붕 고치라고 수리비까지 얹어 준 겁니다.** 그것도 집값의 세 배가 넘게요.
> 헐값에 주웠다는 얘기가 아닙니다. **고칠 자신이 있어서 간 쪽에 가까워요.**

"정정공시", "기존 주주", "신주" — **전부 뺀다.**

### ⑥ 검증 과정을 대본에 노출하지 않는다

**❌ 우리가 실제로 쓴 것** (china-rice-cadmium)
> 여기서 우리가 쓰지 않을 숫자를 먼저 말씀드릴게요. 2013년 광저우 검사에서 44.4%가 나왔다는 수치가 널리 돕니다. 열여덟 건 중 여덟 건이 걸린 겁니다. 이 정도 표본으로 퍼센트를 앞세우기엔 약해서, 우리는 이 숫자를 안 씁니다.

정직하지만, 시청자는 **우리의 검증 방법론에 관심이 없다.** 흐름만 끊긴다.

**⭕ 이렇게 쓴다**
> 못 미더운 숫자는 **그냥 대본에서 뺀다.** 왜 뺐는지 설명하지 않는다.
> 확실한 것만 말한다: "후난성 조사에서는 **열에 일곱**이 기준을 넘었습니다."

> ⚠️ **팩트체크 파이프라인은 그대로 유지한다.** 검증은 계속 하되, 검증 과정을 화면에 보여주지 않는 것뿐이다.

## 2. 용어 치환표 (필수)

우리 대본은 경제·행정 용어를 레퍼의 **5배**(1,000자당 4.1개 vs 0.8개)로 쓰고 있다.
아래 단어가 대본에 보이면 **오른쪽으로 바꾼다.**

| ❌ 관공서·업계 말 | ⭕ 사람 말 |
|---|---|
| 공시 / 정정공시 | 회사가 공개한 서류 / (대개는 통째로 뺀다) |
| 지분 100% 인수 | 회사를 통째로 사들였다 |
| 사모펀드 | 돈 굴리는 회사 |
| 규제당국 승인 | 나라에서 도장을 찍어줬다 |
| 수주 | 새로 받은 주문 |
| 순손실 535억 | 그해 까먹은 돈이 500억 |
| 부채비율 | 재산에 견준 빚의 배수 (풀어서) |
| 매출 / 연결 매출 | 판 돈 / 판 물건 값 |
| 점유율 | 열 대 중 몇 대 |
| 조업단축 | 일감이 없어 근무 시간을 줄이는 것 |
| 전직지원회사로 이관 | 다른 일자리 찾아보라고 내보냈다 |
| 시행령 / 고시 / 조항 | 규정 / 법에 적힌 한 줄 |
| 의무수입물량 / 저율관세할당(TRQ) | 해마다 사주기로 약속한 물량 |
| 국영무역 | 나라가 직접 사온다 |
| 가공용 / 주정용 | 공장으로 가는 것 / 술 만드는 데 쓰는 것 |
| 단립종 / 중립종 / 장립종 | 짧은 쌀 / 긴 쌀 |
| 복합원재료 | 여러 재료를 섞어 만든 것 |
| 국제기준 코덱스 | 세계가 정해 놓은 기준 |
| 전략물자 | 아무한테나 못 파는 물건 |
| 우선협상대상자 | 먼저 얘기해 보기로 한 상대 |
| 국가핵심기술 | 나라 밖으로 못 넘기게 묶어 둔 기술 |
| 수치제어장치(CNC) | 기계한테 어디를 얼마나 깎으라고 시키는 두뇌 |
| 컨소시엄 | 여러 회사가 뭉친 팀 |
| 정규직 | 계약이 끝나지 않는 자리 (대개는 "정식 직원") |
| 영업손실 | 장사해서 까먹은 돈 |
| 법령 | 법에 적힌 규정 |
| 안전이용률 | 평생 먹어도 괜찮다고 정해 둔 양의 몇 %인지 |
| 인증서 | 나라가 발급하는 확인 서류 |
| 이관 | 다른 데로 넘겼다 |

## 3. 수치 처리 4원칙

1. **반올림한다** — 다만 **어떻게** 반올림할지가 정해져 있다 (2026-08-12 정호님)

   🔴🔴 **865조를 800조로 만든 사고가 있었다.** 「반올림 규칙에 따랐다」 고 했지만
   865를 반올림하면 900이지 800이 아니다. **규칙이 애매해서 아무렇게나 깎였다.**

   **㉠ 어느 자리에서 자르나 — 맨 앞 한 자리만 남긴다**
   ```
   7,917억  →  7|917    2만 3,900  →  2|3,900    865조  →  8|65
   ```
   ⚠️ **단위를 따로 정할 필요가 없다.** 「맨 앞 한 자리」 라고 하면 자를 자리가
      저절로 정해진다 (억이든 조든 만이든).

   **㉡ 방향을 먼저 정한다 — 내림이 기본이다** (2026-08-16 개정)

   🔴 **사고를 만드는 건 오차의 크기가 아니라 방향이다.**
   내림은 뒤에 「넘는다·이상·남짓」을 붙이면 **참이 된다.** 올림은 어떤 수식어를 붙여도 참이 안 된다.
   실측이 이 축을 그대로 보여준다 — `2만 3,900곳 → 2만 곳이 넘는다`(**-16.3%**)는 아무 문제가 없었고,
   `1만 7천 개 → 2만 개 가까이`(**+17.6%**)는 검수에서 과장으로 잡혔다. **오차는 비슷한데 결과가 갈렸다.**

   ```
   ⭕ 내림       기본값. 내린 뒤 「넘는다 / 이상 / 남짓」을 붙인다
                 2만 3,900곳  →  2만 곳이 넘는다

   ⚠️ 올림       자를 자리 첫 숫자가 7 이상이고, 결과가 원값에서 3% 이내일 때만
                 7,917억     →  8,000억        (+1.0%,  허용)
                 1만 7천 개   →  2만 개          (+17.6%, 금지 → 「1만 7천 개 넘게」)

   🔴 4·5·6     그대로 둔다 (반올림하지 않는다)
                 865조       →  865조
   ```
   ⚠️ 4·5·6 은 **어느 쪽으로 깎아도 거짓말이 된다.** 865를 900이라 하면 부풀리고
      800이라 하면 줄인다. **그럴 땐 안 깎는 것이 맞다.**

   ⚠️ **올림에만 3% 한도를 두는 까닭** — ㉠의 「맨 앞 한 자리」는 **앞자리가 작을수록 오차가 커진다.**
      7,917억은 앞자리를 올려도 1%대지만 1만 7천은 같은 규칙으로 **18%가 틀어진다.**
      ㉠만으로는 이 차이를 못 잡으므로 여기서 한 번 더 거른다.

   **㉢ 🔴 아라비아 숫자로 적는다 — 「팔백조」 라고 쓰지 마라**
   ```
   ○ 865조 · 800조 · 8,000억 · 2만 곳
   ✗ 팔백육십오조 · 팔백조 · 팔천억
   ```
   **까닭은 §3-2 의 퍼센트와 똑같다.** 대본 글자가 **자막으로 그대로** 나가므로
   한글로 풀어 쓰면 화면에 「팔백조」 가 뜬다. 읽는 것은 툴이 맡는다 —
   이지롱폼 발음 규칙이 `800조` 를 **「팔백조」** 로 알아서 바꾼다 (확인함).
   (2026-08-12 정호님이 완성 자막에서 잡으심 — 「16%」 때와 **똑같은 사고**다)

   **㉣ 🔴🔴 올림이 사실을 부풀리면 반올림하지 않고 원값을 쓴다** (2026-08-16)

   🔴 **밀도를 낮추려다 팩트를 깨는 사고가 실제로 났다.** `china-beltroad-debt-bill`에서
      숫자 밀도를 10.2 → 8.7 로 내리는 압축 패스를 돌렸는데, **검수에서 잡힌 치명적 7건 중
      4건이 그 패스가 새로 만든 과장**이었다.

   | 원값 | 반올림한 표기 | 무엇이 깨졌나 | 판정 |
   |---|---|---|---|
   | 1만 7천 개 | `2만 개 가까이` | +17.6% 부풀림 | 🔴 **㉡을 지켰는데 틀림** → 그래서 ㉡에 3% 한도를 넣었다 |
   | 1조 5,800억원 | `2조원에 가까운` | +26.6% 부풀림 + 다른 파트의 `2조원`과 혼동 | ⚠️ **㉡ 위반** (앞자리 5 → 그대로 뒀어야 함) |

   ㉠~㉢ 은 **자릿수를 어디서 자를지**만 정할 뿐, **자른 결과가 참인지**는 안 본다.
   그래서 규칙을 지켜도 거짓이 나올 수 있다. 아래를 마지막 관문으로 둔다.

   ```
   반올림한 값을 소리 내어 읽고 스스로 묻는다.
   "이 문장, 원값을 아는 사람이 들어도 틀렸다고 안 할까?"
   → 아니면 반올림하지 말고 원값을 그대로 쓴다.
   ```

   - **"~에 가까운 / ~이나 / 거의 ~" 같은 수식어를 큰 쪽으로 붙이지 않는다.** 붙이는 순간
     반올림이 주장으로 바뀐다. 내림에 붙이는 「넘는다·이상」은 반대로 문장을 참으로 만든다
   - **같은 대본 안에 이미 쓴 금액으로 수렴시키지 않는다.** 1조 5,800억을 `2조원`으로 올리면
     앞 파트의 다른 `2조원`과 같은 사실로 읽힌다
   - ⛔ **밀도가 넘칠 때 올림으로 자릿수를 줄이려 하지 마라.** 밀도는 **퍼센트를 '몇 중에 몇'으로
     바꾸고(§3-2) 중복 값을 합쳐서** 줄인다. 그쪽이 효과도 크고 사실을 안 건드린다

   📌 **같은 사고에서 나왔지만 반올림 문제가 아닌 것 2건** — 여기서 다루지 않는다
   - `평균 12년 연장 → 20년이나 뒤로` — 재편성 **전체 기간**을 연장 폭으로 읽은 **팩트 오독**.
     → `script-review-checklist.md` 소관
   - `공정률 13% → 열에 하나도 못 끝냈는데` — **퍼센트→분수 변환**의 경계값 문제.
     → 바로 아래 **§3-2** 소관

   📌 **표기 형식은 `tts-rules.md` 8번 표를 따른다.** 이 절은 「어떤 값을 쓸지」 만
      정한다 — 값을 정한 뒤의 **적는 법은 tts-rules 가 이긴다.**
2. **퍼센트는 분수·사람 수로** — 19.4% → 다섯 곳 중 한 곳 / 86% → 열 대 중 여덟 대 넘게

   🔴🔴 **퍼센트를 한글로 풀어 쓰지 않는다. 숫자로 남길 거면 언제나 `%` 기호다.**
   ```
   ○ 숫자를 아예 없앤다      19.4% → 다섯 곳 중 한 곳
   ○ 숫자로 남긴다           16%              ← 이대로 쓴다
   ✗ 열여섯 프로 · 십육 퍼센트 · 십육 프로     ← 한글로 풀지 마라
   ```
   **까닭 — 읽는 것은 툴이 맡는다.** 대본 텍스트는 자막으로 **그대로** 쓰이므로
   `16%` 라고 적혀 있어야 화면이 자연스럽다. 소리로 읽을 때는 이지롱폼의
   발음 규칙이 `16%` 를 **「십육 퍼센트」** 로 알아서 바꾼다
   (`0.1%`·`16.5%`·`97에서 98%` 도 다 처리한다).
   한글로 풀어 쓰면 **자막이 「열여섯 프로」 로 나가서 오히려 망가진다.**
   (2026-08-09 정호님이 완성 영상 자막에서 잡으심)

   ⚠️ **「프로」 라는 말은 어느 규칙에도 없다.** 쓰지 마라.

   🔴 **경계값을 넘겼는지 반드시 확인한다** (2026-08-16 추가)

   분수로 바꾸는 것도 반올림이다. **가장 가까운 분수로 가되, 경계를 넘긴 값을 내려 쓰지 않는다.**

   ```
   ❌ 13%  →  열에 하나도 못 끝냈는데     13%는 10%를 "넘었다". 사실과 반대다
   ⭕ 13%  →  열에 하나를 겨우 넘겼는데
   ⭕ 19.4% →  다섯 곳 중 한 곳          20%에 근접 — 가장 가까운 분수라 참
   ⭕ 86%  →  열 대 중 여덟 대 넘게       내림 + 「넘게」라 참
   ```

   판정법은 §3-1 ㉡과 같다 — **내려서 쓸 때는 「넘는다·넘게·이상」을 붙이면 참이 되고,
   「못 / 도 안 되는 / 채 안 되는」을 붙이면 거짓이 된다.**
3. **핵심 숫자만 체감으로 착지시킨다** — 그 파트의 감정을 만드는 숫자에만 붙인다

   ⚠️ 옛 규칙은 "던졌으면 **반드시** 살림으로 착지"였다. 그러면 숫자 개수만큼 비유가 생긴다.
   착지는 **비유가 아니어도 된다.** 오히려 이쪽이 낫다.
   ```
   ❌ 부채비율 386% → "재산 백만 원에 빚 삼백팔십육만 원" (살림 비유)
   ⭕ 대조로 착지    → "일본은 같은 의무로 86.6%를 사료로 돌렸습니다. 한국은 63.8%를 사람이 먹는 데 넣었고요"
   ⭕ 시나리오로 착지 → "공장 사장 입장에서 보세요. 눈앞에 쌀통이 두 개 있는 겁니다"
   ⭕ 규모 환산으로   → "대한민국 1년 예산의 절반이 넘는 돈입니다"
   ```
4. **한 문단에 숫자 2개까지** — 세 번째 숫자가 나오려 하면 그건 버릴 숫자다

**하한만 있다: 1,000자당 4개 이상**(방구석 12개 이상). 미달이면 WARN이고, **상한은 없다.**

> 🔴 **상한 10.0은 2026-08-19 삭제했다.** 근거였던 레퍼 히트 3편(5.9/7.4/9.7)이 2026-08-04 것인데, 방구석 결 벤치 히트작은 23~33이었다. **소재가 돈이면 숫자가 본질이다.**
> 탐정 발행 대본 91편 중 54편이 초과인데 전부 발행됐고 채널은 성과가 났다. **과반이 걸리는 상한은 무시되고, 그 습관이 진짜 FAIL에도 옮겨붙는다.**
> 실제 청취 문제인 **「몰아쓰기」는 문장당 4개 게이트가 잡는다** — 상한 초과 54편 중 40편이 거기에도 걸렸다. 상한이 단독으로 잡던 14편은 그냥 숫자가 골고루 많은 대본이었다.
> ⛔ **숫자를 많이 쓰라는 뜻이 아니다.** 총량으로 차단하지 않을 뿐, 아래 몰아쓰기 규칙은 그대로다.

- **하한 4** (방구석 12): **203k 히트작이 4.6**이고 우리 최근작은 2.0~5.1이었다.
  숫자가 모자란다는 건 **할 얘기가 없어서 비유로 때웠다**는 뜻이다. 비유를 지우고 사실·사례를 넣는다

> 경제·행정 용어는 **1,000자당 1.5개**가 차단선이다. §2 치환표대로 바꾸면 대개 0점대로 떨어진다.

## 4. 문체 레이어 — 상한·하한 (2026-08-10 전면 개정)

### 항목별로 실제로 뭘 하라는 건가

**반문 — 던진 질문은 그 자리에서 답한다. 개수를 채우지 않는다.**

> 🔴 **2026-08-19 개정 — 옛 하한 「≥3.5, 60초에 한 번꼴로 되묻는다. 이게 리텐션 백본이다」는 삭제했다.**
> 근거가 203k 히트작 **1편(7.9)** 뿐이었는데, 탐정경제학 발행 대본 **91편을 전수 측정하니 중앙값 2.4로 78%(71편)가 미달**이었다. 성적이 나온 대본 대부분이 어기고 있었으므로 **하한 쪽이 틀렸다.**
> 반대로 이 하한을 곧이곧대로 지킨 방구석 08-16은 **반문 7.7**이 됐고, 개수를 채우려다 **"질문해 놓고 답을 미루는"** 문장이 들어가 시청자에게 *"무슨 말인지 하나도 못 알아먹겠다"* 는 댓글을 받았다.

- ⭕ 질문을 던졌으면 **바로 다음 문장에서 답한다.** 답이 곧바로 나오는 질문만 던진다
- ⛔ **답을 뒤로 미루는 질문은 아예 던지지 않는다** — "이건 뒤에서 말씀드릴게요", "여기서는 계산하지 않겠습니다"
- ⛔ 밀도를 맞추려고 질문을 끼워 넣지 않는다. 개수 기준이 없으므로 **채울 이유가 없다**

> "그러면 여기서 당연히 이런 질문이 나오겠죠. 대체 왜 떠난 거냐?" → **곧바로 이유를 말한다**
> "지금 이 두 나라가 잠수함 성능을 겨루고 있는 걸까요? 그게 아니에요." → **한 문장 안에서 닫혔다**

**권위 인용 (하한 없음)** — 발언·보고서·통계를 그대로 가져온다. 1인칭을 줄인 자리를 채우는 **선택지 중 하나**다(대조·사례도 된다).
> ⛔ **하한 0.3은 2026-08-19 삭제했다.** 인용할 것이 없는 소재에서 억지 출처를 붙이게 만들었다.
> "미국의 한 안보 연구 기관은 이번 사업의 가장 큰 위험 요소를 콕 집어 지목했는데요."
> "농협 미래전략연구소 보고서에 따르면—"

**전환어 (하한 없음)** — `자,` `자 여기서` `그런데 말입니다` `여기서 한번`. 블록이 바뀌는 자리에 짧게.
> ⛔ **하한 0.6은 2026-08-19 삭제했다.** 개수를 맞추려 "자,"를 뿌리게 만들었다. 전환이 필요한 자리에만 쓴다.

**비유 소재 (기본 ≤3.0 WARN / 방구석 ≤4.0 FAIL)** — 기계는 확장 비유 하나와 잘게 뿌린 비유 열 개를
구분하지 못하므로, **기본 채널에서는** 넘으면 검수자가 직접 보고 판정한다.

> 🔴 **2026-08-19 — "이 값은 판정이 아니라 「볼 자리」 표시다"라는 옛 문구는 삭제했다.**
> 방구석 08-16이 **4.6으로 경고를 띄웠는데** 검수자가 정확히 이 문구를 근거로
> *"확장 비유 하나를 깊게 판 결과이므로 위반 없음"* 이라 적고 통과시켰고, 그 비유가 개념을 잠식해 사고가 났다.
> **경고를 무시해도 된다고 적어 두면 무시된다.** 방구석은 상한 4.0을 **차단선(FAIL)** 으로 올렸다.
운용 규칙은 [`script-skeleton.md`](script-skeleton.md) §5에 있다 — **영상당 1~3개, 하나당 60초 이상, 뒤에서 재호출.**

> ⚠️ **profile.md의 시그니처 표현 최대 횟수 제한은 "쉽게 말하면" 같은 정형구에만 적용된다.**

## 4-1. 검수 후 재작성(리비전)일 때 — 가장 흔한 사고

레퍼와 겹치는 표현을 지우라는 지적을 받으면, **그 자리를 무엇으로 채우느냐가 매번 사고를 낸다.**

```
❌ 복제된 비유 삭제 → 그 자리에 수치·날짜·기관명 나열   (숫자 밀도가 튄다)
❌ 복제된 비유 삭제 → 그 자리에 새 비유                 (비유 총량이 늘기만 한다 — 옛 규칙)
⭕ 복제된 비유 삭제 → 그 자리에 사례·대조·시나리오·권위 인용
```

> 실측: `bar-karaoke-collapse`는 독창성 4건을 고치는 리비전에서 숫자 밀도가 **2.0 → 5.5**로 뛰었다.
> 옛 규칙("지운 자리를 새 비유로")은 반대 방향으로도 사고를 냈다 — 비유가 줄지 않고 계속 쌓였다.

**지워야 할 게 비유라고 채워야 할 것도 비유인 건 아니다.** 그 자리에 들어갈 1순위는
같은 사실을 보여주는 **다른 사례**, 그리고 **대조**다. 채울 재료가 정말 없으면 outline에 요청한다.
**복제 표현을 되살려서 분량을 맞추는 것은 어떤 경우에도 금지**다 — 독창성이 항상 우선한다.

## 5. 금지 목록

- ❌ "제가 이 숫자들을 나란히 붙여 놓고 본" / "제가 본 핵심은" — **분석가 자기소개 말투**
- ❌ "우리는 이 숫자를 안 씁니다" / "표본이 약해서" — **검증 과정 노출**
- ❌ 한 문단에 퍼센트 3개 이상
- ❌ 같은 금액을 외화와 원화로 두 번 말하기 (원화만)
- ❌ 조항 번호·기관 정식명칭 나열 ("농수산물의 원산지 표시 요령" → "규정 하나가 있는데요")
- ❌ 공포·클릭베이트 과장어 (profile.md 금지 표현 그대로 유지)
- ❌ 레퍼런스 고유 표현 복제 (`script-review-checklist.md` 독창성 검수 그대로 유지)
  ⚠️ **이 금지는 「대본 본문」에만 적용된다.** 제목·썸네일 텍스트는 `prompts/creative-strategy.md`의 「🔓 제목·썸네일 텍스트의 어휘 제약」이 유일한 원본이며, 2026-08-16부터 **100% 그대로 베끼기만 금지**다(단일 명사·감정어·수식어·장르 관용어는 마음껏 쓴다). 모든 채널 공통.
