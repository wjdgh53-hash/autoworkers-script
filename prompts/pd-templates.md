# PD 템플릿 — 산출물 포맷 정의

> 📄 **이 파일이 산출물 포맷의 단일 출처다.** creative-strategy.md 등 다른 프롬프트는 여기를 참조만 하고 포맷을 재정의하지 않는다.

## concept.md 포맷

concept.md는 STRATEGY 단계에서 한 번에 완성된다.
strategist 에이전트가 컨셉 + CTR을 단일 패스로 동시 작성한다.

```markdown
# 영상 컨셉

## 앵글
{이 주제를 어떤 관점으로 풀어가는지 1-2문장}

## 핵심 약속
{한 문장}

## 타겟 시청자
{대상 설명}

## 서사 유형
{서사 유형명} — {선택 근거 1줄}

## 감정 전략
- 목표 감정: {감정}
- 감정 아크: {초반} → {중반} → {후반}
- 리텐션 접근: {방향}

## 제목 후보
1. {후보 1}
2. {후보 2}
3. {후보 3}

> **제목 형식 가이드**
> - `"따옴표 문구" 본제목` 형식 권장 (채널 pd-guide.md에서 필수 지정 가능)
> - 따옴표 형식: 전체 50~60자 이내 / 자유 형식: 30~45자 이내
>
> **따옴표 형식 사용 시:**
> - **따옴표 문구** (15자 이내): Hook/Intro에서 활용될 핵심 문장을 미리 설계
> - **본제목** (35~45자 이내): 주제 + "왜/이유/비밀" 등 호기심 유발 키워드
> - 예: `"배달비 무료라고요?" 시장 99%를 지배했던 배민이 무너진 소름돋는 이유`

## 확정 제목
{제목 1순위 — 잠정 확정. 대본·썸네일·youtube.md는 이 제목 기준으로 작성}

## 제목 후보

| | 제목 | 글자수 | 은닉 대상 |
|---|---|---|---|
| ① (1순위) | {제목안 1} | {N}자 | {감춘 것} |
| ② | {제목안 2} | {N}자 | {감춘 것} |
| ③ | {제목안 3} | {N}자 | {감춘 것} |

> 세 안 모두 같은 본문·같은 썸네일과 호환된다. 사용자가 ②·③을 고르면 제목만 교체하면 된다.

## 참고 레퍼
- 제목 참고: {NNN} "{레퍼 제목}" — {무엇을 참고했는지 1줄}  (또는 "없음 — 독자 설계")
- Hook 참고: {NNN} (차용 레벨 L1~L4)  (또는 "없음 — 역설형")
- **썸네일 계승 후보**: {NNN}  ← 실사형 5번 장이 이 레퍼의 구도를 우선 검토한다. 참고 레퍼가 없으면 "전역 앵커: {NNN}"

## 썸네일 텍스트 후보

1. {줄1} + {줄2} (+ {줄3} if applicable)
2. {줄1} + {줄2} (+ {줄3} if applicable)
3. {줄1} + {줄2} (+ {줄3} if applicable)

> **글자수 기준 (한국어)**: 메인 카피 **1줄·2줄 모두 9~12자(공백 제외), 허용 7~14자**. 리액션 텍스트 2~6자는 별도이며 **매번 세트로 같이 뽑는다**.
> 폰트 크기 때문이다 — 12자를 넘기면 대형 폰트가 안 들어가 모바일에서 안 읽힌다. 못 담은 궁금증 문구는 **제목(기준 35자, 허용 30~40자)**이 받는다.
> 후보마다 각 줄 뒤에 글자수를 `(11자)` 형태로 표기해 기준 안에 드는지 확인한다.

### ★ 후보 표 형식 — 산출물에 이 형태로 수록

> 🚨 **제목·썸네일 카피는 채팅으로 골라 달라고 묻지 않는다.** 후보를 전부 산출물에 넣고 1순위로 진행한다.
> 수록 위치는 **두 곳 모두** — `_script/concept.md`(「## 제목 후보」·「## 썸네일 카피 후보」)와 `output/youtube.md`(「## 제목」 아래).
> 사용자는 대본이 다 나온 뒤 산출물에서 직접 고른다. 중간에 물어서 흐름을 끊지 않는다.

**반드시 아래 두 표로** 낸다. 문장으로 늘어놓거나 후보를 한 줄에 붙여 쓰지 않는다. 1줄·2줄·리액션을 **각각 다른 칸에** 넣어야 조합을 눈으로 비교할 수 있다.

```
## 제목 후보

| | 제목 | 글자수 | 은닉 대상 |
|---|---|---|---|
| ① | {제목안 1} | {N}자 | {감춘 것} |
| ② | {제목안 2} | {N}자 | {감춘 것} |
| ③ | {제목안 3} | {N}자 | {감춘 것} |

## 썸네일 카피 후보

| | 1줄 (감정) | 2줄 (지식 격차) | 리액션 | 시점 |
|---|---|---|---|---|
| ① | `{문구}` ({N}자) | `{문구}` ({N}자) | `{문구}` | {A~D} |
| ② | `{문구}` ({N}자) | `{문구}` ({N}자) | `{문구}` | {A~D} |
| ③ | `{문구}` ({N}자) | `{문구}` ({N}자) | `{문구}` | {A~D} |
```

- **제목·카피 모두 3안씩** 낸다. 1안만 내면 비교가 안 되고, 4안 이상이면 고르기 힘들다
- **글자수를 매 칸에 표기**한다 — 기준 이탈이 눈에 바로 보여야 한다
- 표 아래에 **추천 1개와 그 이유를 2줄 이내**로 덧붙인다. 길게 쓰지 않는다. 추천안이 곧 **1순위 = 잠정 확정**이며, 대본·썸네일 프롬프트·youtube.md는 이 1순위 기준으로 만든다
- 나머지 2안은 **버리지 않고 표에 그대로 남긴다.** 사용자가 나중에 2·3순위를 고르면 제목만 교체하면 되도록, 세 안이 같은 본문·같은 썸네일과 호환되게 설계한다
- 시점 칸은 `ctr-reference.md`의 A~D(피해자 반문 / 가해자 서술 / 당사자 체감 / 상대 좌절) 중 무엇인지 표기
> 계승형(패키지 D)이면 **앵커 레퍼의 실제 글자수를 그대로** 따른다 — 평균값이나 짧은 레퍼 쪽으로 줄이지 않는다. 상세 → `prompts/ctr-reference.md`의 "문구 규칙" 1번

## 선택 근거
{어느 패키지(A~D)를 왜 골랐는지 1~2문장. 데이터 출처 명시.}

> ⚠️ 계승 범위는 **제목과 썸네일뿐**이다. 대본(Hook·본문·비유·전개 순서)은 앵커를 참고하지 않고 독자적으로 작성한다.

- 앵커 레퍼: {NNN} "{앵커 제목}" ({조회수}/일)
- 견인 요소: {제목 / 썸네일 / 양쪽} — {판정 근거}

```

## hook-intro.md 포맷

순수 대본 텍스트만 포함한다. 메타 정보(컨셉 요약, Hook 전략 분석)는 concept.md에 이미 있으므로 여기 넣지 않는다.

```markdown
# Hook & Intro

### Hook ({N자}, ~{N}초)
{실제 나레이션 원문 1~2문장}

### Intro ({N자}, ~{N}초)
{실제 나레이션 원문 4~6문장}
```

> ⚠ 확정 텍스트 헤더는 반드시 `### Hook` / `### Intro` (h3)로 쓴다.
> `## Hook` (h2)를 쓰면 draft.md에서 별도 섹션으로 분리되어 분량 검증이 어긋난다.
> 메타 정보(전략 유형, 차용 레벨, 참고 레퍼런스 등)를 이 파일에 넣지 않는다 — draft.md 오염 원인.

```markdown
⚠️ 각 항목이 구체적이지 않으면 대본 작성 단계에서 레퍼런스 복제로 귀결된다. 빈 칸 금지.

## 6. 리텐션 설계
- 감정 아크: {전체 감정 흐름 — 예: 충격→분석→공감→경각심}
- 재참여 포인트 (파트 전환 + 2~3분 간격):
  - ~N분 (파트1→2 전환): {새로운 궁금증 또는 스테이크 상승}
  - ~N분 (파트2 중반): {새로운 궁금증 또는 스테이크 상승}
  - ~N분 (파트2→3 전환): {새로운 궁금증 또는 스테이크 상승}
  - ... (타겟 러닝타임에 맞춰 2~3분 간격으로 배치)
- 스테이크 상승: {파트가 진행될수록 무엇이 커지는가}
- 참고할 레퍼런스 장치 (patterns.md에서 발췌):
  - {검증된 오픈루프/전환문구/감정유발 장치 — 대본 작성 시 참고}
  - ...
```

### 설명 작성 규칙

**3개 블록, 총 300-500자 (한글 기준):**

1. **Above-the-fold (첫 100자 이내)** — 가장 중요
   - 검색 결과/피드에서 "더보기" 위에 보이는 유일한 텍스트
   - 반드시 포함: ① 핵심 검색 키워드 ② 영상의 핵심 가치/약속
   - 인사말("안녕하세요"), 채널 소개로 시작 금지
   - concept.md의 "핵심 약속"에서 시청자 가치를 추출

2. **본문 (100-200자)**
   - 영상에서 다루는 구체적 내용 2-3가지 명시
   - 핵심 데이터/숫자 1-2개 포함 (신뢰감)
   - 동의어/관련어를 자연스럽게 분산 배치

3. **꼬리 블록**
   - 영상 장르/성격 1줄 (profile.md의 **장르**에서 추출) + 구독 CTA
   - 해시태그 3개 (첫 3개가 영상 제목 위에 표시됨)
   - 해시태그 선정: ① 주제 대표 키워드 ② 채널 장르 키워드 ③ 트렌드/시의성 키워드

> ⚠️ **채널명 삽입 금지 (설명·태그·해시태그 전부)**
> 설명·태그·해시태그 어디에도 **채널명·채널 핸들(@…)을 넣지 않는다.** 완성된 대본의 결에 따라 실제 업로드 채널이 달라질 수 있으므로, youtube.md는 특정 채널에 묶이지 않아야 한다.
> - 꼬리 블록의 소개 문구는 **채널명 대신 영상의 장르/성격**만 서술한다. (예: "역사 속 숨겨진 진짜 이유를 파헤칩니다" — O / "…'방구석 역사'입니다" — X)
> - 장르 키워드(역사, 경제 등)는 태그로 써도 되지만, **채널명 자체는 태그로 쓰지 않는다.**

**키워드 규칙:**
- **3곳 일치**: 제목의 주요 키워드 = 설명 첫 문장 키워드 = 첫 번째 태그
- 동의어 분산 (예: "러시아 원유" → 본문에서 "러시아 나프타", "러시아 에너지")
- 같은 단어 3회 이상 반복 금지 (keyword stuffing 방지)
- 15개 초과 해시태그 사용 시 YouTube가 전부 무시하므로 3개로 제한

### 영상 출처 작성 규칙

**목적:** 영상이 실제 자료를 근거로 제작됐음을 공개해 신뢰도를 높이고, 양산형 콘텐츠 오인에 따른 수익화 제재 시 소명 근거로 삼는다.

- **데이터 소스**: `_script/factcheck.md`(출처 컬럼) + `_script/verified-data.md`("추가 리서치" 항목의 출처)에서 추출. **새로 검색하지 않는다** — 이미 수집된 출처만 정리.
- **대본 대조 필수**: factcheck/verified-data에는 최종 대본에 안 쓰인 사실도 들어있다. **각 출처의 사실이 `_script/script.txt`에 실제로 등장하는지 반드시 확인하고, 대본에 쓰인 사실의 출처만 넣는다.** (대본은 숫자를 한글로 풀어 쓰므로 grep이 아니라 내용으로 대조 — 예: "5천만"→"오천만 톤") 대본에 없는 사실의 출처는 제외.
- **선정**: 위 대조를 통과한 출처 중 영상 핵심 주장·데이터의 근거가 된 **3~7개**. 중복 기관은 하나로 병합. 블로그/커뮤니티는 제외하고 공식 기관·언론사·공시자료 우선.
- **형식**: `『기관·매체명』 — {참고한 핵심 내용} ({URL 또는 기관명 YYYY.MM})`
  - 매체의 기사/보고서 원제를 알면 핵심 내용 대신 큰따옴표로 원제를 넣어도 좋다.
  - URL이 있으면 URL, 없으면 `기관명 YYYY.MM`.
- **출처가 하나도 없으면**(factcheck/verified-data 모두 비어있음) `## 영상 출처` 섹션을 통째로 생략한다. 가짜 출처를 지어내지 않는다.

### 태그 작성 규칙

**5-8개, 500자 이내. 순서가 중요 — 첫 번째 태그에 가장 높은 가중치:**

| 순서 | 유형 | 설명 |
|------|------|------|
| 1번 | 핵심 검색 키워드 | 제목의 주요 키워드와 일치 |
| 2-3번 | 롱테일 변형 | 2-4어절 조합의 구체적 검색어 |
| 4-5번 | 고유명사/엔티티 | 영상 내 핵심 인물/기관/사건명 |
| 6-7번 | 상위 카테고리 | 채널 장르 수준의 넓은 키워드 |
| 8번 (선택) | 오타/대체 표기 | 흔한 맞춤법 오류 커버 |

**형식:** 쉼표로 구분, 띄어쓰기 포함 가능, 해시태그(#) 붙이지 않음
**금지:** 영상과 무관한 트렌드 키워드, 채널명(자기 채널명·핸들 포함), 경쟁 채널명, 10개 초과

### 데이터 소스

```
concept.md → 확정 제목, 핵심 약속, 앵글, 키워드 소스
outline.md → 파트 구조 + 예상 시간 → 타임스탬프
profile.md → 채널 장르 설명 → 꼬리 블록 + 카테고리 태그
script.txt → 글자수/분량 → 타임스탬프 보정 (~440자/분)
factcheck.md + verified-data.md → 영상 출처 (출처/URL)
```
