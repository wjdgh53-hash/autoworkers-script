## concept.md 포맷

concept.md는 STRATEGY 단계에서 한 번에 완성된다.
strategist 에이전트가 컨셉 + CTR을 단일 패스로 동시 작성한다.

```markdown
# 영상 컨셉

## 앵글
{이 주제를 어떤 관점으로 풀어가는지 1-2문장}

## 핵심 약속
{한 문장}

## 타겟 시청자
{대상 설명}

## 서사 유형
{서사 유형명} — {선택 근거 1줄}

## 감정 전략
- 목표 감정: {감정}
- 감정 아크: {초반} → {중반} → {후반}
- 리텐션 접근: {방향}

## 제목 후보
1. {후보 1}
2. {후보 2}
3. {후보 3}

> **제목 형식 가이드**
> - `"따옴표 문구" 본제목` 형식 권장 (채널 pd-guide.md에서 필수 지정 가능)
> - 따옴표 형식: 전체 50~60자 이내 / 자유 형식: 30~45자 이내
>
> **따옴표 형식 사용 시:**
> - **따옴표 문구** (15자 이내): Hook/Intro에서 활용될 핵심 문장을 미리 설계
> - **본제목** (35~45자 이내): 주제 + "왜/이유/비밀" 등 호기심 유발 키워드
> - 예: `"배달비 무료라고요?" 시장 99%를 지배했던 배민이 무너진 소름돋는 이유`

## 확정 제목
{제목}

## 썸네일 텍스트 후보

1. {줄1} + {줄2} (+ {줄3} if applicable)
2. {줄1} + {줄2} (+ {줄3} if applicable)
3. {줄1} + {줄2} (+ {줄3} if applicable)

## 썸네일 이미지 컨셉

### 컨셉 A: {한줄 설명}
- 구도 패턴: {패턴명}
- 핵심 오브젝트: {1~2개}
- 색채/대비: {배경 톤 + 포인트 색}
- 감정 톤: {감정 1개}

### 컨셉 B: {한줄 설명}
- 구도 패턴: {패턴명}
- 핵심 오브젝트: {1~2개}
- 색채/대비: {배경 톤 + 포인트 색}
- 감정 톤: {감정 1개}

## 텐션 트라이앵글 시너지
- 제목: {역할}
- 썸네일 텍스트: {역할}
- 썸네일 이미지: {역할}
- 시너지 평가: {3요소 합작 효과}

## 선택 근거
{왜 이 패키지를 골랐는지 1~2문장. 데이터 출처 명시.}
```

## youtube.md 포맷

```markdown
# YouTube 업로드 정보

## 제목
{concept.md "확정 제목" 그대로 복사}

## 설명
{Above-the-fold 1-2문장: 핵심 키워드 + 후크}

{본문 2-3문장: 영상 핵심 내용 + 데이터 1-2개}

🔔 {영상 장르/성격 1줄 — profile.md의 장르 기반. 채널명·핸들은 절대 넣지 않는다}
구독과 알림 설정 부탁드립니다.

#{해시태그1} #{해시태그2} #{해시태그3}

## 영상 출처
본 영상은 아래 자료를 참고하여 제작되었습니다.

- 『{기관·매체명}』 — {참고한 핵심 내용} ({URL 또는 기관명 YYYY.MM})
- 『{기관·매체명}』 — {참고한 핵심 내용} ({URL 또는 기관명 YYYY.MM})

## 태그
{primary keyword}, {long-tail 1}, {long-tail 2}, {entity 1}, {entity 2}, {broad 1}, {broad 2}
```

### 설명 작성 규칙

**3개 블록, 총 300-500자 (한글 기준):**

1. **Above-the-fold (첫 100자 이내)** — 가장 중요
   - 검색 결과/피드에서 "더보기" 위에 보이는 유일한 텍스트
   - 반드시 포함: ① 핵심 검색 키워드 ② 영상의 핵심 가치/약속
   - 인사말("안녕하세요"), 채널 소개로 시작 금지
   - concept.md의 "핵심 약속"에서 시청자 가치를 추출

2. **본문 (100-200자)**
   - 영상에서 다루는 구체적 내용 2-3가지 명시
   - 핵심 데이터/숫자 1-2개 포함 (신뢰감)
   - 동의어/관련어를 자연스럽게 분산 배치

3. **꼬리 블록**
   - 영상 장르/성격 1줄 (profile.md의 **장르**에서 추출) + 구독 CTA
   - 해시태그 3개 (첫 3개가 영상 제목 위에 표시됨)
   - 해시태그 선정: ① 주제 대표 키워드 ② 채널 장르 키워드 ③ 트렌드/시의성 키워드

> ⚠️ **채널명 삽입 금지 (설명·태그·해시태그 전부)**
> 설명·태그·해시태그 어디에도 **채널명·채널 핸들(@…)을 넣지 않는다.** 완성된 대본의 결에 따라 실제 업로드 채널이 달라질 수 있으므로, youtube.md는 특정 채널에 묶이지 않아야 한다.
> - 꼬리 블록의 소개 문구는 **채널명 대신 영상의 장르/성격**만 서술한다. (예: "역사 속 숨겨진 진짜 이유를 파헤칩니다" — O / "…'방구석 역사'입니다" — X)
> - 장르 키워드(역사, 경제 등)는 태그로 써도 되지만, **채널명 자체는 태그로 쓰지 않는다.**

**키워드 규칙:**
- **3곳 일치**: 제목의 주요 키워드 = 설명 첫 문장 키워드 = 첫 번째 태그
- 동의어 분산 (예: "러시아 원유" → 본문에서 "러시아 나프타", "러시아 에너지")
- 같은 단어 3회 이상 반복 금지 (keyword stuffing 방지)
- 15개 초과 해시태그 사용 시 YouTube가 전부 무시하므로 3개로 제한

### 영상 출처 작성 규칙

**목적:** 영상이 실제 자료를 근거로 제작됐음을 공개해 신뢰도를 높이고, 양산형 콘텐츠 오인에 따른 수익화 제재 시 소명 근거로 삼는다.

- **데이터 소스**: `_script/factcheck.md`(출처 컬럼) + `_script/verified-data.md`("추가 리서치" 항목의 출처)에서 추출. **새로 검색하지 않는다** — 이미 수집된 출처만 정리.
- **대본 대조 필수**: factcheck/verified-data에는 최종 대본에 안 쓰인 사실도 들어있다. **각 출처의 사실이 `_script/script.txt`에 실제로 등장하는지 반드시 확인하고, 대본에 쓰인 사실의 출처만 넣는다.** (대본은 숫자를 한글로 풀어 쓰므로 grep이 아니라 내용으로 대조 — 예: "5천만"→"오천만 톤") 대본에 없는 사실의 출처는 제외.
- **선정**: 위 대조를 통과한 출처 중 영상 핵심 주장·데이터의 근거가 된 **3~7개**. 중복 기관은 하나로 병합. 블로그/커뮤니티는 제외하고 공식 기관·언론사·공시자료 우선.
- **형식**: `『기관·매체명』 — {참고한 핵심 내용} ({URL 또는 기관명 YYYY.MM})`
  - 매체의 기사/보고서 원제를 알면 핵심 내용 대신 큰따옴표로 원제를 넣어도 좋다.
  - URL이 있으면 URL, 없으면 `기관명 YYYY.MM`.
- **출처가 하나도 없으면**(factcheck/verified-data 모두 비어있음) `## 영상 출처` 섹션을 통째로 생략한다. 가짜 출처를 지어내지 않는다.

### 태그 작성 규칙

**5-8개, 500자 이내. 순서가 중요 — 첫 번째 태그에 가장 높은 가중치:**

| 순서 | 유형 | 설명 |
|------|------|------|
| 1번 | 핵심 검색 키워드 | 제목의 주요 키워드와 일치 |
| 2-3번 | 롱테일 변형 | 2-4어절 조합의 구체적 검색어 |
| 4-5번 | 고유명사/엔티티 | 영상 내 핵심 인물/기관/사건명 |
| 6-7번 | 상위 카테고리 | 채널 장르 수준의 넓은 키워드 |
| 8번 (선택) | 오타/대체 표기 | 흔한 맞춤법 오류 커버 |

**형식:** 쉼표로 구분, 띄어쓰기 포함 가능, 해시태그(#) 붙이지 않음
**금지:** 영상과 무관한 트렌드 키워드, 채널명(자기 채널명·핸들 포함), 경쟁 채널명, 10개 초과

### 데이터 소스

```
concept.md → 확정 제목, 핵심 약속, 앵글, 키워드 소스
outline.md → 파트 구조 + 예상 시간 → 타임스탬프
profile.md → 채널 장르 설명 → 꼬리 블록 + 카테고리 태그
script.txt → 글자수/분량 → 타임스탬프 보정 (~400자/분)
factcheck.md + verified-data.md → 영상 출처 (출처/URL)
```
